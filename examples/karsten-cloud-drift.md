# 案例 02：单图到可分层氛围场景

## 目标

输入为 `assets/karsten.jpg`。这次验收的重点不是“把原图加一点动态”，而是把它变成能被独立编辑的场景层：远景、云和前景旅人不再是同一张图。

```text
原照片（构图与主体参考）
  → Agent 重建连续远景底板（移除前景山脊与旅人）
  → Agent 提取透明前景（山脊 + 旅人）
  → Agent 提取透明云层
  → 编辑器：逐层变换 / 调色 / 蒙版 / FX / 时段
```

## 素材与层级

| 图层 | 文件 | 可独立调整的内容 |
|---|---|---|
| 远景底板 · 天空与山谷 | `assets/karsten-layer-backdrop.png` | 背景布局、颜色、全局效果 |
| 透明云层 · 缓慢漂移 | `assets/karsten-layer-clouds.png` | 漂移幅度、速度、波带位移、透明度、混合方式、局部效果 |
| 前景 · 山脊与旅人 | `assets/karsten-layer-foreground.png` | 位置、比例、颜色、蒙版、显示时段；人物不参与扭曲 |
| 谷地空气 | 声明式局部 FX | 锚定前景的跟随关系、雾、蒙版、时段；不裁入前景 Alpha |
| 前景草尖 · 风感 | 程序元素 | 风感强度和颜色 |

前景与云层是真透明 PNG；远景底板有意不包含旅人和尖脊。因此它们不是“在完整背景上又画一遍”，可以独立关掉、移动或替换。

## 当前结论与边界

这验证了“单图 → 分层循环场景”的可行路径，但它还是一次生成式分层试验：三张图之间的像素边缘与光照并非由传统分割算法精确继承，复杂照片可能需要多轮局部修补。它的价值在于让后续编辑拥有真实层级，而不是把 AI 生成图当作不可动的背景。

后续产品化应将这一步变成显式工作流：先让用户确认候选层，再分别生成 / 修补 / 入库；而不是默默以单张完整图替代场景。
