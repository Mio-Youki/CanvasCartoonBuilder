# 双色放射 · 待审阅提案

打开[交互预览](preview.html)，或通过本机预览服务访问。

自动回传需运行`node scripts/serve-effect-review.mjs`并使用8780宿主地址。当前双色放射尚缺正式生成器，确认会接收并说明阻塞，不会伪造正式包；自动交付已有受支持图样的闭环已用测试资源验证。[自动化状态](../../../docs/architecture/EFFECT_REVIEW_AUTOMATION_2026-10-23.md)。下文“未回传”是普通静态地址下的行为。

- 名称：双色放射，预览页可直接修订展示名称，不修改ID。
- 载体：矩形／椭圆／正多边形／自由多边形；不支持开放路径。
- 参数与No／Step／Linear声明直接来自`candidate.js`，旋转仅作用于内部放射色块。
- 打开“时序试验”，选择“目标段”，点击参数旁的◷后修改；再选择“变化段”查看插值。中段“保持／过渡”可切换。No参数不能设置目标。
- 默认可修订名称与参数名称；✎填写单项备注，下方填写总体备注。调参只是试验，须点击“采用当前基础值为默认值”才成为默认值修改建议。
- “修订重置”只还原名称／备注／默认值建议；“图样参数”右侧“重置”只还原试验值与时序。确认按钮根据有无修订显示“确认本轮修订／通过”。
- 本地存储按候选身份和定义指纹隔离；刷新后恢复。不提供下载按钮。`window.patternReview.review()`可读取结构化审阅记录；确认会发出`tosampool:effect-review-confirmed`页面事件。当前没有Agent传输接收方，已确认仍显示“未回传”，不是已经发送。

该页无网络模型、无共享发布或工程写入。审阅记录保存在当前浏览器源下的localStorage；请保持同一预览地址／端口和浏览器配置。候选代码尚未注册进编辑器；等待视觉确认后再进行正式生成器接入。

完整合同与测试：[P5记录](../../../docs/architecture/V4_PATTERN_PARAMETER_TIMING_P5_2026-10-23.md)。
