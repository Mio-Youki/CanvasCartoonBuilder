# 括号 / 角标统一图元设计提案

本文件仅为待实现、待验证的设计建议，不代表现有功能或可运行工程。未读取应用源码、现有示例或测试；未编写 Runtime。两张给定参考图均已读取：深灰底上的浅灰粗左方括号，以及浅灰粗左上角标。图中深灰只作为预览背景，不属于图元。

## 1. 产品结构与最小参数

先选布局，再选造型与位置。造型和布局独立：直角 + 完整得到 [ ]；圆弧 + 完整得到 ( )；直角 + 角标得到「等；圆弧 + 角标得到四分之一椭圆角标。图元可独立创建，也可将参数应用到兼容图元；兼容性由实现验证，本提案不推测现有接口。无独立时序。

| 参数 | 建议默认 | 含义 / 显示条件 |
|---|---:|---|
| layout | full | full 完整括号 / corners 角标 |
| shape | orthogonal | orthogonal 直角 / arc 圆弧 |
| fullSides | both | both 左右 / left 仅左 / right 仅右；仅 full 有效 |
| cornerSet | [tl, br] | 仅 corners 有效；支持四角、两种对角、任意单角 |
| width / height | 240 / 240 | 整组图元外包围框宽高，独立正数 |
| thickness | 24 | 统一粗细，最终坐标单位 |
| horizontalLength | 60 | 每侧横向伸入长度，按中心线测量 |
| verticalLength | 60 | 每角纵向伸入长度，按中心线测量；仅 corners 有效 |
| cornerRadius | 0 | 直角转弯的中心线圆角半径；仅 orthogonal 有效 |
| color / opacity | #CCCCCC / 1 | 全组统一颜色、透明度；透明度 0–1 |

基础界面只需布局、造型、位置、宽高、粗细、横长、颜色。角标显示纵长；圆角放在展开项，直角时显示。宽高可提供比例锁但不必新增持久化参数。上述默认值只是提案，不声称像素复刻参考。

“统一参数”不应解释为每个参数在每种模式都有效：完整括号的竖边由高度决定，不能同时用 verticalLength 再约束；圆弧的曲率由横长与高度 / 纵长决定，不能再同时强制 cornerRadius。条件无效参数保留原值并禁用，切回后恢复；不悄悄重置。

## 2. 统一几何规则

采用局部坐标，外框为 [0,W] × [0,H]，原点左上，y 向下。图元仅有轮廓实体，无背景填充。先构造中心线路径，再用同一粗细 t 展开为实体；端头为平头。左右、上下变体通过关于外框中轴镜像获得，避免各位置重复定义。应用整体变换前在局部空间求几何。

中心线边界 x0=t/2、x1=W−t/2、y0=t/2、y1=H−t/2；有效跨度 A=W−t、B=H−t。横臂长度 a、纵臂长度 b 统一使用中心线长度，因此直角左括号的可见外部横向尺寸为 a+t，角标的外部纵向尺寸为 b+t。这一点必须在字段提示中说明；不能把“横长”同时当外框宽或完整开口宽。

### 完整直角括号

左侧中心线路径依次为 (x0+a,y0) → (x0,y0) → (x0,y1) → (x0+a,y1)。右侧由 x→W−x 镜像。r=0 时为锐角 / 斜接，得到参考中的方正外角；r>0 时在两处转折各以半径 r 的四分之一圆替换，切点距原顶点 r。中心线 r 上限为 min(a,B/2)。竖边总跨度始终由 H 决定。

### 直角角标

左上路径为 (x0+a,y0) → (x0,y0) → (x0,y0+b)；其余角按坐标镜像。r 的上限为 min(a,b)，采用同样的切点圆角规则。

### 圆弧括号

完整左括号用半椭圆：中心 (x0+a,(y0+y1)/2)，半轴 (a,B/2)，取椭圆左半段。上端为 (x0+a,y0)，最左为 (x0,(y0+y1)/2)，下端为 (x0+a,y1)。其端点位置、外框和横向深度与直角括号一致；不额外叠加短横臂。右侧镜像得到配对。

左上圆弧角标用四分之一椭圆：中心 (x0+a,y0+b)，半轴 (a,b)，从顶点 (x0+a,y0) 到左点 (x0,y0+b)，选左上四分之一。其余角镜像。这样完整弧与角弧共享“横向深度”，而纵向覆盖由布局明确决定。

圆弧采用真实椭圆或数值精度有保障的近似，不按字体字符绘制；否则字形、端点和粗细不能统一控制。所有路径的展开区域先求并集，再以 opacity 合成一次，避免交叠部分加深。

## 3. 长度约束与退化边界

W、H 必须有限且大于 0；要求 0<t<min(W,H)。无效输入保留上一个有效状态并给字段反馈，不产生 NaN 或不可见的无限几何。r≥0、0≤opacity≤1。长度与 r 使用下列有效值；存储的请求值保留，界面显示实际受限值及原因，避免看起来可调但画面不动。

- 单边完整括号：0≤a≤A；成对完整括号：0≤a≤max(0,(A−t)/2)。后一约束给上下臂端头之间留至少 t 的水平间距。
- 角标：单角 a≤A、b≤B；若选中同一行的左右两角，则 a≤max(0,(A−t)/2)；若选中同一列的上下两角，则 b≤max(0,(B−t)/2)。纯对角组合按单角上限，允许末端在边界接触；结果仍求并集。四角同时应用两条约束。
- r 按所处布局限制；长度变小时同步限制有效 r，不反向改大长度。
- a=0：完整括号退化成左右竖线，圆弧用显式竖线分支避免零半轴；角标退化成竖向短线。b=0：角标退化成横向短线；a=b=0 的角标为空，不绘制点。平头线段长度为 0 时为空。
- 选择左右括号且 a=0 时保留两条竖线；不得因形状类型自动改成单线。没有选中位置的非法集合应回退到该布局默认选择，位置界面不允许空选。
- 当 W 或 H 接近 t 时，可用跨度趋近 0，成对 / 四角的有效臂长可能为 0；这是明确的线状或空退化，不强行保留一个假的括号。建议显示“尺寸不足以形成角臂”。不设置与缩放相关的隐式最小像素长度。
- 厚描边、小半径可能使内侧圆角融合；实体并集保证合法，但不保证肉眼仍能分辨圆角。若产品希望避免这种外观，应另设交互提示，不偷偷把 r 改成 t/2。
- opacity=0 为合法全透明状态。非均匀整体缩放是否保持粗细属于宿主变换语义，应明确采用宿主一致行为；本提案的局部 t 不在变换后重新解释。

位置组合切换可能改变允许的最大长度：例如单角长臂切到四角时必须缩短。建议保留请求值，计算并展示有效值；回到单角恢复原臂长。若产品只保存有效值，会造成不可逆的切换损失，需要实现时做明确取舍。

## 4. 差异变体与验收建议

variations.json 提供六组建议参数：参考方括号、参考左上角、薄弧括号、圆角对角角标、四角取景框、反对角弧角标。它们是数据提案，无运行入口，须由实际实现适配。

验证应覆盖：同参数的镜像一致性；颜色透明度一次合成；完整与角标切换后的值保留；粗细调整后外框不越界；圆弧 a=0 与角标 a/b=0；四角长度限幅；短边极粗时的退化提示。父级实际实现后应注明采用和修正了哪些规则，尤其是中心线长度语义、长度限幅、圆弧的定义。

## 5. 真实工程合同映射（宿主接入阶段）

新增 project.tosampool.json，按宿主提供的 tosampool-scene/v4 合同建立六个独立 vector 实体，各包含一个 custom 部件；场景为 1000×640、深灰背景、loop=4，六个外框排为两行。它是针对提供合同编写的可编辑示例工程，尚未在应用中打开或渲染验证，不能将语法和边界检查当作视觉验收。

映射：orthogonal→shape:square，arc→shape:round；fullSides→side；cornerSet 的 [tl,br]→corners:tl-br、[bl,tr]→bl-tr、四角→all，单角使用对应短 ID。horizontalLength→armX，verticalLength→armY，cornerRadius→radius；宽高放到实体与部件 w/h；实体 x/y 负责场景排布，部件 x/y 固定为 0；颜色、粗细、透明度依次放入 stroke、strokeWidth、strokeAlpha。每个 recipe 使用 id:brackets、version:1，不携带提案的长字段名。

宿主已采纳布局与造型独立、中心线内缩、镜像、半椭圆 / 四分之一椭圆、按组合限幅以及保留请求值。下列修正优先于本文件前面的设计建议：默认粗细继承现有工具，armX/armY 默认均为 24；radius 沿用箭头图元的实体轮廓圆角语义，不再只代表中心线转弯半径；完整宽高由宿主成样和 Canvas 手柄控制；极粗值在运行时限幅并提示，而非直接报错。本文件保留原提案作为对照，不据此推测其他宿主能力。

工程六个示例均显式保存原变体尺寸、颜色、粗细、透明度和臂长，因此不受新默认值影响。圆角对角示例仍传入 radius=18，但按宿主新的实体轮廓语义解释，其外观不宣称与原中心线圆角提案相同。其他示例 radius=0。未读取应用现有文件，未修改 Runtime、源码或测试；工程的实际打开、编辑和渲染效果由宿主独立检查。
