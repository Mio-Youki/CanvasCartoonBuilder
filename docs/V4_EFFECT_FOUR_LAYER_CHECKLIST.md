# V4 新效果四层落点清单

每新增一个可见效果，必须在开始实现前复制此清单到 PR、变更记录或该效果的设计文档；四项没有同时完成时，不能作为可用功能显示在 Inspector。

## 1. Registry：声明

- [ ] 稳定 `id`、中文名称、自然语言别名。
- [ ] 作用域：对象 / 场景；处理阶段；默认管线位置。
- [ ] 参数：默认值、范围、Step / Linear 属性、渐进显示条件。
- [ ] 成本等级与不适用场景。
- [ ] 是否允许粒子继承、蒙版、时序。

## 2. Inspector：编辑

- [ ] 使用共用颜色、纹理、蒙版或数值控件；不新建同义字段。
- [ ] 启用、禁用、删除与历史记录可逆。
- [ ] 首次启用即可显示参数，不依赖切换页面刷新。
- [ ] 参数名与 Registry 一致；单位、透明度、偏移采用既有产品语义。

## 3. Runtime：渲染

- [ ] 固定时间渲染、编辑器预览、导出使用同一实现。
- [ ] 声明阶段顺序与实际合成顺序一致。
- [ ] 蒙版、对象变换、透明度和混合方式行为明确。
- [ ] 高分辨率下有成本预算；必要时走 Draft / Auto 预览降级。

## 4. 测试：合同

- [ ] Registry / 参数边界测试。
- [ ] Inspector 写入与启用—禁用测试。
- [ ] Runtime 固定时间帧测试，至少包含默认态和一项极值。
- [ ] 浏览器流程测试；覆盖该效果首次启用、编辑、删除。
- [ ] 将此前发现的失败案例写成回归断言。

## 提交门槛

运行 `npm run verify:v4`。如效果引入新的视觉语义，还需添加对应的专门合同夹具，不能只依赖烟测。
