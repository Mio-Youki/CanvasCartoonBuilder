# v4 与 Legacy 体验等价审查

> 本文是差异盘点资料，不再承担迁移完成状态。权威状态见 [v4 Classic Shell 迁移总规范](V4_MIGRATION_MASTER_SPEC.md) 与 [机器迁移矩阵](V4_MIGRATION_MATRIX.json)。
>
> 基准：`img2asset-layout-v1.html` 的可观察操作结果，而非页面是否出现同名按钮。
>
> 结论（2026-09-21）：`img2asset-vnext.html` 是可运行的 v4 架构切片，尚不是 Legacy 的替代品。任何“已迁移”都必须同时满足数据、交互、跨面板联动、撤销、视觉反馈与预览性能六项。正式产品迁移不再以该页面持续补洞，而采用 [V4 Classic Shell 桥接协议](V4_CLASSIC_SHELL_MIGRATION.md)。

## 验收规则

| 等级 | 含义 |
|---|---|
| P0 | 缺失即不能作为日常编辑器使用；先迁移再添加新能力。 |
| P1 | 核心工作流完整后补齐。 |
| P2 | 保留为 v4 设计选择或等待 schema / Runtime。 |

## 逐区差异

| 区域 | Legacy 已有的实际行为 | v4 当前真实状态 | 差异 / 迁移任务 | 优先级 |
|---|---|---|---|---|
| 画布视口 | Alt 滚轮缩放、Shift/中键平移、重置后仍维持到下一次编辑 | 已有相同入口 | 原先每次 `render()` 会重新 fit，已改为共享 `EditorVNextViewport` 保持视口；仍需持久缩放语义与触控验收 | P0 |
| 画布选择 | z 命中、锁定过滤、图元/程序对象层级深入、Canvas↔树滚动定位 | 仅实体轴对齐包围盒命中 | 迁入带父级变换的命中、锁定与可视性；v4 当前没有 parts / 程序代码编辑，不伪装支持 | P0 |
| 直接变换 | 单/多选、组联合框、镜像、pivot、图元变换，手势只记一条历史 | Classic 候选已有单对象及多选联合框拖移/四角缩放/旋转/镜像、单对象 pivot 与组级 Canvas 变换；实验页仍仅保留基础切片 | 补嵌套组极端 TRS/剪切边界、图元直操与完整 Inspector 同步；继续采用 v4 手势事务 | P0 |
| 素材库 | 两列缩略卡、删除、添加按钮、拖入画布、单/多帧预处理 | 配方预处理、帧预览、拖放存在 | 页面重绘曾退回文本清单，现由素材 UX 统一接管；补回卡片“→”添加中央。逐素材再次编辑仍缺失 | P0 / P1 |
| 结构树 | 层级收纳、选择同步、重命名、锁定/独立/隐藏、指针调序、进入组/拖出组、图元和局部 FX 子项 | Classic 候选已有对象/组层级树、多选、展开/收起、重命名、编组/解组/删除、Pointer 前后/中央投放、锁/独/隐；独显为不写作品的预览态 | 补嵌套组与跨层调序全组合、拖拽临界区自动滚动、效果/图元树项；继续禁止 HTML5 原生拖放 | P0 / P1 |
| Inspector | 场景/对象/组/图元/粒子上下文、可复用颜色/纹理/蒙版、首次启用即渐进披露 | Classic 候选已有场景、对象、组和多选基础上下文；实验页另有成样/加样/采样卡片 | 基础字段已与树/Canvas/撤销同步；继续迁入动态、效果、时序、图元/粒子与共享颜色/纹理/蒙版，不能把实验页或 Legacy 参数表直接算作候选完成 | P0 |
| 时间轴 | Scene 段、边界编辑、上下文轨、显示时段、Step/Linear、播放头和 Inspector 严格同步 | 一条简化对象/效果轨 | 当前不是等价时间轴；先定义 v4 Scene 段 schema 或明确取消，再迁移交互。不得以视觉占位计为完成 | P0 |
| 历史/保存 | 一次手势一条撤销，打开/保存场景保持结果 | Mutation / Workspace 已具备 | 新迁控件必须只通过 `EditorVNextSceneMutation` 写入；每个 P0 操作补浏览器验收 | P0 |
| 导出 / 测试页 | JS、帧/GIF 和测试页 | 禁用 | v4 Artifact Builder 尚未完成；保持禁用是正确边界 | P2 |

## 迁移顺序

1. **先守住 v4 预览热路径**：满足 [性能合同](V4_PREVIEW_PERFORMANCE_CONTRACT.md) 的静态大图闸门；未达标时不继续迁入表面功能。
2. **复制 Legacy 体验壳，不复制 Legacy 数据**：从已验证的工具栏、视口、Canvas 辅助层与结构树行为开始，经 Facade 写 v4 Scene。
3. **编辑闭环**：变换命中与多选联合操作 → Inspector 上下文 → 一条完整可撤销链路。
4. **时间闭环**：先定义 v4 的 Scene 段 schema；随后迁移播放/切分/上下文轨，不复用 Legacy 存储格式。
5. **再扩展**：图元、粒子、复杂蒙版、效果容器、测试与导出。

## 不可直接迁移的部分

- 任意 Legacy `program.code`、专用绘制函数与其可编辑 parts；v4 可通过项目 Scene Module、普通对象、builtin、冻结素材或显式混合转换进入，但编辑器不会直接执行旧代码。
- Legacy `fx.layers` / `show` / Scene 数组格式；v4 必须用自己的 Registry 与 Timeline schema 表达。
- 任何“页面上有控件、但 Runtime 未声明支持”的能力。

## 每项完成定义

一项交互迁入前后，都要具备：

1. v4 Scene 的稳定持久字段；
2. Runtime 预览实际响应；
3. Canvas、结构树、Inspector、时间轴中所有相关入口一致；
4. 一次动作只有一条可撤销 Mutation；
5. 至少一个浏览器端连续操作验收，而不仅是源码字符串或纯状态测试。
