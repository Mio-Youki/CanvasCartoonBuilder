# G4：已注册图样的隔离Agent使用实验

## 范围与上下文

这是使用现有corner-arrows/v1的首轮可用性实验，不是从图像自动发明新配方、任意注册Inspector或内部Skill完成的证明。

执行者为无历史继承的子Agent。输入只有一条创作任务与最小场景／图样字段合同；没有编辑器源码、已有示例、测试、历史讨论或预期JSON。它未读取其他文件、未修改Runtime、未自行渲染。输出未经主Agent手工改写，保留在`examples/agent-pattern-g4/`。

本轮输入是文字，不包含用户参考截图。因此只验收意图与参数映射，不声称完成截图拟合，也不将这些产物当作创作质量的上限。

## 可复现任务

基础任务：720×420深灰背景，分别展示四角、三角形、五边形角点箭头；粗线、留白、尖尾、圆角0。矩形用独立custom；多边形应用同一角点规则。

修改任务：仅四角图样加长箭杆、粗细保持，改为固定方向、圆角3，其余对象不变。

合同提供format、实体与图元结构、坐标含义和corner-arrows/v1的8项几何参数及样式字段。明确未知配方不能自行发明；配方参数没有独立时间轨。

首次输出即通过结构验证，无人工修稿。修改版长度50→75、固定角0°、圆角3，宽度8及另两对象未变。真实浏览器从“打开场景”选择这两个JSON，验证实际画面不同、Inspector改值生效、撤销恢复画面、工程重开保留参数、自包含HTML能播放，无页面异常。入口测试通过模拟浏览器文件选择返回File，不绕过产品打开命令直接填工作区。

初轮主Agent看过画面，但未识别出固定方向破坏轴对称的问题，用户随后指出。该问题归属宿主参数设计，不是Agent文件语法错误；初轮“文件有效”不能视为视觉意图全部满足。Runtime现已修正固定角度为按角点镜像的倾角，原Agent产物不改写；下次复跑同一文件按新语义绘制。Agent原始说明中的“所有箭杆平行”保留为历史输入语义，后续输入合同不得再沿用。未做独立美术评分或参考图相似度评分。

## 发现与边界

当前合同足以让Agent使用一个已知图样并进行局部修改；没有出现无效暴露字段或静态图片替代。单次、小规模、字段充分提示的实验不证明任意自然语言请求都可靠，也不验证未知图样生成、Agent视觉迭代、内部创作面板接通或普适Skill质量。

后续分开验证：①同一能力面对更少字段提示与图片参考；②未注册图样先交付受限几何／参数提案，经宿主审核后实现，不允许场景文件注入任意绘制／面板代码。螺旋和通用配方执行器仍在G4未交付范围。

回归入口：`tools/tests/browser/v4-agent-pattern-g4.mjs`；纳入根目录`node scripts/verify-v4.mjs`。本轮仅跑定向门禁，没有运行全量verify-v4、打包Tauri或提交Git。
