## 顺序与蒙版合同

生产场景仍为 overlay → sample；本轮 sample 白名单是采样格、阈值分色、不均采样，其他启用效果仍在上传／分配前触发整条 CPU 场景链回退。

实际 CPU 每卡各自执行：缩小至采样尺寸 → 该卡处理 → 放大 → 合成该卡范围。两卡不能简单融合成“只缩小一次、在低分辨率处理全部效果、最后套一次蒙版”。GPU 因此采用：

```text
Canvas 来源 → 首次缩小／上传
  → 阈值 → 放大与阈值蒙版合成 → 全尺寸中间纹理
  → GPU 再缩小 → 不均采样 → 放大与不均采样蒙版合成
  → 最终 Canvas 输出或 GPU 转场纹理
```

两卡顺序固定，不取决于 JSON 键插入次序；不同范围不会合并或互相覆盖。中间没有 GPU→Canvas→GPU 往返。矩形、椭圆、Alpha／明度 Alpha、元素引用及反相仍由正式 resolver 生成范围。非白名单例如染色叠加仍完整 CPU 回退，不偷偷局部绕过。

资源：单卡四张纹理／两道，双卡惰性增加一张全尺寸中间纹理，共五张／五道（两卡之间另有一次缩小）。GPU 双场景最终转场共七张／十一道；两个范围的双侧合计上传八次。中间纹理在同尺寸重复播放中复用，关闭卡片后可保留至清缓存／释放。当前仅最多两卡，后续第三卡必须实现明确 ping-pong，不能将同一纹理同时作读写目标。

## 精度问题与修正

### 奇偶尺寸最近邻

333×187 等尺寸下，GPU 从底部计数时，居中采样恰好落在相邻 texel 分界，Y 方向可能选择 Canvas 的另一侧。一般照片只出现很小平均误差，阈值双色会将它放大成少数整色错点。修正为按左上角坐标显式计算最近邻 texel；放大与卡间缩小均统一，原不均采样路径也使用此取整。Step 改尺寸／改阈值再 seek 回原段的本组对照逐像素一致。

### CPU double 的临界判定

GPU 浮点亮度比较也可能在临界处换色。先按 8-bit RGB 重建，使用整数权重 2126／7152／722 判定；但不能只将数学公式整数化，CPU JS double 在部分恰好相等的灰／彩色组合上仍有向下舍入。

为不改 CPU 基线，预检只枚举该阈值恰好相等的有限颜色，记录 CPU 判为暗色的例外。通过每个红色字节至多一个临界组合的关系，打包为约1KB uniform 表，GPU 常数次查表，不逐像素扫描列表；共享纯数值缓存最多16项，不保留素材／场景引用。测试用独立的 R/G 双层穷举验证此表，不使用 Runtime 自身枚举过程作为参考。

灰阶 0–255、八个阈值以及六个阈值的全部精确彩色临界组合在本组均逐像素一致。沿用 CPU 现有参数解析和零值回退，不在实验 GPU 中悄悄重定义参数。

### 透明最终转场

逐卡／范围组合对照：照片24组平均 RGB 误差最大0.2364/255，Alpha为0，预乘通道最大差2/255；Alpha／明度／引用范围另三组平均 RGB 最大0.3059/255、平均 Alpha 最大0.0241/255。测试限制预乘最大差≤3，防止用平均值掩盖二值整色错点。

GPU 最终 fade 的一组平均 Alpha 差为0.604/255，但每像素最大差仅1/255、预乘通道最大差2/255；将**同样的 GPU 两卡结果改用 Canvas 最终合成**后，Alpha差回到0。该差属于最终合成减少中间量化，不是阈值处理新增 Alpha 丢失。转场单独按最大 Alpha≤1、预乘最大差≤3验证，不放宽普通卡片的平均 Alpha 限制。

## 真实 Player 首轮预算

```text
node tools/tests/browser/v4-gpu-player-threshold.mjs --write-report
node tools/tests/browser/v4-gpu-player-performance.mjs --with-threshold --frame-end-validation --write-report
```

Intel UHD620／Edge／ANGLE D3D11，每组预热8帧、记录64帧，640×360与1920×1080。不是完整编辑器／Tauri，也不是设备覆盖或长稳结论。下面为1080p **阈值＋不均采样**，带范围时每卡采用不同范围，单位ms：

| 工作负载 | CPU 完整调用 P95 | GPU 完整调用 P95 | GPU RAF 参数间隔 P95 |
|---|---:|---:|---:|
| 单 Scene，无范围 | 103.4 | 6.5 | 16.7 |
| 单 Scene，两卡范围 | 117.7 | 20.0 | 16.9 |
| 双 Scene，两卡范围＋GPU fade | 232.9 | 32.3 | 33.5 |

本组不透明最终画面最大平均RGB误差0.007/255、Alpha差0。GPU纹理单Scene约25.49MiB，双Scene约41.31MiB；播放中零新增纹理／backing尺寸重设，一个GPU上下文。最大调用／参数间隔仍有离群值，不宣称稳定60fps或无掉帧30fps。RAF参数间隔与回调实际到达／屏幕呈现不是同一概念，解释沿用[交错连续验收](V4_GPU_INTERLEAVED_PLAYBACK_2026-10-15.md)。
