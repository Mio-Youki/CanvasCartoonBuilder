# 基础算子覆盖审计与后续批次建议

日期：2026-10-25。性质：源码与既有证据审计、计划建议；未实施新算子框架，未改变Inspector、项目JSON或默认后端。并行会话仍可能更新源码，本审计不等于重新验收所有产品功能。

## 1. 结论与计划调整

当前Registry声明18项效果、1个采样控制器、19种运动声明、4条效果级配方；此外还有路径、附着图样、文字、粒子和程序构件模块。这足以覆盖一批轻量2D和采样创作，但不等于拥有完备且可自动组合的基础算子库。

后续应调整验收单位和执行顺序：先在现有Registry／执行器内建立最小可执行配方，将已验证内核变为有合同的节点，再扩大采样格与效果覆盖。保留画面语义、轻量运行、CPU回退、导出／Tauri一致性这些原目标。不另建一套效果目录，不重写编辑器，不为此先建节点编辑器，也不马上开发通用Shader编译器。

## 2. 证据等级

- E：有当前源码／声明，不据此认定全部工作流或后端已验收。
- V：限定实现与场景已有GPU画质／生命周期证据，可作为已验证内核提取。
- P：有独立GPU实现或原型证据，未等同共享执行器支持。
- G：未发现作为通用公开模块的能力；专用效果内部的相似计算不算通用实现。

“V”不是任意参数、任意组合、跨设备、导出和Tauri全部成功。内核提取成算子时仍须保持原有数值、坐标和Alpha合同，进行适配回归，而非重新证明每条数学公式。

## 3. 已验证内核可以沉淀哪些基础能力

| 候选算子／公共能力 | 现有证据与实际范围 | 尚未完成 |
| --- | --- | --- |
| 最近邻缩小／放大、坐标寻址 | V：69a／69c；场景非整除尺寸和本机Canvas坐标校准；对象试点格1 | 对象格>1、任意坐标变换、跨设备 |
| 预乘Alpha编码、字节舍入与输出 | V：透明输入／阈值／杂色／色散整链；69a的共用表与Shader前导 | 通用颜色空间和所有混合模式，不可称完整颜色管理 |
| 亮度判定＋二选一映射 | V：threshold，临界值和限定动态／时序 | 抽成可调用节点；不等同自动提色／最近色映射 |
| 确定性随机字节＋加性杂色 | V：noise-dither；mono／RGB、时间、seed、Step／seek | 通用连续2D/3D/4D噪声场不是同一算法 |
| 邻域Alpha／亮度判定＋通道偏移 | V：edge-dispersion三种来源及组合 | 通用卷积、距离场、任意位移图尚非该内核 |
| 波／径向／受限整数噪声场＋自适应采样 | V：scene uneven GPU；CPU场另在67 | 对象路由、通用场输出接口、边缘保护的GPU实现 |
| 染色＋部分混合 | V：scene tint指定混合、Alpha与透明测试 | 完整12种混合／Hard Mix；对象共享路由 |
| 范围蒙版混合、双源转场 | V：场景限定蒙版与两侧动态转场实验／Player | 蒙版本身仍CPU生成；全部对象、转场和新蒙版语义未由此验收 |
| 设备、ping-pong表面、整链回退、释放 | V：Batch1～14针对性证据 | 多GPU对象、对象＋场景共用设备链、长时及跨设备 |

第14批正式编辑器新增33组（另保留27组前处理）不能被简化为“所有基础算子已成功”。其价值是提供可保留的回归资产和可提取实现：[第14批](V4_GPU_INFRA_BATCH14_2026-10-25.md)。

## 4. 当前效果到算子族的映射

| 当前效果 | 需要的基础能力 | 当前共享GPU状态 |
| --- | --- | --- |
| 投影 | Alpha提取、位移、着色、前后合成 | CPU前处理可与GPU末端采样组合；投影本身未GPU化 |
| 描边 | Alpha膨胀、差集、着色、合成 | 同上；CPU是有上限的采样扩张，不冒称精确距离场 |
| 染色叠加 | 单色生成、Alpha约束、混合 | 场景部分模式V；对象仍未接 |
| 纹理叠加 | 图案／tile、坐标平铺、Alpha约束、混合 | CPU E；共享GPU未接 |
| 内光效／外光效 | Alpha膨胀／腐蚀／差集、分层衰减、混合 | CPU E；不是通用高斯模糊 |
| 颗粒叠加 | 有种子的颗粒生成、刷新、混合 | CPU缓存E；不是加性杂色同一语义 |
| 调色四轴 | RGB／亮度变换、色相／饱和度计算 | CPU E；共享GPU没有完整四轴路由 |
| 颜色映射 | 最近色、提色、LUT；新增亮度渐变映射分支 | CPU E；有GPU实验，未接共享执行器 |
| 杂色抖动 | 有种子随机字节、RGB加性扰动 | 对象／场景V，范围见合同 |
| 阈值分色 | 亮度、阈值、色值选择 | 对象／场景V |
| 边缘色散 | 邻域检测、通道取样与混合 | 对象／场景V |
| ASCII映射 | 单元统计、边缘方向、字形图集、着色 | 独立CPU／可选GPU路径P，不是共享链通用算子 |
| CRT显示 | UV弯曲、通道位移、扫描／波纹、邻域与亮度调制 | 独立GPU路径P，不等于通用UV／模糊算子 |
| 偏移采样 | 随机选格、位移、条带复制、边缘约束 | CPU E；共享GPU未接 |
| 网点映射 | 单元取色／亮度、图样生成、网格与Alpha规则 | CPU E、GPU原型P；尚未接共享链 |
| 不均采样 | 标量场、局部格尺寸、取样、边缘保护 | 场景部分V；对象和GPU边缘保护未接 |
| 蒙版暗角 | 蒙版／空间衰减场、着色、混合 | CPU E；共享GPU未接 |

采样控制器、渐变填充、路径描线和成样变换不应被漏掉，因为它们不是上述18张效果卡。参见`55-pattern-field`、`58-paint`、`59a～59m`、`29-motion`、`30-frame-state`及`49～51`蒙版模块。

## 5. 与Remotion基础能力的对照与补缺

Remotion依赖浏览器并提供可组合组件；它不是一份能被我们直接逐项复制的“完整算子标准”。当前官方已提供Canvas effects数组和`createEffect()`，不是只有DOM/CSS。`createEffect`支持backend、setup/apply/cleanup、calculateKey、参数schema／校验；相邻同后端分组。它仍需开发者指定2d／webgl2／webgpu，并不把任意JS算法自动转换成GPU。

| 基础族 | ToSampool现有能力 | 真正的补缺／产品建议 |
| --- | --- | --- |
| 时间与数值调制 | No／Step／Linear，clock／ease／oscillate／progress／advance／refresh；基础变换与19种运动声明 | 将同一时间值绑定到任意配方参数；通用Bezier／spring未发现，后补而非重写时序 |
| 2D变换与内容 | 仿射矩阵、层级、旋转中心、图片／序列／文字／图元／程序源 | 暂不必GPU重写文字或程序；明确内容刷新与变换刷新分离 |
| 颜色传递 | 四轴、阈值、最近色、亮度渐变LUT、线性／径向空间渐变 | 统一point-map／ramp／palette接口；曲线、levels／gamma、3D LUT未形成通用模块 |
| 合成与蒙版 | 12种常规混合、特定Hard Mix；静态／Alpha／元素蒙版 | 统一GPU合成、Alpha／luma通道与端口合同；新蒙版模块仍由其专项验收 |
| 图案与随机场 | tile／线／网格／点／自定义纹理、seed刷新、波／径向／分块hash | 统一场输入与输出；平滑噪声／向量位移场是缺口，不能把hash当成所有噪声 |
| 位移与几何映射 | 偏移、沸腾、像素呼吸、条带；CRT专用UV弯曲；水平／垂直斜切 | 通用UV remap／位移图缺口；四角透视未发现，斜切不能替代corner pin |
| 邻域与轮廓 | 色散邻域、CPU轮廓扩张／腐蚀、CPU边缘距离；ASCII内部DoG模糊 | 通用模糊／卷积／形态学算子未形成；优先简单可控模糊与Alpha形态，不急做镜头散景 |
| 路径 | 描线显现／裁段、平滑、圆角、波形、虚线、端点及实例／附着图样 | 通用路径形态插值未发现；已有能力先复用，不把所有路径工作迁GPU |
| 时间累积 | 周期、粒子与序列，不等同历史帧累积 | 拖尾／运动模糊缺口；需seek可重建、显存有界，后置 |
| 媒体与排版 | 图像序列、位图文字；程序源可扩展 | 原生视频／音频时钟、DOM富排版不是当前通用能力；偏产品范围，不是GPU收口前置条件 |

不能为了与Remotion数量一致而添加全部效果。对于轻量采样创作，首要缺口是**颜色传递、空间场／位移、图案、合成、邻域**这些可重组模块及统一合同；视频剪辑、完整3D、光学镜头效果和复杂排版可后置。

## 6. 建议替代后续按效果逐项扩白名单的步骤

| 建议阶段 | 交付／验收门槛 |
| --- | --- |
| A 最小算子合同与清单 | 端口、颜色／Alpha、坐标空间／单位、边界、时间／seed、缓存依赖、成本、后端与回退；标明E/V/P/G |
| B 提取已验证内核 | 以杂色／阈值／色散及公共取样／Alpha为首组，已有项目和固定画面对照不变；保留所有测试资产 |
| C 配方解析与能力推导 | Registry效果映射到节点；组合已有节点无需新增effect-ID GPU白名单或Shader；新配方自动做类型／预算检查及小规模画面smoke |
| D 扩采样与补高收益族 | 对象格>1；颜色传递、图案、合成、位移、形态学逐族落地；只为真正新算法做新增后端实现 |
| E 完整宿主与交付 | 多对象／尺寸／动态、冷启动、对象＋场景、蒙版／转场，最后导出／Tauri／跨设备与默认Auto决策 |

当前整链CPU回退策略继续保留。不因Remotion支持相邻后端分组，就未经测量改为逐卡CPU/GPU往返。不要一开始融合全部Shader：先复用已验证多pass，保留数值和顺序；只有证明中间量不影响结果且有收益时才融合。

Agent常规创作不运行全部后端认证。它优先组合现有节点、生成易懂参数和预览；真正新算法保留受信CPU-only／宿主扩展通道，不以有限节点库禁止创作，也不自动获得GPU支持。
