# P5首例：双色放射提案与参数时序合同

状态：交互预览待用户视觉确认。通用时序求值门控、声明式图样参数的正式编辑入口及测试已接通；双色放射尚未注册到产品、没有可导入的正式图样包，没有发布共享。

后续更新：预览已改为默认可修订，无模式切换和下载按钮。旧文中提案下载／模板按钮描述为首轮历史，当前以[审阅页V2](EFFECT_REVIEW_V2_2026-10-23.md)为准；原时序与候选未发布的边界不变。

## 提案四项

1. 建议命名：**双色放射**。名称是可编辑展示元数据，不作为引用ID。
2. 载体：矩形、椭圆、正多边形、自由多边形的闭合路径。开放直线／笔触不伪装支持。预览展示这四类，后续注册必须读取真实宿主路径，不能只拿宿主bounding box代替其轮廓。
3. 参数：色块对数；颜色一／二及各自透明度；中心X/Y（归一化，可在载体之外）；起始角度；色块占比；动态旋转开关及周期时间／方向。默认12对，米灰双色，参考构图中心(0.62,0.58)。内部扇区旋转，载体边界与选择框不旋转。
4. 交互预览：`examples/pattern-proposals/dual-ray/preview.html`。控制区由参数声明生成，支持播放／暂停、四种载体、两个构图入口、可选三段时序试验、960或1920宽度及提案参数下载。生成逻辑仅一份`candidate.js`，未来接入时审阅复用，不另写一套相似但不同的绘制。

本轮只提取参考图中米灰放射背景，不复现文字、标志或人物。候选不是图像生成结果，不包含原图资产。

## 参数能力

新参数明确声明`timing: No | Step | Linear`。Linear包含Step能力，No不仅是禁用按钮，求值器也过滤非法覆层。旧声明式图样省略此字段视为No，不借本次修改整体开放旧图样时序。现有注册表的`step/linear-safe`可通过同一能力适配器读取，未全量重写加样／采样面板。

| 双色放射候选参数 | 声明 |
| --- | --- |
| 载体类型 | No |
| 色块对数（整数） | Step |
| 两色与透明度、中心X/Y、占比 | Linear |
| 起始角度 | Linear；`interpolation: angle-direct`，直接数值插值，可表达超过一圈，不擅自改为最短路径 |
| 动态开关、周期时间、方向 | Step |

颜色以现有RGB通道插值、透明度独立数值插值，不声明感知均匀插值。整数、开关、选项不得声明Linear。动态使用绝对播放时间，不以切段为零点重启；周期／方向发生Step变化时可能跳变，不假装已经提供相位连续变速。

候选的颜色能力已在通用核与交互预览验证，但当前v1线性路径模板仍不具备双色扇区生成能力。它不能仅改后缀就导入编辑器。用户确认后需要审阅受预算约束的角向重复／双色绘制能力及其正式载体接线，不开放任意JS自动导入。

## 三段审阅模板

- 默认普通参数＋旋转播放；打开时序试验后显示等分的起始／变化／目标三段。
- 起始段编辑基础值；目标段为每个参数点击◷后设置目标，未参与参数继承基础值；No按钮禁用。
- 中段“过渡”仅插值Linear参数，Step保持前值直到目标段；“保持”不做插值。
- 中段参数只读并显示当前求值结果。清除参数的◷即清除本次目标，不残留覆层。
- 全部参数共用这三个分段，不为每个参数生成一条轨道。
- 页面的“下载提案参数”输出`tosampool-pattern-proposal/v1`，不是安装包。该页不写当前编辑工程、IndexedDB共享库或正式登记表。

模板分为`editor/pattern-review-workbench.js/.css`与候选生成逻辑，可供后续加样／采样审阅复用；不意味着这些生产面板本轮已全部改造。

## 正式Runtime与编辑器落点

- `runtime-src/vnext/21-parameter-timing.js`负责能力校验、稀疏覆层过滤与三段构建，最终调用原`timeline.applyValues`，没有第二套预览插值公式。
- `timeline.valuesFor`针对具有声明的图样参数接入门控；稳定`partsById`与数组索引写法均不能绕过No。保留其他对象属性原有规则。过滤结果按不可变轨道／定义引用缓存，不在每帧序列化定义。
- 受限路径模板可选声明参数timing/interpolation；未声明仍No。改变已发布定义内容须提升版本，原有同版本冲突保护不变。
- Inspector仅为已声明的Step/Linear模板参数增加◷。写入所属对象原轨道的`partsById.<encoded-id>.recipe.params.<key>`；No仍修改基础值，无时序图标。过渡段只读，在两侧Step段设置端点。
- 稀疏值只包含参与参数；清除一个参数不删除其他参数。声明Linear的参数加入原对象轨道的可过渡白名单，没有图样独立轨道。
- 分发Runtime与内联导出镜像均重建；浏览器夹具验证正式编辑器改变实际几何，并验证内嵌HTML使用同一门控。

## 证据、性能与边界

- `tests/v4-parameter-timing-contract.mjs`：No、Step、Linear、颜色、三段边界、清除继承、类型限制、稳定图元ID与数组索引防绕过、缓存、基础值不变。
- `tests/browser/v4-pattern-proposal-timing.mjs`：四载体、真实参数输入、三段控制、旋转闭环、外部透明、正式Inspector写入与正式帧求值／绘制、HTML导出一致，且候选未出现在产品登记。
- 默认12对、预热30帧后各150次绘制命令提交测量，960×540及1920×1080均在约0.2～0.4ms P95范围内；详见`tests/artifacts/p5-dual-ray/performance.json`。**这是命令提交时间，不是GPU完成／整页帧耗时**，不承诺所有极值和设备相同。预览的滚动指标包含预热样本，可能明显高于该批量测量。
- 已查看默认预览截图；没有独立视觉评分。浏览器静态服务首次尝试失败（单文件服务范围／沙箱连接隔离），改为宿主只读本机服务。截图检查仅有无关favicon 404，不因此调整项目配置。
- 本轮是主Agent制作候选，不是隔离子Agent的盲测，不作为已完成Skill质量提升的证据。阶段耗时见同目录执行记录。
- 未做全量verify-v4、Tauri封装、所有效果组合及长时显示合成性能验收。
