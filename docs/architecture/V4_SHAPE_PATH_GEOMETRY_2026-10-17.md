# 图元路径：完成度、正多边形圆角、中心展开与静态波形

## 四层落点

本次属于基础图元能力，不新增效果卡／EFFECT_REGISTRY ID。原有Paint、图元字段和所属对象轨即数据落点，不能为每个图元注册额外效果轨或给参数临时起实例别名。

| 落点 | 文件／职责 |
| --- | --- |
| 数据合同 | vnext-parts-state的APPEARANCE与normalizePart；原生矩形／椭圆／直线／多边形同名字段。VNEXT_SCENE_CONTRACT补充当前约定。 |
| Inspector／工具 | classic-v4-stroke-style-control共用表单与normalize；drawing-controller接入正多边形拖拽、预览和提交；Inspector自动加入所属对象Linear键。 |
| Runtime | 59a-path-stroke保留既有笔触；新增59b-path-geometry负责封闭轮廓、弧长显现、圆角、波形与填充裁切，60-content-renderer消费；构建和内联同步。 |
| 测试 | v4-shape-path-geometry加入verify-v4，连同既有path-stroke／stroke-reveal回归。 |

## 参数合同

| 字段 | UI／默认 | 范围与时序 |
| --- | --- | --- |
| strokeCompletion | 完成度／100 | 0～100，Step／Linear，按描线弧长，不代表填充面积比例 |
| pathStart | 起始位置／0 | 封闭图形0～1周长归一化；0=1，Step |
| strokeReverse | 反向绘制／false | Step；笔触保留原后缀显现和虚线相位的既有逻辑 |
| fillReveal | 填充显现／none | none=保持完整，center=中心展开；Step；自由多边形不开放center。仅控制完成度，不是波形跟随开关 |
| polygonMode | 多边形类型／free | free=自由多边形，regular=正多边形；Step |
| sides | 边数／3 | regular时显示，整数3～64，Step |
| radius | 圆角／0 | 正多边形显示，局部长度、非负；有效倒角受相邻边约束；Step |
| strokeWave.enabled | 路径波形／false | 封闭图形无描线也可见；开放路径需启用描线。Step，不新增自动运动入口 |
| strokeWave.amplitude | 幅度／2 | 非负局部长度，Step |
| strokeWave.wavelength | 波长／16 | 最小0.5，局部长度，Step；闭合时就近匹配整数周期 |
| strokeWave.phase | 起始相位／0 | 0～1，Step |
| strokeWave.fixEnds | 固定端点／true | 仅开放路径显示；使用两端为零的平滑包络，Step |

所有图元完成度都写入所属对象轨的`partsById.<编码ID>.strokeCompletion`，不新增图元轨。原生图形对象直接使用strokeCompletion。其余新增字段Step，特别是正多边形边数和路径方向不做数值Linear。

## 默认起点与方向

- 矩形／圆角矩形：顶部中点；椭圆：最高点。
- 正多边形：顶部顶点，倒圆后为该圆角最高处；自由多边形：第一个原始顶点。
- 默认顺时针；直线／笔触沿原始首点。完成度变化不裁小原始路径或选择框。
- 正多边形由外接椭圆中的等角顶点生成，可随宽高非等比拉伸。三角／五边／六边为同一poly类型的快捷选项，不新增Runtime实体类型。
- 正多边形转自由多边形时，将当前边数生成的顶点存入points；不会回到创建时旧顶点。自由多边形圆角尚未开放，半径不作用于其凹角。

## 填充与描线分开

默认完成度只影响描线；没有描线时仅调整完成度不会隐藏填充。开启中心展开后，以原图形框中心连接路径显现部分形成裁切区域，同时与原填充轮廓相交；纯色、渐变、纹理一起被裁切。径向边界不描线。0无填充，100完整填充；周长比例不保证面积匀速。

矩形、椭圆、正多边形可用；自由凹多边形不展示入口，即使外部数据写center仍按保持完整处理，不伪装支持。未来需要凹图形方案时应另立合同。

## 路径波形与预算

2026-10-18扩展为六种波形节奏、数字周期与平滑随机，字段、法线处理与新增缓存见[V4_PATH_WAVE_RHYTHMS_2026-10-18.md](V4_PATH_WAVE_RHYTHMS_2026-10-18.md)。

开放路径变形描线；封闭路径开启波形后，填充和描线默认使用同一波形边界，不保留单独的波形“填充跟随”开关。纯色、渐变、纹理及中心展开共用该边界，关闭波形恢复原形。沿完整路径取样，再按法线施加正弦偏移；闭合路径匹配整数周期并将首尾点对齐。折角附近仍可能有明显转折，配合圆角更连续，不声称一般曲线的C1连续。

封闭且无描线的填充图形也显示波形入口。填充采用Canvas默认nonzero规则，自交产生的区域按该规则处理；命中检测同步采用非零绕组判断，不用旧矩形／椭圆轮廓代替。离屏范围沿用完整波形的视觉边界，完成度仍不缩小选框。填充时不对同一边界重复clip＋fill，避免抗锯齿Alpha被二次削弱。

填充随波形调整后，定向夹具逐像素比较了矩形／椭圆／正多边形的波形填充与直接路径填充；渐变同Alpha、纹理不越界、中心展开、对象与图元命中以及进入加样胶囊不裁边均通过。沿用现有绘制／裁切，不增加像素读写或新离屏层。

封闭基础几何、原描线及波形派生结果采用最多64项LRU缓存；源坐标不修改，复制笔触点避免缓存与原始数组共用可变存储。长度表复用既有WeakMap；仅完成度变化时不重新生成完整波形。波形最多8192段／8193点，极短波长和极长路径可能降采样，非无限精度承诺。没有像素读取、逐像素滤镜或额外GPU依赖。

不启用新能力的实线图形保留原绘制快路。封闭虚线统一经过规范起点的路径，避免从99%到100%时突然回到旧原生路径起点；已有笔触的虚线／反向逻辑保留。
