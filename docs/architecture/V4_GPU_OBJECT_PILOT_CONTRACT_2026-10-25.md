# 显式对象采样 GPU 试点合同

日期：2026-10-25；状态：experimental。不是默认渲染器，不替代场景后处理合同。

第13批补充：在CPU稳定性修复后，已验收Canvas投影／描边前处理＋GPU阈值的限定组合，见 [验收记录](V4_GPU_INFRA_BATCH13_2026-10-25.md)。这不代表投影／描边获得GPU实现。

第14批扩展为杂色抖动／阈值／边缘色散的限定完整采样链。见 [最新记录](V4_GPU_INFRA_BATCH14_2026-10-25.md)。下述条件只适用于显式实验预览，不代表默认、导出或Tauri已启用。

## 宿主入口与所有权

- 编辑器预览后端第三项“对象采样试点”：`sceneBackend:'cpu'`＋`objectBackend:'gpu-threshold-pilot'`。后一个内部请求token保留原名以保持宿主接口稳定，不表示实际只处理阈值；不写入作品JSON。
- 原“实验GPU（场景）”只请求场景GPU，未自动扩展为对象GPU。
- 作品JSON不包含后端选择；Inspector、时序与效果参数没有新增GPU专用配置。
- Workspace惰性持有对象会话，借给逐次重建的Player；普通同尺寸编辑保留设备，但不保留来源输出缓存。根尺寸、素材描述、replace／撤销／重做、显式releasePlayer／dispose与策略切换均释放。
- 直接Runtime调用默认由Player持有；显式借入`_objectGpuSession`时由宿主负责释放。临时Player也须dispose。

## 数据与路径

```text
同一frame：对象／效果／控制器按统一声明求值
→ 原Canvas内容与蒙版（保持世界胶囊边界）
→ 整条采样预检
→ 合格时：一个来源上传 → 现有杂色／阈值／色散内核与GPU中间表面 → 一次Canvas胶囊输出
→ 不合格／设备失败：完整原CPU采样链
→ 原有对象Alpha×父Alpha、混合、图层合成
```

`sceneGpu.renderEvaluatedSample`是现有执行器的窄适配接口，不复制Shader：接受已求值采样组，无卡内范围蒙版；不读取场景时序，不保留来源版本缓存或转场slot。对象会话先对白名单完整预检，原执行器再检查具体参数条件，任一失败整链回退。`69d-object-gpu-pilot.js`负责对象语义和预算，不是另一份效果目录。

## 初始准入与预算

以实际世界胶囊而非元素W/H计算。常量唯一来源为`api.modules.objectGpu.budget`，Registry声明与诊断查询它。

| 项目 | 本次范围 |
| --- | --- |
| 效果 | noise-dither／threshold／edge-dispersion的非空子集，固定按CPU内部顺序执行，不按JSON插入顺序 |
| 顺序 | sample必须最后；其他顺序完整CPU，不重排 |
| 采样 | 有效格=持久格×预览预算=1，Alpha keep |
| 前处理 | 允许原Canvas投影／描边（含两者组合）；其他激活加样、非零调色仍回退；对象蒙版沿用CPU |
| 载体 | image／vector／rect／ellipse／poly；程序、文字、粒子暂不准入 |
| 胶囊面积 | 131072～1048576像素 |
| 单边 | 不超过4096；设备真实上限可进一步回退 |
| 显式纹理预算 | 不超过24MiB估算；不含Canvas／驱动隐式内存 |
| 每帧 | 按实际绘制顺序第一个合格对象，最多1次GPU尝试；与Inspector选中态无关 |
| 暂不支持 | 重复滚动、包含任意入口转场的项目、场景GPU同时请求、paletteCapture |

这些是可撤销的宿主实验策略，不缩小产品输入范围。小对象避免上传与同步开销；上限覆盖已测大对象量级；最多一个避免多尺寸来回切换。不能视为跨设备最优阈值。原CPU前处理稳定性问题已修，见`V4_GPU_OBJECT_PREFIX_BLOCKER_2026-10-25.md`；扩大准入只限已有专项证据的投影／描边，不扩展到所有加样。

第14批预算估算：单效果每像素16字节，多效果24字节，再预留524288＋96×胶囊宽度字节用于有界数值表。它覆盖当前执行器的两个中间结果及RGB跳跃表等，不是总进程内存；实际活动纹理仍以执行器统计为准。组合可能在面积上限前触及内存预算并回退。

## 诊断

- `sceneBackend`保持场景实际后端，不因对象试点而改成gpu。
- `objectBackend`仅在实际成功时为`gpu-object-sampling`；请求token与实际结果分开。
- `objectGpu`返回实际handled／cpu／attempted、来源像素、上传／处理遍数、当前GL资源、设备／表面初始化、预算及最多24条对象ID／实际effects／世界bounds／原因；更多条目计入truncated。对象行成功后端为gpu-object-sampling，不能继续称为gpu-threshold。
- 预算拒绝归为host-budget，可下帧重评；设备失败保持执行器原有故障状态，显式释放后可重试。
- 来源每次上传，CPU和GPU都消费已经求值的参数；没有第二套Step／Linear、颜色或动态公式。
- 内容绘制、蒙版、最终透明度／混合仍为Canvas路径；不能称为整个对象或图样生成器已由GPU绘制。

## 验收边界

`verify:gpu-object-pilot`为定向入口。真实编辑器测试包含输入位移、撤销／重做、边界预算、图元扩展、蒙版、父组透明度／multiply、对象效果Step、位置／旋转Linear与seek、无WebGL、上下文丢失、绘制失败、当前项目释放。

第13批真实编辑器另验收投影／描边、包含投影的描边、宽描边、蒙版与加样互换、父组透明度、混合、旋转／斜切，以及加样前处理＋阈值Step和对象Linear。GPU只处理末端阈值；其他CPU前处理和最终对象合成仍存在成本。

独立原型的大范围通过不能扩大此生产试点准入。更多采样效果、采样格>1、其他加样前处理、纹理、文字、程序构件、多GPU对象、粒子、过渡、对象与场景GPU共用一条设备管线、导出、Tauri、跨设备均尚未完成。

参数／样式会话无需更改控件：仅保留舞台`preview-backend`的三个值及现有诊断状态，不能把试点选择写入作品或改为默认。
