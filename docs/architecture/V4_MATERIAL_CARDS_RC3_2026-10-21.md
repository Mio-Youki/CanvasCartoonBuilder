# RC3：元素卡统一及单向共享

日期：2026-10-21。存量流程整理，沿用现有编辑器视觉；不是新皮肤或素材架构重写。

## 用户结果

- 素材导入图标同时接收图片和资源 JSON。多张图片仍一起交给原序列预处理，不拆成逐张导入。
- 资源包的 **Module 根**转为普通元素素材预设，使用 Manifest 默认参数和建议尺寸，保持现有不超过画布2/3的初始尺寸规则。不增加画布对象。
- 同一默认预设重复导入复用已有定义；被修改过的预设不被默认值覆盖。元素包内仅作为依赖的 Module 不额外建卡。
- 独立“程序构件”栏已移除。实现仍留在工程依赖图中；不是删源码，也不是把程序烘焙成图片。
- 卡片以图标呈现：左上♡发布共享，发布后♥只负责更新共享；右上×移出，右下→加入画布；位图／序列左下α保留修边。
- 项目卡不再提供取消共享；只能在共享页通过×移出，确认与不连带删除语义不变。
- 位图／序列点击名称或空白只选择；已选中时点击预览才打开预处理。元素卡不会进入位图编辑。
- 图标固定可见，不以悬停作为可点击的前置条件；操作不挤动预览及名称。键盘焦点、可访问名称和原按压反馈保留。

## 四层落点

| 层 | 修改与边界 |
| --- | --- |
| 合同／状态 | `v4-element-presets.fromModule`：仅从声明生成现有格式预设，不执行源码，不新增Scene字段；同一次资源导入历史包含定义及预设 |
| Inspector／界面 | 原Inspector不变；素材控制器、共享控制器和图片卡点击规则调整；独立构件栏删去，不隐藏另一份可交互状态 |
| Runtime | 绘制算法不变。导入授权仍经原ModuleLoader；获准后的卡片预览和放置可延迟加载，不再次询问 |
| 测试 | 生命周期合同、项目素材面板、共享、上下文入口及构件烘焙浏览器回归；真实点击，不以DOM存在替代可用性 |

## 验证及取舍

合同验证包含默认参数、缩放、重复导入复用、无画布实例和不执行源码。浏览器验证包含取消后重新选同一文件、拒绝不写入、元素卡重复放置无新提示、名称不误开编辑、预览编辑与取消、共享更新及移除、图样入口、工程切换、冻结与序列烘焙回归。

实际画面：`tests/artifacts/rc3-material-cards/page.png`，1440×1000。已人工查看，图标位于预览四角，名称和类别保留；无独立视觉评分或评审。截图工具报告favicon 404，不影响本次功能。此前分散的共享复选框／文字加入按钮已删除，不增加新的常驻说明文案。

没有运行全量verify-v4／Tauri／性能压力测试，不声称这些已验收。共享状态按卡片缓存，同一轮投影只遍历一次共享相关指纹；未改逐帧Runtime。
