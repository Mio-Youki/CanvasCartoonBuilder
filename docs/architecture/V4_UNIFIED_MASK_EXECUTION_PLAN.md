## 每批四层落点

1. 定义：统一mask schema、默认值、能力与引用依赖。
2. Inspector：共用来源／提取／坐标／图形编辑／预览组件；调用方只传消费上下文，不复制表单代码。
3. Runtime：统一遮罩取样，消费方决定可见度、滤镜覆盖度、出生分布或粒子透明度；CPU／GPU不各猜语义。
4. 测试：合同 → Runtime smoke → 浏览器真实流程／像素 → 交付／后端；不是只断言JSON被写入。

## 开工前需要进一步落定的细节

以下不推翻用户已确认方案，而是各阶段开工门槛；有产品影响时继续对齐，不以实现者猜测代替：

- U1：No／旧覆层清理与多图形version1已落地，不建独立轨；单图形在UI投影为图形类，添加第二个时提升集合。
- U2：“显示来源”与多个消费者、来源手动隐／独、来源显示时段的裁决；来源只采自身对象合成、不含场景滤镜的具体样例。
- U3：多图形列表／＋／复制／删除、绿色编辑和真实预览已落地；预览为View状态，不写工程或历史，保留时间／轨道／草稿并隔离异步结果。没有图片时仍从文件导入。
- U4及后续修订已实现：旧粒子按出生参数存活，新粒子按新段参数；非空分布归一化到目标数量，全黑不出生、不补中心。数量／寿命为Step，按稳定出生序列重建。冷启动大图完整来源成本留在U6，不按耗时偷偷改Alpha。
- U5：若图片来源为多帧素材，本批完整支持还是显式限制；不能静默只读首帧。共享来源缺失时的恢复路径与提示。
- U6：结合现有预览预算确定S/M/L验收阈值，不先拍脑袋承诺动态完整对象引用无开销；桌面封装验收是否在该批执行需明确。

## 最低测试集

| 类别 | 场景／断言 |
| --- | --- |
| 通道 | 透明边缘、透明区非零RGB、黑白／彩色、半透明亮度、反相后的有限边界 |
| 多图形 | 不相交两岛、重叠不加深、整体反相、复制删除、父组变换下编辑和真实像素一致 |
| 对象引用 | 图片／文字／矢量／程序／组；自身蒙版和加样／采样实际参与；来源动态／时序；自身／包含自身的组／间接循环拒绝 |
| 来源显示 | 专用隐藏不改hidden；多消费者；手动显隐／独显；关闭或移除引用不残留隐藏状态 |
| 粒子出生 | 发射器平移后旧粒子不被带走、新粒子从新位置出生；顺播与直接跳到同一时刻一致；出生时取样动态来源 |
| 粒子分布 | 多岛、稀疏灰度、全黑、反相；无包围盒中心误发射；显示灰度乘透明度，不误变碰撞／逐像素裁切 |
| 生命周期 | 预览不写历史；取消和撤销；工程保存重开；来源改名／删除／ID冲突／共享依赖闭包；项目切换与异步导入过期隔离 |
| 后端交付 | 真实Player的CPU／GPU结果；不支持组合明确回退；测试场景及内联Runtime／PNG／序列与编辑器求值一致 |
