# G3：自定义图元与角点箭头合同

状态：G3已实现；本轮补充路径显现与箭杆配置。G4已有隔离Agent使用已注册图样的实验，通用新配方生成、螺旋和内部Skill仍未实现。

## 一、持久化与注册

R3a增量：[静态几何缺失保护](V4_PATTERN_SNAPSHOT_R3A_2026-10-18.md)为custom补充可选`geometrySnapshot`。下述“未知版本报错／不保存派生路径”为原G3边界，现已扩展为：未知版本有匹配缓存时保留外观并锁定内部参数，否则仍报错；派生轮廓仅作为显式工程保存的可移植快照，非逐帧缓存、非生成器代码。精确实现存在时继续使用原生成器。

后续增量：同一custom合同已新增brackets/v1；其参数、Agent审阅和样例见[括号／角标](V4_BRACKET_PATTERN_2026-10-18.md)。下述corner-arrows规则不自动套用到所有自定义配方。

自定义是`entities[].parts[]`中的图元类型，不是新的Scene实体类型：

```json
{"id":"arrows","type":"custom","x":0,"y":0,"w":200,"h":120,
 "stroke":"#ffd23f","strokeWidth":3,"strokeAlpha":1,
 "recipe":{"id":"corner-arrows","version":1,
   "params":{"size":24,"length":36,"inset":0,"direction":"out","radius":0,"shaftMode":"center","shaftAngle":0,"shaftCap":"butt"}}}
```

Runtime模块`59g-custom-shapes.js`提供版本化definitions和归一化、生成、绘制、边界、命中；首批仅登记corner-arrows/v1。未知ID／版本或非对象params明确报错，不回退为矩形，不执行代码字符串。工程只保存声明数据，不保存派生路径、Canvas、缓存或文件权限。

应用到已有图元则保留rect／poly原类型，保存于`extensions['corner-arrows']`；同样使用该生成器。两条路线不是相互转换功能，不增加创建后的载体类型选择。

## 二、参数

| 字段 | 名称 | 默认与含义 |
|---|---|---|
| size | 箭头大小 | 24；从尖端沿相邻两边方向量取的两翼长度；非负 |
| length | 箭杆长度 | 36；从箭尖至最终尾端的总长度，切换端头不改长度；非负，0关闭箭杆 |
| inset | 缩进 | 0；角点沿朝重心方向移动的距离，负数向外扩 |
| direction | 方向 | out向外／in向内；同步反转两翼与箭杆方向 |
| radius | 圆角 | 0为尖角；作用于箭翼与箭杆尾端轮廓，受相邻边长约束 |
| shaftMode | 箭杆角度 | center几何中心／fixed固定角度；只调整箭杆，不改变箭翼及缩进 |
| shaftAngle | 角度 | 0；fixed渐进显示；以局部水平轴为基准的倾角，按角点朝向重心的象限镜像，0°水平、90°垂直，随图元旋转。轴上角点保持轴线方向。其余角度按三角函数折回等价倾角 |
| shaftCap | 箭杆端头 | butt平头／round圆头／point尖头；默认平头。尖头底边垂直箭杆，深度为半线宽且不超过箭杆长度 |

描线width／color／alpha：应用路线存于拓展配置，缺省继承源描线（再取填色）；源没有描线或线宽为0时，初始宽度为3以免启用即不可见。自定义路线复用图元strokeWidth／stroke／strokeAlpha，不在recipe.params再存一份样式。颜色复用既有实色／透明度组件，用户侧透明度0～100。两条路线在同一拓展控件编辑。

参数均为基础值，不接独立Step／Linear；已有对象变换、显示时段、图元局部动画和对象效果继续作用。首批自定义由多条开放路径构成，不额外承诺填充、路径波形、逐路径完成度或递归拓展；Inspector不显示这些无效控件。应用后的箭头作为完整静态派生路径，源路径完成度仍控制源描线，不新增箭头逐笔时序。

## 三、几何与边界

- 矩形使用四个原始设计角点，圆角半径不会增加顶点数量。
- 正多边形使用其真实顶点；自由多边形使用原始点序，不使用曲线离散点。
- 相邻边决定两翼，面积重心决定箭杆与缩进方向。凹多边形的重心可能在形状之外，因此不承诺箭杆全在内部；不静默替换成包围框或角平分线。
- 连续重复点清理，不改源数据；直线上的冗余点不生成角箭头。自交、非相邻边接触、退化面积及超过256点明确提示，不生成伪结果。椭圆／开放路径不提供应用入口。
- 中心线派生粗轮廓，0圆角保留尖角；正圆角使用有限采样的二次曲线，每角最多8段。急角斜接受4倍半线宽限制，避免无界尖刺。
- 箭翼与箭杆轮廓统一方向、一次非零填充，交叠处不重复乘透明度。不使用布尔裁切、逐像素读回或新的离屏画布，边界和命中读取同一轮廓。沿用所属对象混合、透明度和mask/decorate/sample管线。
- 视觉边界与图元命中包含派生内容。实例空心区域不以整块矩形冒充精确图元命中；对象层级仍可按组合范围选择。

## 四、性能合同

每形状最多256设计顶点，每顶点最多一条圆滑箭头及一条箭杆。全局几何缓存LRU最多32项，派生点合计最多65536；缓存键仅含纯几何、参数与样式，不持有Scene、素材或对象引用，不产生跨项目ID污染。整体移动／参数变化只重建相应纯几何；相同输入复用结果。不宣称任意尺寸、任意效果组合可满帧。
