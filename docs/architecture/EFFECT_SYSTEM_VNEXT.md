## 目标

将过去分散在“属性 / 风格 / 局部 FX / 全局 FX / Sampling Motion”的能力收束为三种用户能理解的动作：

| 语义 | 对象 | 场景 |
|---|---|---|
| 成样 | 内容、路径、文字、变换、调色四轴、叠加方式 | 画布、循环、背景、对象合成 |
| 加样 | 给对象加投影、描边、染色、纹理、内/外光效 | 给合成画面加调色、染色、纹理、蒙版暗角 |
| 采样 | 改变对象像素的颜色、格点、网点、噪点与偏移 | 对完整合成画面作相同类别的采样 |

这不是把所有效果做得更多，而是让人和 Agent 都能先回答“我是在造对象、加一层，还是重采样它”，再选择具体效果。

## 单一事实来源

`editor/effect-registry-vnext.js` 是 vNext 的唯一元数据来源。它声明稳定 ID、阶段、作用域、参数、时序能力、运动能力、粒子继承策略、蒙版要求和性能等级；其他产物只能派生，不手写第二份效果定义。

```text
effect-registry-vnext.js
        ├─ Inspector 控件与渐进披露规则
        ├─ 左侧“效果”卡片及可见顺序
        ├─ docs/agent/EFFECT_MANIFEST_VNEXT.json
        ├─ Runtime stage dispatcher / validator
        └─ 性能预算与验收夹具
```

## 渲染管线

### 对象

对象先按内容/路径/文字完成**成样**；对象级调色四轴固定在成样末尾、蒙版之前。后续三个可调序阶段默认顺序为：

```text
成样 → 蒙版 → 加样 → 采样 → 按 z 合成进场景
```

`蒙版 / 加样 / 采样` 是可整体调序的三个阶段；阶段内部顺序固定，避免用户需要理解数十个底层滤镜的排列组合。默认顺序保存为：

```js
pipeline: ['mask', 'decorate', 'sample']
```

拖动的是阶段标题而非单张效果卡。这样允许“蒙版只裁原对象”或“蒙版裁所有处理后结果”，但不引入无限制滤镜栈。

### 场景

场景在所有对象按 z 合成后处理：

```text
对象合成 → 场景叠加滤镜 → 场景采样滤镜 → 输出
```

场景滤镜可有范围蒙版；范围只约束滤镜作用区域，不改变任何对象的 z。它替代旧的“局部 FX 是一个独立图层”的模型。`grain-overlay` 是加样/场景叠加滤镜，不是采样滤镜或独立输出阶段；旧 `texture-overlay` 的 `texture:'noise'` 仍可读取，但新建颗粒不再走稀疏图案。`crt-display` 仅属于场景采样滤镜，在该阶段末端处理已合成画面；不在对象采样、场景背景成样或编辑器外壳上叠加。

### 场景 CRT 显示（试验实现）

`crt-display` 提供七组可编辑的主题预设：经典彩色、单色绿屏、绿屏扫描线、Apple 风格、怀旧电视、IBM 3278 风格、未来屏幕。主题切换将曲率、扫描线、荧光栅格、RGB 错位、光晕、暗角、噪声、闪烁、滚动亮带等参数写入工程；它们是风格方向，不宣称逐像素复刻参考站。CRT 卡片的「动态」默认关闭：静态扫描线、荧光栅格与固定相位的亮带/颗粒仍然可见，但随播放时间不变化。开启后，周期时间、周期帧数、扫描线漂移渐进显示，噪声、闪烁和亮带强度也在动态区编辑；预览调度器因此将静止场景判为需要持续绘制。关闭动态保留参数，并将时间相位固定为零。全部参数为 Step；周期相位闭环，固定时间与随机种子保证测试场景可重复播放。该效果只接在场景采样阶段末端，仍服从场景叠加/采样两阶段的现有顺序；若用户将整个叠加阶段排在采样之后，后续叠加不会被 CRT 处理。

Runtime 优先使用离屏 WebGL 着色器，WebGL 不可用时回退 Canvas 2D 像素遍历；两条路径使用相同工程参数，导出测试场景沿用同一 Runtime。`tools/tests/browser/v4-crt-display.mjs` 检验七主题有区别、固定时间确定性、动态开关与预览调度、GPU 非空输出和 Inspector 写入。2026-10-12 本机无头 Edge、640×360、预热后 16 帧夹具：GPU P95 约 0.5–0.6 ms，CPU P95 约 100–150 ms；此数值不是 1080p 性能承诺，也不能代表所有显卡与浏览器。2D 回退应视作正确性保底，不应承诺全画布实时编辑。输出画面仍由主 2D Canvas 合成，GPU 仅为该效果的可选加速路径。

## 效果表

### 加样（对象）

| 稳定 ID | 面向用户的名称 | 典型用途 | 时序 |
|---|---|---|---|
| `projection` | 投影 | 硬阴影、长投影 | 颜色、透明度、距离、角度可 Linear |
| `outline` | 描边 | 对最终 Alpha 的硬边外描边 | 颜色、透明度、宽度可 Linear |
| `tint-overlay` | 染色叠加 | 灯光、色膜、淡入 | 颜色/透明度 Linear；混合方式 Step |
| `texture-overlay` | 纹理叠加 | 纸纹、网格、扫描线类质感；自定义 tile 可选实色混合 | 颜色/透明度/缩放/角度 Linear；纹理/混合 Step |
| `grain-overlay` | 颗粒叠加 | 低强度细颗粒至高强度雪花屏；可按周期刷新 | 强度 Linear；类型/尺寸/种子/混合方式/动态 Step |
| `inner-light` | 内光效 | 内发光、内阴影 | 数值/颜色 Linear；模式 Step |
| `outer-light` | 外光效 | 外发光、硬边光晕 | 数值/颜色 Linear |

路径描线仍属于图元内容，不等同于 `outline`；前者画一条路径，后者从整个对象 Alpha 外扩。

`texture-overlay.blend:'hard-mix'` 是限定在纹理叠加的实验性模式：每个 RGB 通道以“底色 + 纹理色 ≥ 255”判为 255，否则为 0，再按纹理 Alpha 与底色合成。它不是 Canvas 原生混合方式；Runtime 需要逐像素读写，成本随纹理作用面积线性上升。对象/图元整体混合、投影、描边等入口暂不显示该模式，避免选择后静默退化为正常混合。完整性能数据见 `HARD_MIX_PERFORMANCE_2026-10-09.md`。

### 成样调色（对象）

`color-grade` 是对象的成样属性，不显示为独立效果卡，也不带动态预设。它只提供色相、亮度、对比度、饱和度四个 Step 参数；四轴都为零时 Runtime 不建立额外处理面。场景级 `color-grade` 仍位于场景叠加滤镜。

### 采样（对象与场景共用 ID）

| 稳定 ID | 面向用户的名称 | 运动变体 / 说明 | 时序 |
|---|---|---|---|
| `color-map` | 颜色映射 | 自动提取 2–256 个代表色，或选择命名调色板；命名调色板优先 | Step |
| `noise-dither` | 杂色抖动 | 对已有 RGB 像素值添加随机扰动；可按周期刷新 | 强度/类型/尺寸/种子/动态均为 Step |
| `threshold` | 阈值分色 | 可启用阈值呼吸 | Step |
| `offset-sampling` | 偏移采样 | 稀疏候选采样的像素沸腾、统一采样窗的像素呼吸，或有限完整条带的故障 | Step |
| `halftone` | 网点映射 | 可启用网点震荡 / 网点移动 | Step |
| `uneven-sampling` | 不均采样 | 启用即使用采样场、边缘保护与统一采样运动；可形成“轮廓稳定、内部翻涌” | Step |

采样格是唯一的共享控制器，不是独立效果卡，也不会出现在左侧“对象效果”容器；它固定显示在采样 Inspector 顶部：

`noise-dither` 在固定采样顺序中位于颜色映射之后、阈值分色之前。强度是 RGB 值的最大扰动幅度（0–100 对应 0–255），不是颗粒覆盖率；单色共用同一个扰动值，彩色分别扰动三通道，Alpha 原样保留。颗粒尺寸以当前采样工作面的像素为单位。它与加样中的 `grain-overlay` 不同：后者叠一层可见颗粒，不改写原图 RGB；杂色抖动需要一次像素读写，完整大画布应按采样预览预算评估。

- `sampling-grid`（采样格）只保留**采样尺寸**，且自身就是可见的最近邻再采样：先缩至格点工作面，再放大回输出尺寸。偏移采样、网点映射与不均采样继续在该工作面运算，避免完整尺寸逐像素处理造成碎裂和性能浪费。网点映射的实际单元为“采样格 × 相对尺寸”，其亮度先缩至该分析格再批量生成网点；色彩可选原色、单色、暗／亮双色渐变。错列偏移 0 为整齐、0.5 为半格错列；起始偏移与旋转只属于该效果，不混入共享采样格。
- `color-map` 的“自动提取”先在当前处理面统计实际 RGB 代表色、再以加权 Median Cut 缩减至“最大颜色数”，并缓存 5-bit 颜色查找表；它不是固定 RGB 立方体量化。自动值为 256 时直通原色（命名调色板仍强制映射）。`palette-flash` 按其唯一的“周期”在原色与映射色之间完整交替。
- `uneven-sampling.field`（采样场）是“不均采样”的内建渐进参数，启用效果即启用该场；它提供波场／径向／噪声三种空间分布，波场有方向，径向有中心。它只决定局部采样粗细，不再暗中影响阈值、网点或偏移采样。
- `uneven-sampling.edge`（边缘保护）同样只服务不均采样，只有关闭、保护轮廓、保护内部三态。它仅在对象级依据 Alpha 轮廓生效；场景合成通常没有有意义的 Alpha 轮廓，因此场景级不开放该项。
- `uneven-sampling.motion` 是一个“采样运动”渐进入口，统一显示周期时间、流动速度、周期帧数与起伏幅度；前者移动空间分布，后者调制不均采样的粗细幅度。不存在单独的“场流动／采样潮汐”开关。

采样格单独即可产生像素化结果；采样场与边缘保护只属于不均采样。历史文件若显式关闭采样场，不均采样必须直通，不能退化成第二次全局像素化。

`offset-sampling` 的三种模式共用“确定性采样偏移”的视觉意图，但 Runtime 路径必须分开：

- **像素沸腾**：对象或场景先完成高分辨率胶囊栅格化；Runtime 从中心、左、右、上、下生成五张低分辨率候选采样面，再按确定性的 seed / tick 为每个采样格选择候选。候选选择是离散的，不会把多个颜色混合成条带方向的整体平移；`沸腾密度` 决定多少采样格离开中心候选，默认 `30%`，因此画面不会整面翻涌。参数是偏置、密度、动态（采样跳变／采样漂移、频率）、种子与边缘规则。偏置是以采样格为上限的中心对称整数。它不再为图片走特殊路径，因此文字、图元集合和内建组件也会得到同一采样语义；采样格小于 2 时不生效。
- **像素呼吸**：整张对象或场景共用一个由 seed / tick 决定的**小数**高分辨率取样窗，再缩入采样格；其窗口公式保留旧导出页的 `origin ∈ [0,幅度]` 与 `sourceSize = 原尺寸 - 幅度`。小数相位使不同低分辨率格跨越源像素阈值的时机略有不同，形成细微、粗糙的格点游移，而不是逐格沸腾。参数是呼吸幅度（默认 `0.1`、步长 `0.05`）、动态、频率和种子；对象级可选 `breath.edge.mode='contour'` 锁定 Alpha 轮廓。呼吸不提供“保护内部”，以免不透明图片被冻结；同样仅在采样格至少为 2 时生效。
- **条带故障**：在对象或场景的采样后处理阶段，复制少量水平或垂直完整条带；参数是条带方向、数量、厚度、最大位移、通道与种子。它不逐像素随机重采样，故障范围也不会扩散成整幅碎裂画面。

## 时间与运动

同一参数不应同时被两套“动画”概念竞争。vNext 采用固定求值顺序：

```text
基础值 → 稀疏时段覆层（Step / Linear）→ 程序运动调制 → 输出
```

- **时序覆层**用于创作者明确编辑的分段变化。轨道只记录被改变的字段。
- **Linear**只开放给注册表标注为 `linear-safe` 的值；颜色、透明度、距离、尺寸等低成本连续量可用，调色四轴和采样参数第一版保持 Step。
- `#RGB / #RRGGBB` 颜色按确定性的 sRGB 整数通道插值；颜色透明度继续使用独立数值字段，不把八位 Alpha 混入颜色字符串。
- **程序运动**是效果卡右侧的运动开关，例如阈值呼吸、网点震荡、网点移动、条带漂移；它按随机种子 / 周期时间闭环，不生成大量关键帧。

效果卡有独立时间轴上下文。若启用时序，只对该卡的稀疏字段写入；不会把全部 Inspector 参数复制到每个时段。

### Step / Linear 参数能力表

该表约束 UI 与 Agent；机器可执行真相仍是 `editor/effect-registry-vnext.js` 中每个参数的 `timing`。Inspector 不得自行扩大 Linear 范围。

| 范围 | Linear | Step |
|---|---|---|
| 对象成样 | X/Y、宽高、比例、旋转、整体透明度；文字完成度；内部笔触完成度（按图元ID写入所属对象轨） | 内容、文字、路径、素材引用、混合模式、蒙版配置；文字光标开关／样式／闪烁周期／颜色；笔触反向／平滑度／端点／转角／虚线配置 |
| 对象 / 图元动态 | 暂无 | `bob / scroll / pulse / spin / wave / blink` 的启用状态与全部参数；写入当前对象轨的 `anim.*` 或 `parts.<index>.anim.*` |
| 对象加样 | 注册表标记的颜色、颜色 Alpha、距离、角度、宽度、尺寸、纹理缩放 | 启用、模式、混合方式、纹理类型与程序运动配置 |
| 对象采样 | 暂无 | 颜色映射、调色四轴、阈值、噪点、偏移、网点、不均采样及三个共享控制器 |
| 场景叠加 | 注册表标记的颜色、颜色 Alpha、尺寸、角度与缩放 | 启用、模式、混合方式、纹理、范围蒙版 |
| 场景采样 / 输出颗粒 | 暂无 | 全部参数；避免高分辨率场景每帧重跑高成本像素操作 |

动态条目本身是由全局固定时间时钟调制的 Step 配置：跨段更改开关或数值不会重置相位，进入下一段后继续以当前播放时间计算。Linear 只改变同一参数轨道的固定时间求值，不复制效果配置。任何新增 Linear 参数必须同时补 Registry 声明、Runtime 插值、Preview Scheduler 连续重绘声明、保存往返和固定时间测试。

## 蒙版与引用源

对象蒙版与场景滤镜范围共用一个组件和一个 schema。支持静态矩形/椭圆/多边形/Alpha 图片，以及引用场景元素或组的动态 Alpha。

元素或组一旦被引用为蒙版源，就只贡献 Alpha，不参与可见合成。此状态由引用关系派生，不写入来源对象自身的 `hidden`，也不再保存 `sourceVisibility` 字段。解除最后一个引用后，来源恢复原有显示状态。若同时需要可见副本，可建立共享素材的另一对象实例。

## 粒子与性能

粒子继承对象的可见视觉胶囊：内容/路径/文字、对象级加样、采样、相关动画和蒙版结果；不继承位置、z、滚动、显示时段和场景滤镜。带采样或加样的实体必须每发射器每帧先渲染一次共享精灵，粒子仅复用该帧结果，禁止每颗粒子重跑完整像素管线。

性能等级：A 为直接绘制或少量合成；B 为对象/蒙版离屏或局部像素操作；C 为场景级像素遍历。Runtime 需要按工作像素、激活效果与质量档位记录预算；离线导出强制 Full 质量。

## 格式与迁移边界

vNext 将引入新的声明式 `effects` 数据，而不是继续扩写旧 `fx.layers`。本轮决策是不维护旧作品格式兼容：迁移实施前要冻结样例、提供一次性迁移工具或明确新建场景入口，但不要在新 Runtime 中长期保留双语义。

`SCENE_SPEC.md`、`editor/effect-registry.js` 与旧 Runtime 继续描述 Legacy JS 会话；[v4 Scene 合同](VNEXT_SCENE_CONTRACT.md)、`editor/effect-registry-vnext.js`、v4 serializer / validator 与 Runtime 描述 `.tosampool.json` 会话。Classic Shell 已接入受控 v4 纵向切片，但在默认产品入口切换前，两套公开说明必须明确标注会话，不能混写字段。

## Runtime 实施状态

v4 Runtime 源码位于 `runtime-src/vnext/`，构建为 `home-scene-vnext.js` 与测试页源码镜像。它只接受 `format:'tosampool-scene/v4'`，已交付固定时间、基础实体、稀疏 Step/Linear（含 `linear-safe` sRGB 颜色）求值、组父级变换、对象视觉胶囊、确定性共享精灵粒子、静态/Alpha/元素或组引用蒙版、对象加样、共享采样控制器、对象与场景采样及场景输出颗粒。

场景级 `overlay → sample` 只有在存在启用效果时才建立全画布离屏层；持久 `assets[id]` 只保存 locator，`runtimeAssets[id]` 由 Host 注入。`group` 是扁平实体列表中的变换父级；元素或组可作为动态 Alpha 引用源。`particle-emitter` 每发射器、每帧只建立一次来源视觉胶囊。Classic Shell Inspector 已由 Registry 推导对象/场景效果卡与共享采样控制器，并与上下文时间轴、保存重开及自包含测试页接通。对象蒙版与场景滤镜范围共用 `EditorVNextMaskState`、同一 validator、Runtime resolver 和绿色 Canvas 编辑控制器；Inspector 可编辑五类蒙版，几何 / Alpha 范围可在画布拖框，多边形可点选和编辑顶点。

静态范围蒙版会在离屏面上产生真实裁切结果；`masked-inner-light` 复用该范围生成轻量径向暗角，不包含羽化/高斯模糊。粒子发射器复用同一几何范围组件：`emissionRange` 决定每颗粒子的本地出生位置，`motionRange` 是默认关闭的本地运动裁切范围；二者随发射器变换而动，当前只支持矩形、椭圆和多边形，避免伪装支持无法稳定采样的 Alpha / 元素来源。噪点通过纹理叠加的稀疏 final-pixel 点绘制实现，不执行整图 `getImageData` 改色。对象/场景效果使用稳定效果轨道键，Registry 默认值、启用/移除、参数路径、阶段重排与轨道清理由 `EditorVNextEffectState` 统一处理。Classic v4 已接入左侧启用项索引和对象 `mask / decorate / sample` 大阶段调序；卡片导航、效果轨同步、统一停用清理和单历史撤销已通过真实 Edge。区域滤镜的数据、Inspector、Canvas、Runtime 与保存往返统一为“场景滤镜 + 范围蒙版”；下一验收切片补齐所有卡片类型的重开恢复与快捷时序入口。旧 `home-scene.js` 与 `fx.layers[]` 只属于 Legacy 会话。

对象描边默认只从对象本体 Alpha 生成，即投影保持在描边之后；启用 `包含投影` 才会以“投影 + 对象”的合成 Alpha 生成外轮廓。这一开关属于 Step 参数，避免在一段 Linear 插值中改变处理拓扑。

`offset-sampling.type:'boil'` 不再对整个低分辨率结果作一次裁窗缩放；它会从高分辨率对象胶囊生成中心与四向微偏移的候选采样面，并按确定性 seed / tick 为每个采样格挑选候选。`boil.coverage` 控制非中心候选的比例，默认 30%。`edge.mode` 复用不均采样的三档语义：`off` 仅保留最外一圈保护带，`contour` 额外固定 Alpha 轮廓及其邻域，`interior` 额外固定不透明内部。最外一圈采样格始终作为保护带，避免对象边界随沸腾改变。`type:'breath'` 保留独立的统一采样窗路径，不使用逐格候选。
