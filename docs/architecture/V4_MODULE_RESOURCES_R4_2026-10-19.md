# R4：程序构件资源与动态交付

状态：R4a 复用实例及 R4b 显式冻结／烘焙首版完成。不是任意代码插件沙箱，也不是把静态快照当成动画；不提供无缓存缺失程序的自动恢复。

## 本轮用户任务与入口

用户把已有的程序构件带到另一个工程，新建多个实例，并分别调整作者公开的参数。视觉沿用既有收藏行、按钮、成样表单，不新增插件管理工作区。

左下“收藏”→“导入图样/资源”→选择 [雨幕资源包](../../examples/resources/rain-curtain.tosampool-resource.json)。当前工程出现“雨幕”，点击“新建”，确认来源后即可建立对象；后续同工程实例无需反复加载代码。实例默认居中，并按比例容纳到画布宽高的 2/3 内。推荐尺寸由 Manifest.recommendedCanvas 提供，没有声明则用画布的 2/3。

新建自动选中对象并进入成样，公开参数仍由既有 Manifest Inspector、共享颜色组件和对象时序编辑；不创建第二套参数协议。资源收藏、跨工程取用沿用统一资源闭包。此首版收藏的是构件定义及其默认参数，不是所选实例的完整造型／效果／时序预设。

## 身份、授信与历史

- 程序资源继续以 Manifest.id/version 标识，同身份内容冲突仍拒绝导入；不重写源码内的素材名。
- 导入、收藏、取用都不执行代码。第一次新建检查当前 Workspace 模块作用域，未加载时明确确认后使用已有受信 Module Loader；取消不新建、不执行。
- 已加载实现的 Manifest 必须和当前工程描述一致；缺少依赖素材、版本或作用域不符时不创建假对象。
- 每个实例拥有独立 params、变换、效果和时间轴。初值来自声明，不共享可变参数对象；不复制别的实例的动态状态。
- 新建是一次工程历史记录，Ctrl+Z/Redo 恢复实例；参数调整沿用原有历史与参数时序规则。
- 信任确认不是工程历史：执行过的 JS 及其潜在宿主副作用不能被 Ctrl+Z 撤回。这仍是明确授信的代码执行，不是安全沙箱。跨工程使用新作用域，不能因收藏自动信任。
- 异步确认／读取提交前重新核对工程对象与 revision。用户在等待期间切工程或修改后，拒绝旧结果写入；不能把已获准执行的代码副作用描述为可事务回滚。

## 四层落点

| 层 | 落点与职责 |
| --- | --- |
| 数据／资源 | 复用现有 module 记录、Manifest、依赖闭包与 SHA-256；本轮不增加新的 Scene 字段 |
| 编辑器 | `editor/v4-module-instances.js` 负责默认参数、精确作用域、依赖和尺寸；`classic-v4-resource-controller.js` 提供新建及显式确认；Inspector.focusModule 跳转公开参数 |
| Runtime | 沿用 sceneModules，不增加像素遍、离屏画布或每帧依赖扫描；每个新实例仍有自身绘制成本，不承诺大量实例免费 |
| 验证 | 合同、真实按钮导入／取消／新建／参数／撤销、跨工程再次授信、工程保存及 HTML 动画交付；接入 verify-v4 |

## R4b：显式生成普通素材

选中一个程序构件对象（不是其下钻图元），打开左下“收藏”。“选中构件”提供“冻结当前帧”和“烘焙序列”；后者可调整周期帧数。生成完成后作为普通 image／sequence 进入当前素材库，原对象、参数、时序及模块描述不变。一次生成对应一次历史记录，可撤销／重做；不会自动覆盖已有素材或替换原对象。

画面为与当前画布相同尺寸的透明画面，仅绘制选中对象。复用正式 Runtime 的 Full Frame、对象合成器与对象效果顺序，包含对象变换／动态、附属图元、父组变换及透明度、对象蒙版／加样／采样。只保留画布内的内容，不包含背景、其他对象、场景滤镜和场景转场；依赖背景的最终混合外观不保证与完整场景一致。这不是整个场景截图。

冻结取当前播放时间；序列采样完整工程周期 `[0, loop)`，不重复尾帧，`fps = 周期帧数 / loop` 保证回放周期精确一致。是否视觉无缝仍取决于源构件及其时间轴本身是否闭合，不会自动修补源运动。Full 不受编辑器 Auto／Draft 降采样影响。

素材描述增加只作来源记录的 `moduleBake`（`tosampool-module-bake/v1`），保存原模块ID／版本、对象ID、基础参数JSON文本、采样时间与边界说明。不存可执行源码，不把来源记录解释为依赖闭包。参数用 `paramsJson` 而非可被 assetId 扫描器误判的嵌套对象；它不是用来复原完整工程的配方。

结果可通过现有素材收藏／资源包／项目包传递，在新工程中以普通图片或序列使用，并导出无 Module 的 HTML。普通素材置入仍沿用不超过画布2/3的缩放规则；如需在同尺寸画布精准对齐，应将新图片位置设为0/0、尺寸设为来源画布大小。原程序需自行保留或移除，首版不引入隐式替换和双向链接。

## R4b 预算、取消与不可用情况

- 单帧及选中对象视觉胶囊不得超过 4,194,304 像素；总采样量最多 96,000,000 像素，最多120帧；序列至少2帧。界面显示本工程可用帧数及精确帧率。
- 累计PNG字节和data URL字符数分别不得超过48MiB；完成后显示真实PNG体积。PNG压缩率不能在生成前保证；超预算会完整失败，不保存前半段。
- 逐帧编码，不积攒原始RGBA；每帧清理尺寸变化造成的胶囊缓存。帧间让出事件循环，支持取消；一帧内的任意JS绘制不可强制抢占，取消响应发生于帧边界及编码完成检查。
- 全部帧先在工程之外准备，成功且工程身份／revision仍匹配才一次提交。取消、编码失败、用户切工程或修改工程均不留半成品；取消不是错误警告。
- 这是空间换计算，不承诺烘焙总比程序快。序列解码像素最多约384MB RGBA（不含其他开销），长期保留的编码数据也有成本；小程序或长周期通常继续保留Module更合适。首版不支持任意倍率／分段导出／压缩格式选择，也不自动降质。

冻结／烘焙需要可用且已获信任的源构件。源码已经缺失且没有事先生成的素材时，不能凭一张预览恢复运动，必须先恢复依赖。已生成的素材是独立资源；图样的静态 geometrySnapshot 不参与此流程。首版没有自动绑定缺失源到缓存、恢复关联、替换原对象或缓存版本同步。

## R4b 四层落点与验收

- `editor/v4-module-baker.js`：计划、精确采样、透明对象渲染、预算、取消及普通素材描述；不新增Runtime渲染分支。
- `classic-v4-resource-controller.js`：选中对象入口、周期帧数、进度／取消、当前工程token及单次历史提交；正式HTML传入当前播放时间。
- 复用 `EditorVNextAssetState`、资源核、项目包、普通序列播放及交付Builder，不建立第二套序列格式。
- `tests/v4-module-baker-contract.mjs` 与 `tests/browser/v4-module-baker.mjs` 接入verify-v4。真实按钮冻结当前0.75s，逐像素比对Full对象；八帧变化／精确周期、取消按钮、失败／过期／源码缺失无写入、来源参数不引入伪依赖、撤销、资源与项目往返、无Module HTML实际运动均通过。
- 截图 `docs/design/evidence/resource-r4b-2026-10-19/bake.png` 已实际查看，按oil-ui-pro沿用存量按钮、表单及反馈，自检无独立评分。不声称完成verify-v4全集、所有对象效果组合或Tauri封装验收。
