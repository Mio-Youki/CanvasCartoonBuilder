# 括号／角标图样：真实需求与实施合同

状态：已接入Runtime、图样目录与共享Inspector；定向合同／浏览器及旧流程回归通过。未重建Tauri安装包，不表示G4通用配方／内部Skill已完成。

## 用户需求与体验

用户希望用同一组参数得到`[`、`「`、`(`，能调整尺寸和粗细，并选择完整左右括号或不同角标组合。参考为深灰背景上的粗浅灰方括号与左上直角，不使用字体字形，也不烘焙位图。

沿用现有图样目录和拓展控件：无唯一图元时直接新建custom，应用时保留原图元类型。尺寸由图元成样宽高／画布手柄控制，线宽独立；不增加创建后的载体切换。渐进展示当前布局相关字段，颜色透明度复用现有组件。

## 四层落点与验收门槛

| 层 | 落点 |
|---|---|
| Registry／合同 | brackets/v1，独立与依附共用参数，兼容闭合图元的局部框定范围 |
| Inspector／目录 | 一个括号卡片，共用拓展页；造型／布局／侧别或角标位置渐进，单次创建事务 |
| Runtime | 独立几何模块；复用custom轮廓绘制／边界／命中，无字体、布尔运算、逐像素读回或额外离屏画布 |
| 测试 | 布局与对称、直角／圆弧、极小尺寸及大粗细、缓存预算；新建／应用／实际画面／撤销／复制／工程重开／HTML与旧图样回归 |

不新增配方参数时序，沿用所属对象的变换、显示与效果。Agent提案与宿主采纳／修正分开记录，不将设计建议称为已运行的工程。

## 持久化与参数

独立图元为`parts[].type='custom'`、`recipe:{id:'brackets',version:1,params:{...}}`，颜色／粗细／透明度仍为stroke／strokeWidth／strokeAlpha。应用到rect／ellipse／poly保持类型，写`extensions.brackets`，其中另有enabled、width、color、alpha。应用使用载体的局部几何框，不沿椭圆或多边形轮廓逐点贴合。

| 字段 | 用户名称／默认值 | 渐进条件与语义 |
|---|---|---|
| shape | 造型 square | square直角／round圆弧 |
| layout | 布局 full | full完整括号／corners角标 |
| side | 侧别 both | 完整时显示both左右成对／left仅左／right仅右 |
| corners | 角标位置 all | 角标时显示all四角／tl-br左上右下／bl-tr左下右上／tl／tr／bl／br单角 |
| armX | 横向长度 24 | 沿中心线测量；完整模式为横臂长度或半椭圆横半轴 |
| armY | 纵向长度 24 | 仅角标显示；纵臂长度或四分之一椭圆纵半轴 |
| radius | 圆角 0 | 仅直角显示，沿用共用实体轮廓圆滑；0为尖角，不再额外作用于圆弧 |
| offsetX／offsetY | 水平偏移／垂直偏移 0 | 整组图样在载体局部坐标内平移，正值向右／向下；不是左右镜像扩张，不改变框定尺寸／臂长，允许移出框定范围 |
| width | 粗细 | 应用缺省继承载体正描线宽，否则3；独立复用strokeWidth，显式0隐藏 |
| color／alpha | 颜色／透明度 | 应用继承描线再取填色，独立复用stroke／strokeAlpha；UI透明度百分比 |

整体框定宽高由成样w/h和画布手柄控制，不在拓展页再造尺寸字段。单侧／单角可能只占框定范围的一部分，横／纵长度决定实际伸入程度；不是强行把单个符号拉满范围。改变框定尺寸不隐式改写粗细；对象整体比例变换仍沿用宿主、可以缩放整幅图样。

隐藏字段保留值；重开和再次启用不重置。所有图样参数只写基础配置，不会因为所属对象的时序开关而写入独立时段。

偏移保存到独立recipe.params或应用extensions.brackets；绘制、边界、命中统一平移，同一缓存键包含偏移。对象自身位置不变，引用／加样胶囊仍以更新后的实际视觉范围处理，不增加新的离屏步骤。

## 几何、边界与预算

先构造局部左侧／左上中心线，再左右／上下镜像。中心线内缩半个有效粗细。直角完整为四点折线，角标为三点折线；圆弧完整为半椭圆，角标为四分之一椭圆。不采用字体，也不以简单圆角矩形冒充圆括号。

有效粗细不超过框定短边减0.0001，保留原始请求值。完整左右成对的横向长度受`(可用跨度-粗细)/2`限制；单侧可到完整可用跨度。角标在同一行／列存在相邻角时才限制对应长度并留一倍粗细间隙；纯对角与单角可以使用全跨度。受限时Inspector显示有效值，不静默改写请求值；返回较宽范围或单角时原值仍在。

横长0可退化竖线、纵长0可退化横线，双0角标为空；显式0粗细／透明度合法。派生轮廓统一方向后一次非零填充，交叠不重复增加透明度。边界／命中复用该轮廓，空心内部不是整块可选区域。应用可与原图元和其他拓展共存，显示原图元沿用既有开关。

半／四分之一椭圆最多128段；纯几何LRU缓存32项／65536点。无字体加载、素材依赖、额外离屏画布或逐像素读回。没有跨设备帧率承诺。

## Agent实验与宿主审阅

隔离Agent未继承对话、未读取应用源码／示例／测试，收到真实需求、两张参考图与已确认的体验要求。它成功读取两图，先交付[设计提案](../../examples/agent-brackets-g4/design.md)和[六种变体](../../examples/agent-brackets-g4/variations.json)。宿主审核后提供实际字段合同，Agent再交付[可打开工程](../../examples/agent-brackets-g4/project.tosampool.json)，没有改写Runtime。

采用：布局×造型分离、中心线／镜像、半椭圆／四分之一椭圆、按位置组合限幅、交叠一次合成及切换保值。宿主修正：短字段ID；沿用工具默认粗细与默认臂长24；角标缺省四角；无关字段隐藏而非禁用；圆角复用已有实体轮廓语义而非仅中心线转弯；极粗值限幅并反馈而不是拒绝；尺寸沿用成样与画布。几何是在宿主审核后编写的受信模块，并非Agent提案JSON被任意执行。

另经宿主核对，提案对平头端点的尺寸推导有误：中心线横臂长a、粗细t时，尖角单侧直臂的可见外宽为`a+t/2`，不是提案所写`a+t`，因为平头不沿切线向外延伸半个线宽。产品保留中心线长度语义与平头，不为迎合该推导加方头；原提案保留作为实验记录。六例用于展示风格与参数，不声称逐像素复刻参考图。
