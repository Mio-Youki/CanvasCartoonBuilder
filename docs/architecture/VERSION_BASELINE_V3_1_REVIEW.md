## 5. 后续应建立的通用校验，而非“通用修改器”

已将只读校验收敛为已跟踪脚本 `scripts/verify-editor.mjs`：

1. 检查 `home-scene.js` 与外层 `public/home-scene.js` 的语法和 SHA256 镜像一致性；
2. 提取并编译 HTML 内每个内联脚本，而非依赖固定 `use strict` 起点；
3. 检查保存/测试导出时图片 `data:` 源不会被序列化剥离；
4. 只报告问题、返回非零退出码，**绝不写回源文件或自动转码**。

代码修改仍应由受控补丁完成；验证脚本只负责发现回归。这样既能复用，也避免再次发生编码或批量替换事故。

## 6. 提交前的最小收口顺序

1. 将第 1 节文件加入 `tools/`；审查其余已修改的文档、Runtime 与 `editor/geometry.js`；
2. 完成工具仓库校验并提交；
3. 确认 `tools/home-scene.js` 与外层 `public/home-scene.js` 完全一致后，在外层仓库单独提交镜像；
4. 快照、`.trash/` 与一次性调试物保持未跟踪，直到确认归档/删除策略。
