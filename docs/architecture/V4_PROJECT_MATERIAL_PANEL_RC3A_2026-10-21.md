# RC3-a：项目元素素材入库入口

2026-10-21增量，属于RC3小批，不代表共享发布或整个素材面板已收口。用户确认共享显式发布／显式更新，并指定导入按钮在素材／图样标题下独立一行。决议见[面板方案](../design/RC3_MATERIAL_PANEL_DECISIONS_2026-10-21.md)。

## 四层落点

| 层 | 实际职责 |
| --- | --- |
| 数据／Registry | 复用RC2的elementPresets、typed依赖及instantiate；无新Scene字段，无新Runtime实体 |
| UI／命令 | 新`editor/classic-v4-material-controller.js`接入结构树“库”按钮及项目元素卡；HTML只接线；原位图预处理／Alpha／导入不改；入库和放置共用changes.run |
| Runtime／Host | Runtime源码不改；静态预览走独立Runtime对象绘制，固定时间0、无场景滤镜／时序。复用AssetLoader／Module授信；不写共享库，不自动重开工程 |
| 验证 | `tests/browser/v4-project-material-panel.mjs`真实入口；RC2基础／依赖合同及原图样浏览器回归，纳入根目录scripts/verify-v4.mjs |

## 可用操作

1. 结构树／画布选择单个普通或程序元素，点击粒子化右侧“库”（提示“收入素材库”）。组、粒子、单独图元及多选禁用。
2. 入库保存自身基础参数与循环动态、既有闭包，不保存时序／显示时段；不创建额外重叠对象。自动打开素材栏，选中新卡，保留原画布选择。
3. 元素卡单击只选择；“加入到画布”创建独立实例并选中。修改实例不回写卡片，也不影响其他实例。
4. 位图／序列／元素有类型标记。原位图再次单击编辑预处理及Alpha修边入口不变，元素不进入位图预处理。
5. 三个导入按钮在标题下独立一行完整展示；沿用现有控件，窄侧栏可换行。

## 预览边界

元素卡仅静态首帧，串行准备、最多缓存每个定义一张160×96缩略图；变更／工程切换防止旧异步结果污染新卡，不与主舞台共用Player。超过1MP或单边4096的元素不生成缩略图，提示仍可放置。该上限只限制缩略图处理，不改素材数据或导出。

程序未授信时显示原因，不执行、不允许放置；授信后重绘可预览及放置。静态预览按素材自身基础参数，而非舞台播放头和场景滤镜。

RC3-c再做统一卡片、可见项懒加载和单卡hover播放；当前原有位图／序列仍沿用旧预览行为，不宣称已全部静态／hover化。旧“收藏”入口仍保留，避免提前删掉图样／Module相关能力。共享开关／更新／范围切换留RC3-b／c，烘焙／删除／导出留RC4。没有不可操作的共享或烘焙占位按钮。

## 验收及取证

- 浏览器从实际入库按钮检查基础值而非时序值、循环动态、独立放置、选择保持、禁用条件、撤销重做、工程读回、切换工程清空、位图／序列类型、未授信拒绝及授信后程序非空预览。
- 1024及1440桌面宽度检查导入按钮行无横向溢出。
- UI技能截图工具真实点击矩形→拖动画布→收入库，证据在`tests/artifacts/rc3a-material-panel/page.png`和`report.json`；主Agent已看图。唯一加载警告为临时服务器favicon.ico 404，不影响模块或素材，无额外主题改造。
- 任务走查口径：从已选对象起算。入库1次点击，无表单，无页面切换；再次放置1次点击。此前没有元素入库用户入口，不能伪造“从N步降到2步”的对照。未做独立视觉评审或评分。
- 不跑全量verify-v4或Tauri，不将浏览器工程包往返冒称桌面路径／共享持久化已验收。
