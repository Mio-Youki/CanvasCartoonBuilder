# 图元拓展 v1：刻度排布与轮廓嵌套

## 范围与交付状态

已实现入口、刻度排布、矩形／椭圆／规则多边形的轮廓嵌套、普通元素／组的引用排布，以及[G3角点箭头](V4_CUSTOM_SHAPES_G3_2026-10-18.md)。元素排布的参数、继承与性能边界见[元素排布合同](V4_PATH_INSTANCES_2026-10-18.md)。粒子来源、任意可组合配方与MCP接口暂不支持。

拓展是图元的声明式几何派生，不是新的对象类型或加样滤镜。不把每条刻度／每层轮廓写入结构树，也不允许生成结果递归拓展自身。默认保留源图元；关闭全部拓展后恢复源图元显示。

## UI与写入合同

> 顶部图样目录及已有拓展的新建／应用选择矩阵已实现，见[首批交付](../design/PATTERN_LIBRARY_G1_G2_2026-10-18.md)。G3自定义分类和角点箭头现已实现，下述Inspector入口继续保留；其余边界见[图样目录实施合同](../design/PATTERN_LIBRARY_INTERACTION_CONTRACT_2026-10-18.md)。

- 单图元矢量元素：成样的“外观”下方出现“拓展”入口，不要求先下钻。
- 已选图元：主Tab仅为“成样／拓展”，不再显示不可用的加样／采样，也不叠加第二套局部Tab。
- 多图元元素：先选择目标图元，同时同步Canvas／结构树选择，不能默认改全部。
- 图片／文字／程序对象只有附着图元时才提供相应入口。原生rect／ellipse／poly／line对象也支持自身拓展。
- 对象主Tab仍为成样／加样／采样；从对象的拓展入口选择目标图元后进入图元层级，使用上述两个主Tab。返回对象选择时恢复三个主Tab。
- 所有参数始终写入源图元基础配置。即使原对象时序已激活，也不生成Step／Linear覆层，不新增轨道；拓展页隐藏时序按钮。
- 继承对象显示、变换与后续蒙版／加样／采样。原路径已有的时序和图元动态可改变拓展的源路径，但这不代表拓展自身参数支持时序。
- 拓展修改不调用矢量对象重新定原点的normalizeBounds：不移动源对象或改写已有位置时序。Runtime视觉边界包含新增内容。
- 使用现有SceneMutation／颜色控件；支持实时颜色预览、一次颜色事务提交、撤销、复制、工程恢复和自包含HTML。

## 数据结构

保存于图元 `extensions`（原生图形对象可同名保存）。稳定类型ID为ticks／nested，在当前图元内唯一；version为1，未来不同类型不能复用同一个ID语义。启用时归一化写入，未使用图元不强制增加该字段。

```json
{
  "extensions": {
    "version": 1,
    "showSource": true,
    "ticks": {"id":"ticks", "enabled":true, "count":24},
    "nested": {"id":"nested", "enabled":false, "count":4}
  }
}
```

### 刻度排布 ticks

| 字段 | 用户名称 | 默认／语义 |
|---|---|---|
| enabled | 启用 | false |
| count | 数量 | 24；1..512整数 |
| offset | 起始偏移 | 0；沿全路径弧长的0..1比例 |
| length | 刻度长度 | 12；基准长度 |
| start / end | 起端位置／末端位置 | 0 / 1；相对附着点的基准长度倍数，可为负值 |
| width | 线宽 | 1 |
| color / alpha | 颜色／透明度 | 继承源描线色或填色／1；用户透明度0..100 |
| orientation | 朝向 | path相对路径／fixed固定方向 |
| angle | 角度偏移 | 0度；固定方向0度向右；相对方向0度为路径左法线 |
| major.enabled | 主刻度 | false |
| major.every | 每隔几条 | 5；第0条即主刻度 |
| major.length / width | 长度／线宽倍率 | 1.5 / 1.5 |
| variation.enabled | 节奏变化 | false；空间调制，不是时间动画 |
| variation.target | 变化目标 | length长度／angle角度 |
| variation.type | 波形节奏 | sine；复用六种路径波形 |
| variation.cycles | 周期数 | 1；沿全路径重复次数，允许小数 |
| variation.amplitude | 幅度 | 0.5；长度为相对变化量，角度为度数 |
| variation.phase | 起始相位 | 0；0..1 |
| variation.digits / interpolation | 数字节奏／连接方式 | 1595 / smooth；沿用1..9、5不偏移及128位限制 |
| variation.seed | 随机种子 | 1；仅平滑随机显示 |

闭合路径等弧长分布，不重复首尾；开放路径数量大于1时包括首尾，数量1时在中点。开放路径起始偏移使末端超出范围的刻度不再绘制，不从尾端绕回头部。路径完成度只筛选已排布位置，不把剩余刻度重新挤满可见路径。反向和起始位置复用源路径语义。

长度节奏：`length * 主刻度倍率 * max(0, 1 + 波形值 * 幅度)`；角度节奏在方向和角度偏移后增加。线宽倍率独立应用。默认圆端点，避免固定短线的端头随朝向不一致。

### 轮廓嵌套 nested

| 字段 | 用户名称 | 默认／语义 |
|---|---|---|
| enabled | 启用 | false；仅rect／ellipse／规则poly |
| method | 生成方式 | scale中心缩放／offset等距轮廓 |
| count | 层数 | 4；新增层数量，不含源图元；1..64 |
| direction | 方向 | in向内／out向外 |
| scaleStep | 缩放步差 | 0.1；逐层加减原始尺寸比例，不是连乘 |
| spacing | 轮廓间距 | 6；源路径局部坐标距离，仅offset显示 |
| rotation | 旋转步差 | 0度；第i新增层旋转(i+1)倍 |
| pathStep | 逐层起点偏移 | 0；每层增加路径归一化起点。描线在虚线或路径显现启用时显示；填充／色带在显现启用且中心展开时显示，不依赖当前完成度 |
| style | 外观 | stroke描线／fill实心填充／bands层间色带 |
| width / widthStep | 描线宽度／宽度步差 | 源线宽或1／0；负宽度结果截为0 |
| color / alpha | 颜色／透明度 | 继承源色／1；所有层共用 |

中心缩放围绕源图元几何框中心，缩放到0前停止。等距采用凸闭合折线平行偏移，椭圆和圆角图形为采样折线近似；收缩至中心半平面失效或局部曲率反转前停止，显示提示。自由多边形不提供嵌套，带路径波形时不运行等距偏移，并提示选择中心缩放；不能暗中fallback。

色带使用相邻轮廓的even-odd区域；若相邻层有旋转并交叉，表示两轮廓的奇偶差区域，不是通用布尔形状编辑器。第一版不提供多层独立配色。嵌套描线复用源虚线、使用圆端／圆转角；完成度按每层实际路径弧长显现。填充默认保持完整；源图元为中心展开时继承该方式。

## Runtime与性能合同

顺序：完整源路径（含平滑／波形）→源图元绘制→嵌套→刻度→所属对象的处理管线。构造不产生逐像素读回。

- 独立模块 `59d-path-extensions.js` 导出normalize／active／eligible／build／paint／bounds／contains。
- 通过弧长表与二分查询位置，实例共享已编译的节奏函数。
- 每图元最多512刻度、64嵌套层、65536派生路径点；按嵌套再刻度分配点预算，触及点数预算会提示。高精度椭圆可能在到达配置层数前触及预算。
- 全局LRU最多32份结果，派生点总预算262144；不能用“每图元8份”乘出无上限内存。几何与视觉边界同时缓存，重复播放复用；完成度不改变完整排布几何。
- 图元形状／局部动态变化仍可能重建几何；不是承诺所有高层数动态图样都可满帧。对象整体变换复用局部几何。
- bounds和hit接入统一路径模块及Canvas拾取；效果胶囊／粒子精灵等使用的内容视觉边界包含拓展，不裁到原始w/h。

## 四层落点与验收

| 层 | 落点 |
|---|---|
| 注册／协议 | pathExtensions的ticks／nested稳定ID及本合同；不注册为EffectRegistry加样／采样卡片 |
| Inspector | classic-v4-path-extension-control.js共享参数；classic-v4-inspector-controller.js管理入口和基础值事务 |
| Runtime | 59d模块；59b统一绘制／命中；59a边界；60笔触先保留完整路径；Canvas拾取与primitive提升保留extensions |
| 测试 | v4-path-extensions-contract.mjs、browser/v4-path-extensions.mjs；接入verify-v4 |

已验证：等弧长、首尾去重、主刻度、数字节奏、固定seed、几何与边界缓存、全局缓存上限、收缩停止、波形等距明确提示、原数据不改；浏览器真实参数写入、渐进展开、扩框和命中、撤销、对象复制粘贴、多图元目标隔离、时序已激活时仍只改基础值、项目恢复和自包含HTML。

透明背景下，原绘制与开启空染色加样胶囊的Alpha逐字节一致，范围一致；Canvas预乘色往返可能有RGB舍入，实色区域最大允许2级差，不把它误写成几何裁切或完全像素相等。

额外通过：原生图形提升为组合图元时保留拓展；填充／层间色带的中心展开与命中使用同一裁切范围；默认保持完整填充；拓展颜色透明度为0时不产生可见墨迹。
