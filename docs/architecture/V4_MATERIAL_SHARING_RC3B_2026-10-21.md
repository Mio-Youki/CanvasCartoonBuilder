# RC3-b：素材显式共享与更新

状态：2026-10-21已实现针对位图／序列／元素的显式发布、更新、取用和移除。遵循[D2／D3决议](../design/RC3_MATERIAL_PANEL_DECISIONS_2026-10-21.md)；RC3-c统一预览／旧入口替换与RC4生命周期仍未完成。

## 1. 身份与数据

- 素材定义、画布实例、发布条目、内容hash各自独立。修改画布实例不回写素材，不让“更新共享”误亮。
- 项目新增编辑器元数据`materialShares`：key为`EditorV4Resources.key`产生的`asset:<encoded-id>@1`或`element:<encoded-id>@1`；值仅为`{publicationId,publishedHash,localHash}`。最多1024条，hash为SHA-256。`localHash`是本地依赖重连之后的资源包hash，不直接套用发布包hash。
- 发布条目为`tosampool-material-publication/v1`，包含`id/name/kind/root/hash/revision`。随机发布ID稳定，revision递增用于并发检查；更新内容不创建第二条同名发布。
- 内容仍为既有`tosampool-resource-package/v1`完整闭包，由既有Resources校验、导入、冲突及Module边界处理，不建立新Runtime。
- 同名不同发布保留，显示短序号；同字节内容可由不同发布引用。移除一条不会删掉另一条发布共用的内容。

`materialShares`仅为显式发布关系，不是实时同步、共享库必需依赖或程序授信。工程保存保留；网页交付剥离，不改变最终Runtime画面和数据量。已移除条目的旧关系可留在未打开的工程，重新查看时以库实际记录判断为关闭，不自动改写其他工程文件。

## 2. 库存储与升级

复用`v4-resource-library.js`，默认IndexedDB数据库由v1升至v2：原`packages`不改，新增`publications`与`shared-content`。旧收藏包照常读取，不凭同名猜测它与新发布关系相连。

发布／更新／移除在同一readwrite事务中检查预期revision，写发布与内容，清理无发布引用的managed内容。旧版本不无限积累，也不删除旧收藏packages。内存存储提供相同事务语义供合同验证。读取与写入均不执行程序源码。

共享库是明确选择的本机持久化，不代表恢复上次项目已开放；IndexedDB数据仍受浏览器profile／origin及宿主管理，未宣称原生目录Vault或跨设备同步。Tauri宿主专项验收未运行。

## 3. 界面行为

素材标题下的导入按钮行维持三个独立按钮，完整展开。内容区新增“项目／共享”范围；项目选中卡片提供“共享”开关，成功写库后才亮；等待时禁用并反馈，失败不伪装成功。

素材定义或位图预处理内容变化后，出现“更新共享”。画布X/Y、比例、效果或动态实例变化不回写定义。其他工程已更新同一发布时提示“共享已有新版本”，不允许以旧副本无声覆盖；可先取用新版，或明确取消共享再另发。

共享卡“加入到画布”先将完整闭包复制到项目，再创建独立实例并切回项目。相同发布版本且本地定义未改时复用项目定义、仍新增画布实例；本地改过或共享已更新时按既有冲突规则创建变体，旧副本不变。程序不继承原工程授信：未信任时只导入项目定义并说明需显式信任，不执行、不自动放置。

项目关闭开关与共享卡“移出共享”都是全库移除发布，均确认；取消保留原状态。移除不删当前或其他工程的素材与画布对象。它不是RC4的“删除项目素材”。旧收藏页面暂保留，图样／Module旧入口尚待RC3-c迁移，不强行合并或提前删除。

共享卡当前为名称／类型／动作的最小功能投影；完整静态缩略图、统一选中动作及单卡hover预览留RC3-c。位图／序列旧预览尚未统一，不能声称RC3整体完成。

## 4. 状态、失败与性能

异步准备先冻结工程输入；事务前检查当前工程身份／revision，取用准备完成后再一次提交并可撤销。并发更新用库revision检查，旧请求不能覆盖新发布。

共享库事务与工程历史不是同一原子域：Ctrl+Z只撤销项目关系／取用，不会默默改写全局共享库。若库提交已经成功、工程随后变化，保留真实发布结果，明确提示当前工程未写入，不能把已完成的外部写入称为撤回。之后可在共享查看或移除；不自动删掉可能已被别处使用的条目。

选中卡共享状态使用定义／依赖的标量快照缓存，不包含画布entities／timeline。拖动实例不重新捕获／hash大图片，定义实际变化、项目切换、范围切换、操作完成或窗口重新获得焦点时更新状态。原始locator字符串按值比较，不用长度代替内容，也不丢掉同长度图片替换。

| 数据／Registry | `v4-material-sharing.js`：元数据校验、状态、发布、独立取用及重复复用；`vnext-scene.js`与CLI校验器共用验证入口 |

合同检查发布身份／显式更新／实例不回写、CAS、同名同内容不同发布、内容清理、跨工程复制／重复复用、本地旧副本保护、远端更新拒绝、工程包往返／交付剥离、校验／工程切换／存储失败。

浏览器实际点击共享开关与更新，跨工程两次放置仅一个素材定义；取消／确认移除不改画面；刷新后持久读取；单独v1测试数据库升级仍保留旧收藏。补验位图预处理触发更新及程序跨工程仅入库、不继承授信。针对性回归项目素材入口、旧资源库与旧资源UI。未跑全量verify-v4、桌面Tauri或跨设备同步。
