# 实际蒙版预览：U3收尾

日期：2026-10-25。承接[多图形与来源分组](V4_MASK_SHAPES_U1_U3_2026-10-25.md)，遵循[统一蒙版合同](V4_UNIFIED_MASK_CONTRACT.md)。本批完成对象／场景的实际预览；粒子范围的新出生／显示模型仍在U4。

## 操作语义

- 对象成样的蒙版、每条场景滤镜的范围蒙版增加共用“预览蒙版”按钮；没有蒙版时不显示。开启后按钮为“返回画面”，有`aria-pressed`状态。
- 舞台显示黑白灰：白色保留／生效，黑色隐藏／不生效，灰色为部分作用。预览的是遮罩值，不是消费者本身的RGB、透明度或最终效果画面。
- 图形合并、反相、跟随、几何换基、Alpha／亮度、完整对象／组来源及其自身动画／时序均由正式求值路径计算。来源处理仍使用已保存的显式档位，不因为预览自动删掉加样／采样。
- 对象预览使用该对象当前胶囊的有限范围；场景滤镜使用整幅画布。反相不能让对象处理范围以外变白。
- 通过Inspector同一按钮、舞台“返回画面”按钮或Esc退出。单纯进出不改变选中对象／下钻、时间位置、效果轨、Inspector位置或图形编辑草稿；编辑手柄暂时遮住，退出后恢复。
- 不允许在预览舞台上误拖对象；Inspector仍可修改蒙版参数，正式编辑照常记录历史。切换到另一对象、移除该蒙版或打开另一工程时自动退出；不会将旧项目的遮罩带到新项目。
- 已有绿色范围编辑器仍是编辑工具，不把绿色示意轮廓冒充此实际灰度预览。粒子入口暂不提供预览按钮。

## 四层落点

### 合同与状态

预览只存于`EditorClassicV4ViewController`的`maskPreview`，形如`{scope:'object',ownerId}`或`{scope:'scene',effectId}`，不写Scene、MaskState、timeline或资源目录。`setMaskPreview`和`subscribeMaskPreview`是共用入口。依旧全部No，不注册新效果或参数轨。

### Inspector与画布

`renderMaskFields`调用`maskPreviewField`，对象／场景共用。开关时只同步按钮文字和状态，不重建整个Inspector，因此不会为预览打断滚动和焦点。预览按钮的pointerdown不触发父效果卡换轨。

View使用原画布和原Workspace Player；临时遮住选择框和绿色编辑叠层，增加透明交互屏障及返回按钮。绿色编辑器通过View订阅暂停显示，不取消草稿或重建编辑状态。退出时恢复仍存在的入口焦点，Esc在下钻／蒙版编辑快捷键之前处理，避免顺便退出编辑或取消选择。

异步保护有两层：

1. View令牌阻止已过期素材／Player准备结果绘到画布。
2. 预览版本参与调度完成校验；等待期间发生切换，保留显式重绘原因。不能用旧完成结果清除新视图的dirty状态，也不能在暂停时把必要刷新当普通播放帧限掉。

### Runtime

`renderTo(canvas,time,{maskPreview:target})`进入独立诊断分支，`modules.renderer.maskPreview=1`声明支持。使用正常frame、对象胶囊范围、`masks.apply`、maskSources缓存和pathInstances上下文，不再画另一套简化几何。

临时白色表面经过正式蒙版，再合成到黑色底上获得不透明灰度。仅增加Canvas合成，不为预览单独读取全帧像素；亮度提取的成本仍取决于来源本身。单次预览同样限制8192边长／16MP，超限明确提示，不静默缩减来源效果。

预览不执行消费者的背景／加样／采样／场景滤镜或转场。对象来源自身的完整处理仍执行；可沿用既有对象GPU会话，但不等于蒙版预览新增GPU算法。预览耗时不回传Auto画质预算，避免查看遮罩改变随后正常画面的自动档位。

正常Runtime统计与工程无预览开关；返回的预览统计带`maskPreview:true`供View识别。下一次不传该选项，直接恢复正常渲染。保存／工程打包／测试HTML和其他导出不会读取View预览状态。

### 测试

- `tests/v4-mask-preview-contract.mjs`：能力标记、非法scope、缺失蒙版／目标、无Canvas拒绝，输入工程不变。
- `tests/browser/v4-mask-preview.mjs`：Alpha／亮度、反相、动态完整来源、有限对象范围与实际黑白灰像素；同Player恢复正常结果；预览不改Scene／revision／历史；对象选择／下钻／时间／轨道／滚动／编辑草稿／Esc保持；预览期间导出仍为正常画面；场景滤镜预览不换轨；打开新工程／移除蒙版清理；暂停静态场景下Player异步准备与切换竞态。
- 多图形真实像素／画布编辑和完整来源浏览器回归，以及既有Runtime smoke、Workspace、历史、预览调度和蒙版资源合同通过。
- 新工程按Workspace作用域清理旧绿色编辑草稿／手势，直接丢弃临时状态，不执行旧工程的cancel快照；同项目的历史恢复仍使用原作用域。
- 已纳入根`verify-v4`，未跑全量verify-v4或Tauri验收。
