# 图元拓展：元素排布

## 范围

沿源图元路径引用普通元素或组，不复制结构树实体。支持图片、文字、矢量、程序元素及普通组；本轮按用户确认排除粒子发射器和包含粒子的组。配置保存于`part.extensions.elements`，原生图形也可保存同名配置。不新增独立时序，全部只写基础值；来源已有的显示时段、参数时序、动画和对象效果继续生效。

## 字段与交互

| 字段 | 默认 | 语义 |
|---|---|---|
| id / enabled | elements / false | 稳定ID与渐进开关 |
| sourceId | 空 | 合法顶层元素／组；组不展开为独立候选 |
| count | 12 | 1～256个实例 |
| offset | 0 | 全路径弧长比例；闭合绕回，开放超出末端的实例隐藏 |
| scale | 1 | 保存倍率；界面显示百分比100 |
| orientation | path | 相对路径切线；fixed为固定方向 |
| angle | 0 | 角度偏移，单位度 |
| along / normal | 0 / 0 | 沿切线／左法线的统一偏移 |
| keepSource | true | 是否在原位置保留来源，不改写来源hidden |

闭合路径首尾不重复，开放路径包含两端，数量1位于中点。完成度筛选完整排布位置，不将剩余实例挤满当前可见路径。

选中图元时主Tab只有成样／拓展；对象仍为成样／加样／采样。对象成样外观下的入口先选择目标图元，不添加重复局部Tab。编辑样本提供移动、旋转手柄，统一改变所有实例的along／normal／angle；缩放通过参数调整，不提供每实例独立编辑。一次手势一次撤销，Esc取消当前手势，再次Esc退出；切换项目不允许旧手势快照写入新项目。

## 来源继承

- 根来源静态世界坐标不带入实例。锚点为其基础布局框中心，不随动画中心漂移，因此bob、时序位移不会被重新居中抵消。
- 继承内容、图元、动画、透明度、对象处理效果，以及组成员的相对变换和内部混合。不是截取已合成的整个场景，不继承场景滤镜。
- 根来源的背景相关混合不继承；由载体图元和所属对象的混合控制。组成员之间的混合保留在来源精灵内部。这是本轮用户确认的边界。
- 手动隐藏或时间轴隐藏来源时，实例也隐藏；keepSource=false只是将原来源从主场景绘制和拾取中排除，引用渲染仍可用。
- 禁止自身、祖先与间接引用循环，包括经组成员、蒙版引用等形成的循环。拒绝粒子来源；不静默替换来源。
- 图元蓝框仍编辑路径本身；所属对象视觉范围、胶囊边界和命中包含排布内容。实例命中使用来源胶囊矩形，不增加逐像素Alpha读回。

## 渲染与预算

每帧每个来源共享一张精灵，多个实例只重复绘制精灵，不为每个实例重新执行来源效果。动画使精灵随帧重建；本轮没有跨帧位图缓存承诺。组按成员顺序绘制，来源边界复用对象胶囊的统一计算，包含加样及ASCII等边距。临时表按Scene和Frame隔离，所有离屏资源在finally释放。

每图元最多256实例，和既有派生几何共用65536点预算；几何LRU沿用32项／262144点上限。来源精灵单边最多8192、单张最多16777216像素、每帧累计最多33554432像素。超出预算不继续分配，记录跳过；单来源计划可返回预算状态。高成本来源仍可能卡顿，不承诺任意数量或尺寸满帧。

覆盖等弧长、首尾、边界命中、循环拒绝、组与五类元素来源、隐藏、动画、混合隔离、单次共享、样本拖动／旋转／取消／撤销、项目切换中断手势、项目恢复和自包含HTML。夹具1与64实例都只构建1张来源精灵，像素处理量均为432；这证明共享路径，不代表所有来源同样快。
