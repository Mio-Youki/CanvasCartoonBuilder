# 图案场（Pattern Field）规范

状态：迁移中。本文定义 ToSampool 中所有线纹、点阵、图像 tile 与亮度网点映射共同使用的创作语言；它不要求它们使用同一条像素渲染路径。

## 目标

- 用户只学习一套“格、图元、相位、旋转、锚点”的语言。
- 静态图案以 tile / Path 缓存为优先，不能因为图案填充拖慢编辑器。
- 亮度驱动网点映射保留独立采样器；它会读取对象图像，不能伪装成普通纹理。
- 旧 `fillPattern` 的 `lines / dots / checker` 数据继续可读；新 UI 仅添加可推导的 `lineMode` 提示。

## 基础模型

```text
Pattern Field
├─ 格：cell、rotation、phaseX、phaseY、anchor
├─ 图案：line / grid / layers / dots / image-tile
├─ 图元：circle / square / triangle / pentagon / line
├─ 覆盖：size（图元尺寸或线宽）与 cell 的比例
└─ 映射：none / luminance（亮度控制网点尺寸与颜色）
```

### 参数语义

- `格距（spacing）`：相邻线中心或相邻格点中心之间的距离，即图案的重复周期；线宽／图元大小只决定周期内的占用比例，不能再把“空白间距”当作第二种周期。
- `X / Y 相位`：将整张图案在画布坐标中平移的像素量；它不改变格点之间的关系，适合静态定位和纹理运动。
- `错列相位（rowPhase）`：仅在点阵为“错列”时有效，表示奇数行相对偶数行横向偏移 `0~1` 个格距的比例；`0.5` 是蜂窝式居中错列。

### 线类

| UI 类型 | Portable Runtime 表达 | 缓存策略 |
|---|---|---|
| 单线 | `lines + layers[1]` | 小 tile 或固定结果缓存 |
| 网格 | `lines + layers[2]`，角度差 90° | 小 tile 或固定结果缓存 |
| 叠线 | `lines + layers[2..3]`，每层独立方向 | 不强求小 tile；缓存固定结果 |

`叠线`允许独立角度、线宽与格距，因此可能没有小的无缝 tile。它是高级模式，不应以牺牲表现力换取错误的重复纹理。

### 点类

点阵使用格点原语：

- 点阵：所有格点都放置点图元；可选择圆点、三角、矩形、五边形、六边形、错列与覆盖率。
- 棋盘不作为独立用户类型保留：它与“矩形点阵 + 规律留空”的辨识差异不足，反而增加一组难以解释的参数。

## 三个渲染适配器

| 适配器 | 输入 | 输出 | 是否读取源像素 |
|---|---|---|---|
| 路径填充 | Pattern Field + 图元路径 | 被路径裁切的图案 | 否 |
| 纹理叠加 | Pattern Field + 对象 Alpha | 与对象混合的图案层 | 仅读取 Alpha 裁切，不做颜色采样 |
| 网点映射 | Pattern Field + 源图 | 明暗控制大小、保留原色的透明网点图像 | 是 |

网点映射的基础网格来自“采样格”共享控制器，但不再另设同义的“间距”：其 `单元倍数` 定义为采样格的倍率，真实输出单元为 `sampling-grid.size × halftone.size`。例如采样格为 2、单元倍数为 4 时，网点单元为 8×8 输出像素。网格旋转默认 `0°`；旋转格点保持浮点位置。网点大小由亮度决定，边缘 Alpha 只决定是否生成与点大小，不再二次裁切完整网点；对象胶囊会留出最大点半径的透明边距。默认每格保留量化原色；开启“双色”后只使用该效果的深／浅两色，严格保证两色输出。普通纹理可以选择共享该格，或在高级模式解除关联，拥有独立格距。

## 性能合同

1. 静态程序图案优先缓存小 tile；相位运动只能平移坐标，不得每帧重建 tile。
2. 多方向叠线可使用与目标同尺寸的缓存，只有图案参数、范围或画布尺寸变化才失效。
3. 网点映射先缩放到 `cell` 对应的分析网格再读取一次 `ImageData`；不得为每个网点重复扫描完整对象像素。
4. 网点位置、旋转三角函数与形状 Path 必须按图案签名缓存；动态源只重新采样亮度。每个网点从低分辨率分析格取一组代表 RGB，并按量化后的颜色分桶为 Path2D 批次；边缘 Alpha 只参与点大小／准入，不得裁断完整点。双色开关改为两色分桶，严格限制为深、浅两个填充批次。
5. Auto 预览不得改变采样格或网点单元；仅显式 Draft 可降低预览工作分辨率，导出始终使用完整质量。

## 图案运动（Step）

图案运动是 Pattern Field 的可选层，而不是另一套 FX。填充与纹理叠加共用同一个 `motion` 字段；启用后由 Runtime 在离散 tick 上改写图案参数，因此不会产生连续插值或非闭合循环。

| 下拉预设 | Step 中改变的图案参数 | 渐进显示参数 |
|---|---|---|
| 图样漂移 | `phaseX / phaseY` 沿整数格距前进 | 周期、步数、横／纵循环格数 |
| 像素跳格 | `phaseX / phaseY` 按像素跳距跳转 | 周期、步数、横／纵跳距 |
| 随机印刷 | `phaseX / phaseY` 依据 seed 跳到确定位置 | 周期、保持次数、横／纵范围、种子 |
| 图样呼吸 | 线宽或点图元大小 | 周期、阶数、大小幅度 |

- 四个预设在 UI 中为单选下拉：一次只能给一张图样附着一种运动；可同时存在于不同对象或不同效果卡。
- 时间以 `period × steps` 分成离散状态。相同 `seed`、同一时间和同一 Scene 必须得到同一图案，循环末尾回到初始状态。
- 静态图案继续命中 tile / 结果缓存；运动图案复用同一几何规则，只跳变相位或尺寸。预览调度器会把已启用的 `fillPattern.motion` / `texture-overlay.motion` 识别为时间相关。

## Inspector 规则

- 纹理不再打开独立设置弹层。启用“纹理填充”或“纹理叠加”后，在当前 Inspector 卡片内渐进展开参数和预览。
- 基础类型只显示必要参数；选择“叠线”后才显示每层角度、线宽与格距。
- 颜色、透明度、混合方式继续复用各自的通用组件；图案面板不重复定义颜色 Alpha。

## 迁移顺序

1. ✓ Inspector 统一单线 / 网格 / 叠线 / 点阵术语，并删除 v4 主工作流中的纹理弹层；启用后在当前卡片内渐进展开。
2. ✓ Runtime 抽取 Pattern Field 几何生成器，供填充与纹理叠加共用。
3. ✓ 可严格周期化的单线、正交网格与点阵使用小 tile；任意叠线与无法严格周期化的图案保留固定结果缓存。
4. ✓ 网点映射先缩小到格点分辨率读取像素，旋转格点计划和同色 Path2D 批次缓存；无 Path2D 的环境安全降级。
5. ✓ 接入四种 Step 图案运动：图样漂移、像素跳格、随机印刷、图样呼吸；填充与纹理叠加共用其数据与 Runtime。
6. 待做：接入图像 tile；图像作为“半调符号”另行受网点预算约束。
