## 已确认的产品边界

- 项目素材最终只有 `image`、`sequence`（以及未来 `font`）三类；精灵图不是长期资产类型。
- 精灵图确认切帧后立即烘焙成 `sequence`。不保存原精灵图、切分规则、Aseprite JSON 或 Godot 描述文件。
- `sequence` 与普通图片共用尺寸、去背景等预处理；配方逐帧执行。
- 项目素材将来必须自包含。跨项目导入复制素材字节与 recipe，绝不建立隐式外链。
- JSON 只在导入精灵图的临时切帧阶段作为读入辅助；解析失败必须可退回手动网格。

## 临时 FrameLayout 合同

切帧向导内部只使用以下临时对象，不写入项目文件：

```js
{
  frames: [{ x, y, w, h, duration? }],
  order: 'row-major' | 'column-major',
  clips: [{ name, from, to }] // 可选，当前 UI 不持久化
}
```

- 手动网格与 JSON 都必须先归一化为 `FrameLayout`。
- 当前 Runtime 采用统一 fps；JSON 的逐帧 duration 在 UI 中折算为平均 fps，并明确不伪装为逐帧时长支持。
- 解析到旋转帧或空帧时必须报告，不得静默导入错误画面。

## 不得漂移的实现规则

1. 色板、量化、再采样仍属于 Scene「采样」效果，不回流进素材 recipe。
2. 预处理确认前，任何导入文件只存在于本次内存会话。
3. 确认切帧 → 统一预处理 → 确认入库，是唯一进入 `state.sources` / V4 asset 的路径。
4. 新增素材能力必须同时写明：Registry/数据、UI、Runtime/Resolver、自动测试四个落点。
