# 路径波形：六种节奏、数字周期与平滑随机

## 参数表

| 字段 | UI／默认 | 约束 |
| --- | --- | --- |
| strokeWave.type | 波形节奏／sine | sine正弦、triangle三角、saw锯齿、square方波、digits数字节奏、noise平滑随机 |
| strokeWave.digits | 节奏字符串／1595 | 仅digits展开；1～9，可用空格／逗号分隔，规范化后最多128位；空串、0、字母报错，不静默删掉错误字符 |
| strokeWave.interpolation | 连接方式／smooth | 仅digits展开；hold阶梯、linear直线、smooth平滑 |
| strokeWave.seed | 随机种子／1 | 仅noise展开；整数，随机源内部按32位处理，0也是有效值 |

一串数字＝一个波长周期。每位是等间距控制值，最后一位接第一位；不重复首位也能循环。相位以一个完整周期为单位。数字映射为`(digit-5)/4`，再乘幅度：1=-幅度、5=原路径、9=+幅度。正负沿原路径法线，不能把符号一律解释为向外／向内，开放路径与反向路径尤其如此。

不自动去均值或拉满振幅。`5555`保持原路径，`9999`恒定沿法线偏移；开放路径的固定端点包络仍会让两端偏移归零，不属于自动居中。`1595`为一轮起伏；`55595551`为平稳段夹杂正负起伏。

## 连续曲线与随机源

数字平滑采用周期、保形的三次Hermite：相邻差值同号时取调和平均切线，平坦段／极值处切线为0。控制点之间不越过两端值，连接处一阶连续；不是每段smoothstep，因此不会在每个中间值都减速停顿。

阶梯保持当前数字，直线连接相邻数字。方波和锯齿本身存在跳变，最终折线会连接跳变两侧，不保证这些类型具有平滑切线。高频细节受几何预算限制。

平滑随机是固定8个一维控制值，来自现有`sampling.hash(index,0,seed,0)`，再使用同一周期Hermite连接。它不是二维像素噪声、Perlin或Simplex，没有导入噪声图片或依赖库。相同seed生成相同周期，不因seek、刷新或重开随机改变；波长仍控制周期重复距离，不伪装成无限非周期噪声。

## 法线与闭合

原实现直接采用所在折线段的法线，转角处会瞬变。现在用弧长前后采样的弦方向估计切线；窗口为`min(6, 实际波长/8, 路径长度/16)`，跨闭合端点周期取样，方向退化时回退所在段方向。它缓和偏移方向突跳，但不把原有尖角强制变成光滑曲线，也不承诺任意自交路径C1连续。

封闭路径依旧匹配整数周期，末点与首点一致。开放路径保留固定端点包络。完成度按最终派生路径弧长显现；封闭填充／纹理／中心展开／命中检测继续共用完整派生路径。

## 开销与缓存

- 周期编译独立于幅度、波长、相位、路径长度和时间；这些参数变化不必重新计算数字／随机系数。
- 简单波形直接计算；数字和随机的多项式系数仅编译一次。每次曲线取值为常数级算术，无需逐帧解析字符串。
- 编译缓存最多32项，最复杂的128位数字周期系数约4KiB／项（不含JS对象）；完整几何继续最多64项。
- 几何采样按节奏复杂度自适应，最多8192段／8193点。超长路径、极小波长、很长数字串可能降采样，不承诺无限精度。
- 幅度0或全5的数字串直接复用原轮廓，不做无意义的重新取样，也不会因点数预算把原路径简化。
- 新增法线前后查找只发生在几何重建时；完成度变化复用完整几何及长度表。复杂度增加的是路径生成，不是逐像素滤镜。

## 交互与验收

真实浏览器测试发现旧工具浮层在窄窗口时向左伸入结构树，点击被遮挡；现改为视口定位、横向避开左栏并限制高度滚动，展开、参数重绘及舞台ResizeObserver更新时重新定位。没有使用强制点击或放大窗口来掩盖失败。

验收包括六类型范围／周期、数字严格映射、局部不越界、跨周期一阶连续、零种子、随机重建一致、缓存上限、幅度／相位复用编译、转角最大邻点距离；实际控件渐进显隐、错误文本拦截、seed改变像素及撤销、图元隔离、所属对象轨Step、项目恢复、自包含HTML和工具参数透传。
