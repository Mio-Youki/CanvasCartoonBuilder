# Agent图元配方接入提案：箭头实验

状态：G3已实现版本化自定义图元及角点箭头的共用生成器，见[实际合同](V4_CUSTOM_SHAPES_G3_2026-10-18.md)。G4首轮[隔离Agent使用实验](V4_AGENT_PATTERN_G4_TRIAL_2026-10-18.md)已交付并通过定向验证；通用配方执行器、动态面板注册及内部Skill仍待后续，不得混写成已交付。

> 已确认的入口、分类和选择行为以[图样目录实施合同](../design/PATTERN_LIBRARY_INTERACTION_CONTRACT_2026-10-18.md)为准。本文早期“四角箭头固定配方”已收敛为通用角点箭头；不增加创建后的载体切换。独立新建保存为自定义图元，应用保留原图元类型。以下Agent合同原则保留，不将早期建议视为已实施行为。

## 分清三项职责

R3b增量：首版[声明式模板](V4_PATTERN_PROVIDERS_R3B_2026-10-18.md)已把有限新路径定义接入共用参数表单和资源包，Agent可交付JSON而不修改编辑器源码。它不含任意表达式／算法，早期通用插件设想不能据此标记全部完成。生成格式见[Agent说明](../agent/PATTERN_PROVIDER_FORMAT_V1.md)。

1. 产品合同：定义允许的图元组合、参数类型与绑定、计算预算、版本、边界和错误行为。
2. 共用面板：读取经校验的参数声明并渲染控件，统一事务、撤销、复制、保存；不由Agent生成任意DOM／事件代码。
3. Agent Skill：识别意图、选择已有配方或生成受限配置、解释参数、固定时间渲染并审阅修改。Skill不能代替Runtime对新配方的支持。

已有ticks／nested／elements是三个固定实现的拓展类型，不是任意JSON都能执行的插件系统。初次箭头实验应先验证图元组合配方，不直接将Agent代码注入正式编辑器。

## 用户需要提供的最小信息

- 目标样式：参考图或一句构造描述，例如四角向外箭头。
- 放置范围与排列意图：画布／对象尺寸、箭头朝向、发散／聚拢；缺省可由Agent给出预览再确认。
- 主要可调意图：哪些希望成为旋钮，例如箭头尺寸、间距、粗细、圆角、缩进。
- 使用意图：静态图样，还是后续需要动画；不要求用户填写底层图元坐标、ID或时序格式。

Agent上下文还需明确提供：支持的图元／拓展字段、坐标与单位语义、允许的参数绑定规则、颜色组件、数量预算、工程写入方式、预览及审阅入口。禁止靠模型猜测未实现字段。

## 第一例建议输出

以角点箭头为第一例：矩形产生四向、正多边形产生对应顶点数量的箭头。读取语义顶点／相邻边／中心，不把曲线采样点当角点。独立新建使用默认配方；应用使用当前兼容图元。公开少量易懂参数，具体字段及范围在实现前定型。优先用直线／路径直接构造，不必用“矩形减十字”这种布尔运算倒推视觉结果；只有外观确实依赖布尔相减时才另立几何能力。

交付应包含：稳定recipeId与版本、参数声明（标签／默认／范围／步长）、结构与参数绑定、静态预览、支持与不支持说明。不允许任意代码字符串；超出声明式原语时明确报告需要新的受审模块，而不是静默返回不可编辑位图。

## 已确认的实施顺序

先接已有拓展的目录与应用，再接载体绘制和自定义图元，最后以角点箭头验证Agent输入→预览→参数修改→撤销→工程重开→导出的一致性，顺序及验收见实施合同G0～G4。其后将对应生成／验证流程收录内部Skill。先不引入配方参数时序、任意表达式解释器、通用布尔建模或全插件生态。
