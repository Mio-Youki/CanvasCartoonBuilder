# 效果审阅自动回传与共享交付：第一批

日期：2026-10-23。用户确认方向：确认后自动继续；正式交付优先直接放入共享tab，同时保留资源包结果。MCP不是前提，协议与宿主传输分开。

## 工作流与明确边界

```text
确认快照 → 本机宿主持久化任务 → 自动分流
  无备注：名称／标签／显式默认值 → 正式校验 → 资源包
  有备注：Agent总结 → 必要追问 → 用户回答 → 新版预览 → 再确认
资源包 → 浏览器现有共享库 → 入库回执 → 显示已加入共享
```

没有修改仅通过、仅名称／参数名修改、显式默认值修改，均走确定性交付处理，不为“继续下一步”额外浪费模型调用。任何备注都进入迭代路径；明确的备注可直接返回下一版，只有歧义／冲突／成本选择才追问。当前输入只有备注，没有“建议／必须”独立字段。

自动处理由独立任务执行器完成，不是自动向当前Codex聊天发送消息。新版预览只展示已验证的受限声明式图样，不支持任意JS输出自动安装。加样／采样插件尚无相应受限交付实现，本批不虚称支持。

宿主启动命令：`node scripts/serve-effect-review.mjs`。默认地址`http://127.0.0.1:8780/`；无模型适配器时，元数据交付仍自动处理，有备注会明确阻塞。登记的生产候选目前只有双色放射。

配置本机Agent的方式：`node scripts/serve-effect-review.mjs --codex <已安装codex.exe的绝对路径>`。启用前须由用户明确授权向该服务发送候选参数及修订备注；本批真实外发测试被安全审批拦截，未发送，不能说真实模型闭环已通过。后续不能绕过拦截或改用其他服务偷偷测试。

## 正式交付形式

直接返回**现有**`tosampool-resource-package/v1`（下载名`*.tosampool-resource.json`），而非新增插件执行格式。包包含声明式图样定义、参数预设、几何快照及闭包索引。结果面板显示正式名称、参数标签、默认值、可下载包和编辑器入口。

自动写共享只接受单根、单条、自包含声明式图样，禁止夹带程序模块。发布ID由定义ID及版本确定：同内容重复入库复用；同ID／版本存在不同内容时停止并提示，不覆盖用户旧数据。自动入库不等于公开互联网发布，不替用户给第三方代码授权。

入库回执只在浏览器真实写入成功后发送；宿主核对资源hash并存储回执。它是客户端提交的存储回执，不是宿主独立访问IndexedDB的证明。断线后可按同一job恢复；入库成功而回执丢失时重试复用内容，不再创建副本。

## 生产双色放射的状态

现有v1路径模板不支持旋转双色扇区；候选`candidate.js`尚未迁入正式绘制能力。因此确认会被真实接收，但生产任务返回`blocked`，说明“需要正式角向重复／双色生成器”，不会打包候选JS或伪造入库成功。

测试使用既有折线框标定义证明受支持资源的自动交付。它不是用户确认的双色放射，也没有被装进用户当前共享库。下一批必须完成放射正式能力及颜色组件绑定后，才可解除这个生产阻塞。

## 存储与安全

- 服务绑定127.0.0.1；检查Host防DNS rebinding；写接口会话Bearer授权并检查浏览器Origin；引导接口拒绝跨站；没有任意命令／文件写接口。
- 任务与Agent输出存`.local/effect-review/`（已有忽略规则），静态服务拒绝隐藏目录／越界／指向根外的文件。Agent stderr只保存在私有任务目录，不向页面回显可能含敏感信息的原始日志。
- 不以MCP为前提，也不提供自动权限提升。任务重启时运行中标为中断，不自动重跑付费模型请求；用户可重试。
- 页面关闭时宿主仍可处理任务；共享写入需同源页面恢复在线后完成。尚无原生后台库写入，不能承诺所有窗口关闭时也已入库。
- 当前共享仍是同一浏览器配置、同一源下的IndexedDB。8780与8774、file://、其他浏览器不会互通；旧页面确认不会静默跨源重放，用户应在新宿主地址再次确认。
- 本批未提供第三方网站跨源调用权限；没有把任务数据上传到公共服务器。
