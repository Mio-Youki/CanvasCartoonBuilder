# v4 统一蒙版合同

日期：2026-10-25。状态：No及完整来源见[首批](V4_MASK_SOURCE_U1_U2_2026-10-25.md)；多图形见[第二批](V4_MASK_SHAPES_U1_U3_2026-10-25.md)；预览见[第三批](V4_MASK_PREVIEW_U3_2026-10-25.md)；粒子CPU核心见[U4](V4_PARTICLE_MASK_U4_2026-10-25.md)。执行顺序见[V4_UNIFIED_MASK_EXECUTION_PLAN.md](V4_UNIFIED_MASK_EXECUTION_PLAN.md)。完整生命周期／后端／宿主及性能仍待U5/U6。

## 1. 目标与现状

用户任务：定义一个可编辑区域，用它控制对象显示、滤镜覆盖或粒子分布，不必在不同入口重新理解一套规则。沿用当前视觉体系与渐进式Inspector，不另建专业蒙版编辑器。

| 使用位置 | 目标语义 | 当前实现边界 |
| --- | --- | --- |
| 对象成样的蒙版 | 对象可见度；仍参与mask／decorate／sample调序 | 几何、图片、对象引用；组自身尚无蒙版入口 |
| 每条场景滤镜的蒙版 | 混合滤镜前／后的画面，限定该滤镜覆盖度 | 与对象共用四类来源、多图形、通道和真实预览 |
| 粒子发射范围 | 控制出生位置与出生密度 | 四类来源／灰度／出生时变换与完整来源已实现；CPU冷启动成本仍待优化 |
| 粒子显示范围 | 控制每个粒子的透明度 | UI已改名显示范围，按中心灰度乘透明度；不作像素裁切或碰撞 |

素材去背景／Alpha修边改变素材自身的派生Alpha，不与工程蒙版共用状态；可复用编辑工具。路径图样的载体裁切、采样边缘保护属于算法规则，不新增为本蒙版列表里的来源。

## 2. 已确认的来源与控件

| 控件 | 选项／规则 | 渐进条件 |
| --- | --- | --- |
| 蒙版来源 | 无／图形／图片／场景对象 | 始终 |
| 图形内容 | 矩形／椭圆／多边形，可重复添加 | 图形 |
| 提取方式 | 透明度／亮度 | 图片、场景对象 |
| 反相 | 对最终合成的遮罩取反 | 有蒙版 |
| 跟随目标 | 跟随／不跟随，含目标变换与基础动态 | 有明确目标的静态图形／图片 |
| 位置与大小 | 画布编辑时渐进显示XYWH | 图形／图片 |
| 显示来源 | 引用对象在正常场景中也显示 | 场景对象 |
| 预览蒙版 | 临时查看实际遮罩，再返回画面 | 有蒙版 |

上述是UI分类，不要求直接把旧`rect/ellipse/poly/alpha/element`字段改为四个同名枚举。U1须先定义版本化数据模型与桥接／明确拒绝规则；不得只换下拉框标签。

图片使用正式素材解析与预处理结果，不从另一条临时文件路径读取。保留已有素材选择、从文件导入并入库的能力；取消选择不写入半成品，不让Inspector凭空切换来源。

图片／对象亮度提取统一为`遮罩值 = 亮度 × 来源Alpha`，透明度提取为来源Alpha，均为0到1；白保留／生效，黑隐藏／不生效。提取后再反相，反相只在消费方有限画布／对象范围内定义。不同后端需共享亮度系数、颜色空间与边界约定。

## 3. 多图形

- 初始单图形；通过＋添加，支持选择、移动／缩放、复制和删除。名称／类型用于识别，稳定子项ID用于编辑，不依赖数组位置。
- 首版固定合并，允许非连续区域；重叠不能重复叠加变深，不需要图形调序。
- 反相作用于最终合并结果，不给每个图形额外提供反相。
- 不新增场景结构对象、独立图形时间轴、挖去／相交／布尔运算面板或羽化。不得因内部使用数组就把所有条目渲染成复杂卡片堆。
- 多图形尽量合并为一次路径／遮罩绘制，不给每个形状永久分配全尺寸Canvas。

## 4. 坐标与跟随

- 图形／图片跟随被控制的对象时，使用明确的绑定基准和变换链，包含父组变换及成样动态；不跟随时固定在画布。
- 场景对象来源默认使用自己的场景位置和动态，不再叠加目标对象跟随，避免双重位移。其位置通过编辑来源对象调整，不再复制一套XYWH。
- 场景滤镜没有可跟随的对象，不显示无实际意义的目标跟随开关。
- 粒子范围的跟随对象是发射器；显示范围的跟随独立于粒子出生规则。跟随不得反向改动来源数据或对象的静态变换。
- 画布编辑、包围盒、Inspector数值和真实遮罩必须使用相同坐标换算，保留既有父组仿射／几何换基能力。

## 5. 引用对象与资源闭包

用户确认读取**完整对象处理结果**：成样、对象自身蒙版、加样、采样及其动态／时序均参与；组作为来源时包含组结构和成员完整处理。不是直接调用内容绘制函数后声称所见即所得。

提取边界为“对象自身处理完成、与其他场景图层混合之前”的隔离画面；不包含其他图层、场景滤镜、编辑选框和工具覆盖层。依赖场景背景的全局混合不能顺便把无关背景带入蒙版。此边界须在U2验证和说明。

- 稳定ID引用，不以名称或列表位置识别；重命名不失联。
- 显示来源不修改原对象`hidden`。多个消费者不能互相争抢显隐；“任一有效引用要求显示，则允许正常绘制，仍服从来源自身显隐／显示时段”为拟定裁决，U2实现前以具体例子复核。
- 排除自身、包含自身的组及间接循环。依赖检查须涵盖对象处理、组成员和已有引用链，而非只比一次targetId。
- 来源缺失需有可定位提示；禁止静默变成全白蒙版或复用上个来源的缓存。
- 引用来源被隐藏仅影响正常场景绘制，不能让它作为蒙版的采样结果也消失；手动显隐／独显与蒙版取样的关系在U2明确，不借隐藏状态制造循环。
- 同帧、同来源、同求值状态共享处理；缓存不能跨项目、时间、工程revision或来源不同状态误复用。
- 入库／共享／工程保存／复制粘贴／ID重映射／烘焙／导出必须走同一依赖收集与重连适配器，不由各效果自行遍历蒙版字段。组来源保留结构，不另显式铺满素材卡。

## 6. 粒子消费规则

### 发射

灰度作为归一化的相对出生权重；白色更易出生，黑色不出生。2026-10-25后续确认覆盖U4首轮“稀疏允许减量”：非空范围默认按有效权重分配目标数量，不因包围盒内有效面积小或整体灰度低而减少数量；全黑仍为零。不得用包围盒中心兜底，不用无限拒绝重试。数量／寿命切段后，旧粒子按出生参数继续存活，新粒子使用新段参数。存活／候选预算仍有效，归一化不等于取消预算。

发射器移动只影响新出生粒子。出生时按当时发射器状态确定位置，已出生粒子继续原有轨迹，不随之后的发射器平移。旋转／缩放等初始状态同样应明确采用出生时基准，不把后续父变换重复应用到既有粒子。

任意时间定位、倒放、暂停、导出应得到一致结果：用稳定粒子身份、出生时刻和确定seed重建，不能只在播放过程中累积“上一帧出生位置”快照。对象来源作为发射分布时，须按出生时刻取样，而不是用当前帧区域重算所有旧粒子。

### 显示

原“运动范围”改名“显示范围”。按粒子中心采样灰度并乘入该粒子透明度；越界不是碰撞，不改变轨迹，不裁掉粒子跨出边界的半个精灵。需要逐像素裁切时须作为独立后续能力讨论，不能改名后假装已有。

显示范围跟随当前发射器还是固定画布，由该范围的跟随配置决定；不回改粒子出生位置。范围为空默认不额外限制显示。

## 7. 预览与时序

预览蒙版使用真实求值结果，不是简化示意图；作为临时View状态，不保存到工程、不进入历史和导出。进入／退出后保留选中对象、播放位置、滚动与编辑焦点。

用户进一步确认：所有蒙版相关参数默认No，不新增蒙版轨或参数时序按钮。旧蒙版覆层清理并保留切点、显示时段和其他参数；运行时也阻止旧值覆盖基础蒙版。跟随对象动态、来源对象自身动画／时序仍然有效，不等于冻结来源。

## 8. 性能及交付

Alpha优先走合成路径；亮度提取需要后端支持或像素读取，静态图像／静态来源应复用。动态重效果引用按实际对象处理成本验收，不承诺完全零成本。GPU不支持的组合必须按既有策略明确回退，不以无效果、旧帧或静默降质冒充支持。

正确顺序：定义／状态和资源协议 → 唯一求值／采样器 → 共用Inspector／画布编辑 → 粒子适配 → 持久化／导出／后端验收。不得仅做“同样下拉框”而保留四套不同语义的蒙版实现。

本合同不恢复局部FX，不改变对象处理阶段调序，不开放组自身新增效果，也不扩展任意代码执行能力。以上未列入的能力按原协议保留。
