# 持续图层取样、粒子形状与原图显示解耦

日期：2026-10-26，承接[一次碎裂接入](V4_LAYER_PARTICLES_INTEGRATION_2026-10-26.md)。覆盖该批“来源自动隐藏、只支持一次捕获”的行为限制。不宣称复刻AE全部粒子系统或完成GPU／Tauri验收。

## 入口与语义

选中对象并粒子化 → 粒子Inspector → 实体方式“图层切片”。保留“重复实体”原流程。图层切片下新增：

| 参数 | 字段 | 默认／选项 | 时序 |
| --- | --- | --- | --- |
| 发射方式 | layerEmission | burst一次碎裂／continuous持续取样发射，默认burst | No |
| 粒子形状 | fragmentShape | rect矩形／circle圆形，默认矩形 | No |
| 来源取样 | sampleTime | birth出生时刻／fixed固定时刻，默认birth，仅持续模式 | No |
| 来源刷新率 | sourceFps | 1～30整数，默认12，仅出生时刻取样 | No |
| 取样时刻 | startTime | 秒，默认0，仅固定时刻；一次碎裂仍称开始时间 | No |
| 显示原对象 | showSource | 默认true，两种图层模式均有 | No |

所有字段位于particle下，cellSize切片尺寸仍为正整数默认32且No。继续共用运动、外观、显示范围及基础对象轨，不另建“消逝”专用轨。数量、寿命、运动等既有Step参数仍按出生批次记录；新段不重写旧粒子。新模式字段由Runtime No过滤，控制器使用基础事务而非写入当前时序。

### 持续取样

沿用普通粒子的稳定出生序列：数量表示目标存活数量，出生间隔为寿命／数量；保留预热粒子，不新增易混淆的第二套每秒发射率。源的完整隔离画面按来源刷新率向下量化捕获，而非宣称无限精度地每个出生时刻独立绘制。已出生粒子保留其对应批次纹理，新出生粒子读取新批次；固定时刻模式共享一张快照。

出生位置按来源Alpha分配；如配置发射范围，则将其灰度与来源Alpha相乘后归一化。黑／透明不出生；非空分布不因稀疏而减少目标数量。初始位置对应取样位置，保留局部原色；不会把整张图片重复缩小塞给每个粒子。范围可引用统一蒙版组件的图形、图片及场景对象。

矩形从取样位置截取局部图像；圆形用同一图像窗口裁圆，边界之外保持透明。圆形与随机取样不保证拼回原图；一次碎裂＋矩形网格继续保证初始完整拼回（未主动缩放／随机旋转时）。第一版不支持任意自定义粒子轮廓。

### 原图与消逝

默认保留原对象；可独立关闭，不修改来源自身hidden字段。多个有效图层发射器引用同源时，任一要求显示就保留正常来源绘制。隐藏发射器不再争抢来源显隐；来源本身的显示时段、其他引用规则及内部实体的隐藏规则继续有效。

渐隐／擦除由原对象自己的透明度／蒙版／时间轴完成，粒子仅承担出生、外观与运动。本批不增加一键自动生成消逝蒙版。若同一个来源同时被渐隐，其变化也会影响之后出生粒子的纹理和有效区域；旧粒子保留出生快照。希望出生外观独立时，可使用固定时刻取样或单独的来源副本。

## Runtime及性能机制

- 新`74c-layer-stream.js`接正式粒子会话；复用particleBirths、weightedDistribution、maskSources和统一显示范围。
- 批次纹理按稳定发射器ID＋取样时间建键；ID可含冒号，不以字符串前缀猜所属关系。
- 多粒子共享纹理和分布索引；无动画且未配置额外发射范围的完整来源，复用一张静态纹理；否则按批次缓存。只保留当前候选出生批次需要的纹理，逆序跳播可确定性重建。
- 每批一次RGBA读取；缓存命中的同帧重复绘制为零像素读取。共享固定CPU合成面，不为每个粒子建Canvas。
- 纹理在首次获取2D上下文时声明CPU驻留；不能从已创建GPU上下文的普通表面池取Canvas，再以为重新传willReadFrequently会改变其后端。该修正解决了动态纹理已缓存、却在每片绘制时反复搬运的问题。
- 批次纹理16MP总预算（不含已有蒙版缓存和一个最多16MP合成面）；超预算明确报错，提示降低来源刷新率、缩小来源或改固定时刻。不反复淘汰仍存活的批次造成每帧重新捕获，不自动删效果或降低刷新率。
- 普通数量600／存活4096／候选16384预算保留。一次碎裂的规则网格仍使用独立切片数量预算。
- layerFragments能力提升至2；公共导出要求该版本，持续模式额外要求layerStream.version>=1，旧Player明确拒绝。正式与内联Runtime同步。

## 验证

- 动态红／蓝来源在同帧粒子中呈现两种出生纹理；60个粒子共享24个时间批次，不为每粒子捕获。固定时刻只有一个批次，没有串入后续蓝色。
- 静态来源600个粒子只构建一个批次。
- 同一窗口矩形256个有效像素，圆形200；实际圆形裁切成立。
- 发射范围限制后仍生成600个有效位置，全部在范围内；默认保留来源、显隐可单独修改。
- 任意时间／逆序／缓存清理后重建像素一致，缓存命中重复绘制读取0、构建0。
- 真实Inspector渐进参数、工程ZIP重开、自包含测试HTML启动通过。
- 一次碎裂初始像素、普通粒子范围／动态来源／序列／资源闭包回归通过。
