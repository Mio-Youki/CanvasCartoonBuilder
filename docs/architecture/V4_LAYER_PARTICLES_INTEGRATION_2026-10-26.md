# 图层切片正式接入

日期：2026-10-26。承接[独立实验](V4_WEIGHTED_PARTICLES_LAYER_PROBE_2026-10-25.md)，本批接入正式Player、Inspector、工程ZIP及测试HTML；未声称U5/U6全量或Tauri验收完成。

## 用户入口

在场景结构选中图片／文字／矢量／程序元素，点击粒子化；粒子Inspector → 实体 → 实体方式，选择“图层切片”。普通粒子仍是“重复实体”。本轮不开放组和粒子发射器作为来源。

图层切片捕获开始时的完整对象，包括自身对象效果、Alpha和变换，不带背景、其他图层与场景滤镜。引用源暂停正常场景绘制，避免留下完整原图；发射器隐藏或不在显示时段时恢复正常来源显示，不改来源hidden状态。正常来源仍服从自身显隐和其他引用规则。

## 参数与前端同步

| 面板 | UI | 字段 | 规则 |
| --- | --- | --- | --- |
| 实体 | 实体方式 | particle.mode | sprite／layer，No |
| 实体 | 切片尺寸 | particle.cellSize | 正整数，默认32，No；仅layer显示 |
| 实体 | 开始时间 | particle.startTime | 秒，默认0，小于循环周期，No；仅layer显示 |
| 发射 | 数量／发射范围 | 原字段 | 仅重复实体显示；切片数量由尺寸和有效Alpha决定 |
| 发射 | 随机种子 | 原字段 | 两种模式共用 |
| 运动／外观 | 寿命、速度、方向、扩散、重力、风力、旋转、缩放、透明度、淡出 | 原字段 | 复用原有Step入口；图层批次读取开始时间所在段的出生参数 |
| 运动 | 显示范围 | particle.motionRange | 继续使用统一蒙版，按切片中心取灰度 |

实体播放帧序号／按寿命播放仅在重复实体中显示；图层取开始时间的实际来源帧。结构字段No有Runtime时序过滤，不能通过普通时序覆层切换模式／切片尺寸／开始时间／来源ID。

切换到图层模式时，将粒子尺寸恢复1、尺寸差异0、初始旋转0、旋转差异0、粒子透明度1，以免雪花等旧预设破坏初始拼回；操作进入原有历史事务。之后用户仍可主动修改。来源本身透明度已烘入快照，不再重复相乘。

开始前保持起始快照，开始后一次性飞散，寿命后消失，每个场景循环重放。不是持续发射，不在每片内部继续播放来源动画。后续时序段不重写已经出生的图层批次。发射器开始时的变换作为整体附加变换；默认零位移／单位比例时与来源原位拼回。来源的动态按捕获时间取值。

## 实现与开销

- 新Runtime模块`74b-layer-fragments.js`；正式粒子会话管理其缓存，切换项目／编辑重建／clearCaches／dispose释放。
- 完整来源走既有maskSources隔离捕获；一份RGBA、一次像素读取、Alpha有效格扫描，空格跳过；边缘不足一格保留。
- 每片共享同一张来源画布与缓存运动常量。复用particleBirths.motion，无逐帧随机重算和图像读取。
- CPU切片先合成到一个会话共用离屏画布，再绘到主画布，避免浏览器在截图／像素读取后切换加速路径造成半透明叠加差异。无旋转／缩放路径使用整像素目的位置。
- 离屏画布最多16MP，缓存来源总计16MP，每个发射器最多16384有效片；超过明确报错，不丢片。普通粒子的600上限未提高。
- 默认切片32依据本批正式Player测试选择；尺寸减半，片数约四倍。旋转／缩放及重效果来源另有成本。
- 公共Player导出新增layerFragments.version门禁，旧Player不能静默按重复实体播放。工程、素材依赖闭包继续使用原sourceId机制。

## 验证与数据

真实浏览器通过：图片／矢量／文字初始像素一致（本夹具误差0），源不会额外叠画；飞散后任意时间重复定位像素一致，清缓存重建误差0，寿命后透明；切片缓存首帧构建1次、后帧0次。真实Inspector模式切换、切片修改、工程ZIP恢复和导出自包含HTML启动通过。普通粒子统一范围及600权重分配回归通过。源图为奇数尺寸，覆盖末尾不足整格情况。

本机Edge无头，正式Player，1024×576，无旋转，CPU；预热8次后20次，非编辑器整帧或Tauri保证：
