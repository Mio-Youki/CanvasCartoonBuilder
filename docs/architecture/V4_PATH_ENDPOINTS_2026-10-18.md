# 路径完成度：端点样式

## 行为与字段

适用于矩形、椭圆、自由／规则多边形、直线和像素笔触；在共用完成度控件下增加渐进开关。不是描线的平头／圆头设置，而是额外可见标记。配置保存于源图元`pathEndpoints`，原生图形对象同名。

| 字段 | 默认 | 语义 |
|---|---|---|
| enabled | false | 端点样式开关 |
| type | circle | circle圆点／bar垂直线／object引用对象 |
| size | 8 | 圆点直径 |
| width | 12 | 垂直线横跨路径的总长度；线粗沿用路径描线，最小1 |
| sourceId | 空 | 引用来源对象／组，沿路径切线朝向，使用来源原尺寸 |
| start | false | 显示绘制起点 |
| end | true | 显示当前完成度终点 |

圆点与垂直线沿用路径描线颜色／透明度，无描线时沿用填色，没有实色时使用白色。开启不修改源描线端帽。起点固定在绘制开始位置，终点跟随当前完成度；遵守闭合路径起始位置及反向绘制。0%不绘制标记，100%闭合图形的首尾重合时只画一次。平滑和路径波形先完成，再在同一条实际路径上获取位置和切线，不另用包围框猜测。

样式字段本轮仅改基础配置，不增加独立轨或Step／Linear；`strokeCompletion`继续沿用所属对象轨的Linear，标记自然随动。工具栏共享组件可设置普通标记；引用来源在对象／图元Inspector内选择。

引用对象复用元素排布来源合同：根静态世界位置不带入，保留自身动画、透明度和对象效果；根混合由载体统一控制；组内混合保留。排除粒子、组内独立来源、自身及间接循环。原来源仍保留，不新增隐藏来源开关。
