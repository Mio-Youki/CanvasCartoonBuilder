# 路径显现与箭杆参数

意图：既有编辑器的局部流程优化与功能修复，沿用现有样式，不重做Inspector布局。
用户任务：普通绘制保持简洁，需要路径动画时开启显现；配置角点箭头时能得到真正尖角和明确的尾端。

## 路径显现

普通路径新增基础字段`pathRevealEnabled`，默认false。开启渐进展示完成度、反向、闭合路径起点、适用的填充显现、端点样式。虚线、路径波形、描线端点及转角独立保留。

关闭后的求值视图为完成度100、起点0、正向、完整填充、无端点标记；不写回这些值，不删除原配置或任何时序。重新开启恢复原值。缺省字段的已有数据按非默认显现值初始化，显式false优先；新建正常图元归一化为false。不是仅控制折叠的假开关。

完成度继续使用所属对象轨Linear，其余原有参数规则不扩张；开关走既有对象Step写入。当前参数视图仍由播放头求值，不新增图元轨。端点样式字段继续只写基础值。已有Linear时应先启用显现，避免显现开关false正确地旁路动画。

轮廓嵌套的`nested.pathStep`更名“逐层起点偏移”：每层相对上一层的整路径比例。描线仅在启用虚线或路径显现时显示；实心／色带仅在启用显现且填充为中心展开时显示。判断功能状态，不判断当前完成度是否小于100，因此播放到100不会令参数突然消失。

## 箭杆

参数与几何规则以[G3合同](V4_CUSTOM_SHAPES_G3_2026-10-18.md)为准。固定角度是镜像倾角而非所有箭杆平行：按角点到面积重心的方向确定左右／上下镜像；轴上的角点沿轴线，忽略微小浮点误差。in/out同步反转箭杆。对称载体保留其局部X/Y镜像关系，不将任意自由多边形强制对称，也不承诺固定倾角保留正多边形全部旋转对称。0圆角不再强制round cap/join。普通描线不受新箭头轮廓实现影响。

| 四层落点 | 本轮位置 |
|---|---|
| 注册／合同 | customShapes.definitions新增shaftMode／shaftAngle／shaftCap；PartsState保留pathRevealEnabled |
| Inspector | 共用stroke-style-control与path-extension-control，不另造面板；嵌套显隐统一 |
| Runtime | 59a显现旁路；59b／59d／59f绘制、完成度、派生路径与命中一致；59g共享箭头轮廓、缓存、边界 |
| 测试 | path-reveal-switch合同／浏览器，custom-shapes合同／浏览器，旧完成度／端点／图元几何／拓展回归 |

## 验收范围

针对性检查包含开关实际画面、保留参数、嵌套在100%的稳定入口与中心填充、独立／依附的三种端头、固定方向、圆角0、参数变化、撤销、复制、胶囊边界、项目重开和HTML。只做局部视觉自检，未独立设计评分；不修改主题、字体或新增动效，不为此重建Tauri安装包。
