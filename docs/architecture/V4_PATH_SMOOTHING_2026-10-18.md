# 像素铅笔：自适应路径平滑

## 行为合同

保留原有 `smoothing: 0..100` 字段和UI，不增加参数。0直接使用原始点；正值产生非破坏性的派生路径，固定首尾。不修改鼠标采集点，不依赖画布尺寸、舞台缩放或对象变换比例。

令笔触原始点包围盒对角线为D、原始路径弧长为L、强度为s=smoothing/100：

- 基准半径：`clamp(D * 0.02, 12, 256)`。
- 实际半径：`min(基准半径 * s, L * 0.2)`。
- 沿弧长均匀重新取样，约每路径坐标单位一点，上限8193点。
- 在实际半径范围执行三角加权平均，并按强度混合；靠近首尾逐渐减弱。
- 大于50的平滑度额外进行一次邻点距离简化，容差为 `实际半径 * 0.01 * max(0, (s - 0.5) * 2)`。仅删除距上一个保留点不足容差的中间点，保留末点；不是贝塞尔拟合，也不是大幅改变轮廓的路径重建。

较小笔触沿用最多12单位的基准范围；大笔触范围随自身尺寸扩大，最高256单位用于限制过度抹平。达到上下限或8193点预算时，不承诺严格的几何缩放等价。已有笔触只放大对象变换时，平滑几何随对象一起变换；直接在大尺寸坐标下绘制时，使用新的自适应范围。

## 性能

三角核由坐标累计和与一阶矩计算，每点平均为常数开销，避免半径扩大导致邻域遍历成本增长。使用相对首点的坐标降低大坐标下数值误差。弧长重新取样、平均和邻点简化均为线性遍历。原有WeakMap缓存保留，每份原始点最多缓存4个强度结果，其他几何和完成度缓存不变。

这是几何冷重建优化，不是承诺首次处理任意超长手绘路径无延迟；重复播放、完成度改变仍应复用缓存。波形在平滑后应用，端点／转角及采样格保持各自作用，不由平滑度替代。
