# 编辑器行为合同

> 本文只规定用户能够观察到的编辑器行为。Scene 字段以 `../../SCENE_SPEC.md` 为准；渲染结果以 `RUNTIME_CONTRACT.md` 为准。

## 1. 单一事实来源

用户在 Inspector、Canvas、结构树和编排器中的修改，必须写入同一个当前 Scene 对象。UI 临时状态（选中、展开、独显、面板分页、拖拽预览）不得成为保存后才能维持效果的隐式数据。

```text
用户输入 → Command/写入入口 → Scene Mutation → Scene → Runtime → Preview
                              └────────→ Save / Test / Export
```

顶部新建、打开、保存、测试与导出入口必须通过稳定 Editor Command 执行；其合同见 [EDITOR_COMMANDS.md](EDITOR_COMMANDS.md)。Command 只编排工作流，Inspector/Canvas 对 Scene 的字段修改应逐步进入 [SCENE_MUTATION.md](SCENE_MUTATION.md) 的统一事务入口。

同一能力不得由编辑器预览和 Runtime 各维护一套近似实现。Canvas 上的选择框、蒙版编辑框等编辑辅助层是例外，但不得进入导出画面。

## 2. Inspector 通用规则

- 选中对象后，Inspector、结构树高亮与时间轴上下文必须指向同一对象；清空选择时三者一起回到场景上下文。
- Canvas 空白、Esc 与 API 清选共用 `selection.clear`；结构树删除和 Delete/Backspace 共用 `selection.delete`。组的删除语义是解除组织关系、保留成员，图元/元素删除才移除实体。
- 开关是能力是否存在的事实来源：首次勾选写入默认结构并立即预览；取消只删除该能力的数据，不影响同级能力。
- 多个可组合效果必须使用独立开关；“预设”只能批量写入若干能力，不能替代底层能力结构。
- 渐进披露：关闭时只显示名称和开关，开启后才显示参数。
- 参数输入、Canvas 拖拽、撤销、保存再打开必须得到同一结果。

## 3. Sampling Motion 验收行为

- 图片元素显示独立“采样运动”页；程序元素、图元和粒子暂不显示。
- 像素沸腾、阈值呼吸、网点游移、颗粒潮汐是四个独立复选项，可任意叠加。
- 固定处理顺序为：像素沸腾 → 颗粒潮汐局部采样 → 阈值呼吸 → 网点游移。
- 颗粒潮汐单独开启必须可见；它以缓存式周期空间场改变局部采样粗细。选择组合调制时，只影响已经启用的阈值/网点原语，不暗中创建其它效果。
- “采样场”与“边缘保护”不是第五、第六个效果，而是“不均采样”的渐进参数：场只决定局部采样粗细的空间分布，边缘保护只约束不均采样在对象 Alpha 轮廓附近的作用区域。它们不得暗中影响阈值、网点或偏移采样。
- “轮廓稳定、内部翻涌”按钮必须一次写入 `uneven-sampling.field + uneven-sampling.edge + uneven-sampling.motion`，首次点击立即披露参数；保存后只保留这些声明式字段，不保存预设名。
- 勾选后立即创建默认参数、展开并在当前帧生效；播放时按 `t` 周期变化。
- “采样格”只保留尺寸。它本身就是独立可见的“降采样 → 最近邻放大”阶段；偏移采样、网点映射与不均采样在同一低分辨率工作面继续运算。修改后静态画面也要立即刷新。相位与旋转属于各具体效果或图案。
- 采样格单独拥有控制器时段；不均采样及其场、边缘、潮汐共享同一条效果时段。关闭场、边缘或潮汐不得清除不均采样本体或已有时段。
- 保存、重新打开、测试页面和逐帧导出必须保留叠加关系、时间周期与 seed。

## 4. 兼容与失败方式

- 旧字段可在打开相关 Inspector 时迁移，但迁移必须可撤销，并由 Runtime 在过渡期继续读取。
- Runtime 缺少编辑器要求的 capability 时必须显示明确警告；禁止“控件可写、画面静默忽略”。
- 未完成端到端验收的能力只能标注为实验性，不能写成“功能验证通过”。

## 5. 预览性能

- 舞台状态栏提供 Auto / Full / Draft；它们只控制编辑器 Runtime 重绘预算，不写入 Scene，也不改变循环时长、播放头或导出质量。
- Full 固定作品预览节奏并使用 1× 像素工作分辨率；Draft 按画布工作量将高成本像素处理中间缓冲区缩小 2× / 4× / 8×、以最近邻放大，并降低重绘频率。Auto 根据最近 Runtime 绘制 P95 带迟滞调整重绘频率，在持续超预算时启用对应工作分辨率降级。
- 状态栏显示 Runtime 绘制 P95、当前目标帧率和估算的 CPU 工作像素；这些数字不是显示器 FPS，也不包含 Inspector/时间轴 DOM 刷新。
- Draft/Auto 的工作分辨率只影响编辑器实时预览；保存、测试场景与固定时间导出必须默认恢复 1× 完整质量。

## 6. 历史与快捷键边界

- **V4 会话**使用 `EditorVNextSceneMutation`：最多 100 条完整 `.tosampool.json` 快照，并具备 undo / redo 双栈。`Ctrl/Cmd+Z` 撤销；`Ctrl/Cmd+Shift+Z` 与 `Ctrl/Cmd+Y` 重做；新修改必定清空 redo 分支。
- V4 快照包含可保存的 Scene 数据（对象、图元、组、素材描述、效果、蒙版、时间轴与背景），但不包含选择、面板展开、视口、播放头、临时草稿和 Runtime 缓存。
- V4 的编辑器内剪贴板通过 `Ctrl/Cmd+C / X / V` 处理对象树或当前对象的图元：粘贴生成新 ID，并以 8px 偏移放置；不读写系统剪贴板。`方向键`微移 1px，`Shift+方向键`微移 10px，`Space`播放/暂停。
- `Ctrl/Cmd+A` 全选对象（图元下钻状态则全选该对象图元）；`Ctrl/Cmd+G` 编组、`Ctrl/Cmd+Shift+G` 解组；`Ctrl/Cmd+[ / ]` 调整同级图层顺序；Delete/Backspace 删除；Esc 取消当前临时编辑或逐层退出下钻。
- Legacy 会话仍保留其最多 20 步、单向的旧历史。两套历史与内部剪贴板不得交叉调用。
- 每次可撤销修改记录的是用户操作前后的 Scene 快照；空操作不占用历史。连续拖拽、长按方向键和一次文字/蒙版编辑会话必须合并为一个用户意图。
