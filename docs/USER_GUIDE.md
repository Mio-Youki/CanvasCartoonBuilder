# Patcharium 用户指南

本文面向实际使用者，只描述当前产品入口和稳定工作流。Scene 字段请查阅根目录 `SCENE_SPEC.md`；实现原理请从 [文档导航](README.md) 进入。

## 1. 打开方式

- 浏览器：打开根目录 `img2asset-layout-v1.html`。
- 桌面端：从源码运行 `npm run desktop:dev`，或构建后运行 release EXE。

桌面端与浏览器使用同一编辑器。桌面端额外提供原生文件对话框、Scene 原位保存、相对图片解析和批量目录交付。

> 安全提示：当前 Scene 允许受控程序元素和兼容 JavaScript 配置。只打开自己创建或已经审查的 Scene，不要直接载入未知来源的 `.js`。

## 2. 工作区

- **顶部工具栏**：新建、打开、保存、测试、导出，以及选择/绘制/文字/图片工具。
- **左侧**：场景结构和当前会话素材。
- **中央**：Canvas 舞台；支持选择、移动、缩放、旋转、镜像和直接绘制。
- **右侧 Inspector**：场景、元素、组、图元、粒子和 FX 的唯一参数入口。
- **底部编排器**：播放头、Scene 标签和随 Inspector 上下文变化的时段轨。

## 3. 建立场景

新建场景可从空白画布或图片开始。图片先进入预处理面板，再作为素材、背景或普通图层加入场景。多张同尺寸或可统一尺寸的图片可组成横向 sprite sheet，并按 `frames/fps` 播放。

打开文件时会识别：

- `GENERIC_SCENE`：当前通用工程格式；
- `HOME_SCENE` / `DEFAULT_HOME_SCENE`：保留专用 Runtime 代码的兼容脚本；
- `SCENE`：旧装配格式兼容入口。

新作品应保存为 `GENERIC_SCENE`。

## 4. 选择与组织

- 单击选择；再次深入可进入元素内部图元。
- `Ctrl/Cmd + 点击` 多选，`Ctrl/Cmd + A` 选择可编辑实体，`Esc` 或点击空白清除选择。
- `Ctrl/Cmd + G` 编组。组提供父级移动、缩放、旋转、透明度与动画，但成员仍保持独立数据和顺序。
- 结构树拖到条目前后调整层级；拖到元素或组中央创建/加入组。
- 方向键移动当前黄/蓝/绿选择对象 1 个画布像素，按住 Shift 为 10 像素。
- `Alt + 滚轮` 缩放舞台；工具栏复位按钮或 `Alt + 双击` 恢复视图。

## 5. Inspector 与时间

未选择对象时，Inspector 编辑画布、背景和全局效果。选择后按对象能力显示属性、动态、局部效果、粒子或 Sampling Motion。

“时序”决定本次修改写入基础值还是播放头所在时段。下时间轴随当前 Inspector 上下文切换：元素显示窗口、局部 FX 窗口、Sampling Motion 窗口或全局 FX 分段。Linear 目前用于基础数值变换，不等同于完整关键帧曲线编辑器。

## 6. 蒙版与效果

元素和局部 FX 共用矩形、椭圆、多边形、Alpha/明度图片及实时元素蒙版。元素蒙版来源会从普通合成中派生隐藏，但仍按自身动画、时序和组变换参与 Alpha 捕获。

局部 FX 在数据中保持独立 `fx.layers[]`，在界面中作为绑定元素的子项出现。实际作用时间为目标可见窗口与 FX 自身窗口的交集。

Sampling Motion 面向图片采样结构，可组合像素沸腾、阈值呼吸、网点游移、颗粒潮汐、共享采样场和边缘规则。它可能读取像素缓冲；大画布应使用 Auto/Draft 预览或提高对象采样尺度。

## 7. 保存与导出

- **保存场景**：保存可继续编辑的 JS；图片会冻结为可移植数据。
- **测试场景**：生成内嵌 Scene、Runtime 和图片的独立 HTML。
- **导出其他格式**：当前帧 PNG、Sprite PNG、多帧 PNG、时间采样拼图和 GIF。

GIF 只适合有限色板和二值透明；带半透明边缘时优先保留 PNG 序列。APNG/WebP/WebM/MP4 尚未提供。

浏览器无法读取文件选择器所选 Scene 的相邻文件时，会要求人工重连。Tauri 桌面端可在已授权 Scene 目录内自动解析相对素材。

## 8. 当前数据边界

Scene JS 保存处理后的图片快照，因此可以离开原图运行；当前还不会保存原图、预处理配方或跨场景个人素材库。不要把相对素材解析误解为已经拥有 Project 系统。
