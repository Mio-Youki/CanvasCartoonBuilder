# Patcharium 用户指南

素材与图样卡片的名称均可双击修改（共享中的自带图样除外）。名字只是展示别名，改名不会断开图片、元素或图样关联；项目改名可撤销，不自动修改画布对象或共享副本。要回传共享名称与内容，请主动点击“更新共享”。图样别名同步显示在结构树和Inspector，随元素跨项目取用；已有项目别名优先。

图元的“拓展”页采用添加式：点击“＋ 添加图样”打开目录，再点击应用。只有已添加项显示开关和参数；关闭保留配置，×移除该项，可撤销。旧自定义图元自身参数不作为附加图样删除。

项目中每个图样只有一张预设卡片。当前图元已启用的图样名称高亮，点击卡片定位参数；“应用”把预设覆盖到当前图元，“回写”把当前图元该项参数覆盖到项目预设，不改其他实例。共享仍需主动更新。图元下已应用图样可拖序：树中越上越后绘制，仅改变覆盖，原图元始终在下方。详见[图样操作与边界](architecture/V4_PATTERN_WRITEBACK_ORDER_P3_2026-10-22.md)。

## v4：将元素留下来复用

在画布或结构树选中一个普通／程序元素、组或粒子，点击“场景结构”标题右侧、粒子按钮之后的“库”（收入素材库）。素材栏会打开并选中新元素卡；它保存自身基础参数与循环动态，不保存时序覆层或外部父组外观。组保留内部层级，粒子自带私有来源依赖；都只有一张卡。

入库后来源对象建立关联，再选中它时“库”变为↥“更新项目素材”。点击后将基础参数回存到同一个素材，不创建重名副本，也不改变其他已经放置的实例。修改对象名或素材名都不会断连。此前没有记录来源的旧对象不按名字猜配，需要重新入库建立关联。

位图／序列／元素卡的移除都会保留画布对象和共享副本。图片移出后不显示在项目库，但所需原图仍随工程保存，重开不会丢图，也不会重新冒回卡片；移出可以撤销。这不是物理清理存储空间。

单击元素卡可选择，右下→“加入到画布”创建独立对象；修改新对象不会修改素材卡或其他副本。多选和单独图元不能收入库。位图／序列点击名称只选择，选中后点击预览才进入预处理，左下α打开修边；元素卡不会打开图片预处理。删除仍被粒子使用的画布来源时，自动保留独立来源供粒子继续播放。

素材／图样标题下方一行，左侧♡／♥按钮切换“项目／共享”，文字表示当前查看范围；右侧依次为导出画面、导入文件夹、导入精灵图、导入素材图标，悬停可查看名称。选中项目位图后导出处理后的PNG；序列／元素打开共用导出面板。共享素材先取用到项目。这里的♥只切换查看范围。项目卡左上♡将素材发布到本机共享库，发布后变为♥“更新共享”；它不会取消共享。仅修改画布实例不会更新素材定义或共享版本，应先回存项目素材，再更新共享。

切到“共享”点击“加入到画布”，素材会先复制到当前项目，再创建独立对象。相同内容重复取用复用项目素材定义，画布副本仍各自独立。程序内容在导入／取用时询问信任；拒绝则不导入，接受后预览、放置和重复新建不再询问。新工程需在其导入边界重新确认，不继承其他工程的许可。

共享页的×“移出共享”需要确认；它只移除本机共享条目，不删除任何项目已复制的素材和画布对象。共享库不是工程撤销历史，Ctrl+Z不会默默恢复或改写共享发布。项目卡的♥悬停或键盘聚焦时显示↥，点击只更新共享；项目和共享卡的加入／移除按钮均在预览右下／右上。

“收藏”入口已移除，不执行旧收藏迁移。跨项目可使用共享，或将保存场景的ZIP解压后选择“导入文件夹”：提取其中素材及依赖，不导入画布、时间轴或共享关系；相同身份且内容一致的定义复用。普通图片文件夹仍可导入。未知程序不会自动获得信任。

### 图样、程序构件与烘焙

“图样”页左侧切换项目／共享，右侧图标依次保存图样预设、导入工程图样文件夹、导入图样。共享页“自带”为只读；“我的”为自己发布的图样。新项目无需预装全部图样，空项目首次进入可直接从共享取用。

卡片右下新建／应用。刻度、嵌套和元素排布在新建前选择载体；选中唯一图元时只显示兼容的应用项。项目卡♡发布共享，♥悬停／聚焦后变↥更新；右上×移出项目不删除已应用的画布内容。移出共享只能在共享页完成，不删除各工程副本。

导入后自动选中项目卡，但不应用到画布。保存预设捕获当前图元的图样参数；有多项时先选择要保存哪项，生成新的项目定义。画布参数不会自动改写定义或共享版本。图样有对应实现定义时，底部“图样依赖”提供显式版本应用／停用；停用保留轮廓缓存，可撤销。原“图样管理”文字列表已移除。

新建取消不写入资源或对象，完成后一次撤销完整回退。图样卡为静态预览；包含程序来源的图样不自动执行预览，取用时再按工程授权加载。[完整说明与限制](architecture/V4_PATTERN_CARDS_P2C_2026-10-22.md)。

通过“导入素材”选择程序构件资源JSON；导入确认后生成普通元素卡，使用公开参数的默认值和建议尺寸，不自动加入画布。点击→再放置独立实例。独立“程序构件”栏已移除；实现依赖仍随工程保存。要保留当前实例调整过的参数，请用结构树的“库／更新”回存元素素材。

元素素材卡左下▧打开烘焙，可选位图／序列；位图默认当前播放时刻，序列按当前项目周期和设定帧数生成。使用卡片已保存的基础参数及循环动态，不读取画布实例的未回存修改；需要时先用结构树↥回存。输出保留透明背景和对象处理，按动态共同范围裁切，不含场景背景／滤镜。取消不留半成品，完成后选中新素材，可撤销；原素材和画布对象不替换。普通／程序元素共用，无需先放到画布。旧的“选中画布构件后烘焙”入口仍保留。

不另设“导出可编辑素材”入口：可编辑跨项目复用通过共享或工程文件夹完成。[本批样例与边界](architecture/V4_RC4_MATERIAL_CLOSEOUT_2026-10-22.md)。组烘焙共用后代边界；粒子烘焙采用项目画布范围，复杂预览／烘焙有预算限制。

素材卡空闲显示首帧；悬停序列以2fps预览，元素预览自身基础循环动态。一次只播放一张可见卡，移开、收起素材栏或切换项目后停止并恢复首帧；键盘聚焦卡片后按P可播放／停止。预览保留处理后的颜色和Alpha，不修改工程；程序需要当前工程已经显式信任，否则卡片显示原因。不可读取图片保留名称与错误，不使用其他工程的预览兜底。

本文面向实际使用者，只描述当前产品入口和稳定工作流。Scene 字段请查阅根目录 `SCENE_SPEC.md`；实现原理请从 [文档导航](README.md) 进入。

## 1. 打开方式

- 浏览器：打开根目录 `img2asset-layout-v1.html`。
- 桌面端：从源码运行 `npm run desktop:dev`，或构建后运行 release EXE。

桌面端与浏览器使用同一编辑器。桌面端额外提供原生文件对话框、Scene 原位保存、相对图片解析和批量目录交付。

> 安全提示：当前 Scene 允许受控程序元素和兼容 JavaScript 配置。只打开自己创建或已经审查的 Scene，不要直接载入未知来源的 `.js`。

## 2. 工作区

V4“图样”目录中的“括号／角标”可直接新建，或应用到选中的矩形、椭圆、多边形范围。拓展页选择完整括号／角标及直角／圆弧，再选择左右或角位置；宽高在成样和Canvas调整，粗细独立。角标才显示纵向长度，直角才显示圆角，切换不会清除隐藏值。[六例工程](../examples/agent-brackets-g4/project.tosampool.json)。

V4普通图元的成样面板中，开启“路径显现”后可调整完成度、端点、闭合路径的起始位置及填充显现。关闭时恢复完整路径，保留设置与时序。轮廓嵌套的“逐层起点偏移”在虚线／显现具有作用时出现，不再随着完成度到达100%消失。角点箭头的拓展参数提供几何中心／固定角度和平头／圆头／尖头，圆角0为尖角。[详细规则](architecture/V4_PATH_REVEAL_AND_ARROW_SHAFT_2026-10-18.md)。

V4入口`img2asset-v4-classic.html`提供“图样”工具：点击顶栏图片右侧图标，左下栏切换至图样目录。无唯一图元时，刻度／嵌套／元素排布点击新建并在卡片内选载体，然后在画布绘制；角点箭头点击新建后直接拖拽，建立自定义图元。选中单图元元素或下钻图元时仅显示兼容应用项；应用保留原类型并定位到Inspector拓展参数，重复应用不重置，停用在Inspector完成。自定义本体参数也在拓展Tab编辑，但不提供启用开关或创建后换载体。可打开[五例工程](../examples/pattern-corner-arrows-v4.tosampool.json)检查。

- **顶部工具栏**：新建、打开、保存、测试、导出，以及选择/绘制/文字/图片工具。
- **左侧**：场景结构和当前会话素材。
- **中央**：Canvas 舞台；支持选择、移动、缩放、旋转、镜像和直接绘制。
- **右侧 Inspector**：场景、元素、组、图元、粒子和 FX 的唯一参数入口。
- **底部编排器**：播放头、Scene 标签和随 Inspector 上下文变化的时段轨。

## 3. 建立场景

新建场景可从空白画布或图片开始。图片先进入预处理面板，再作为素材、背景或普通图层加入场景。多张同尺寸或可统一尺寸的图片可组成横向 sprite sheet，并按 `frames/fps` 播放。

打开文件时会识别：

- `GENERIC_SCENE`：当前通用工程格式；
- `HOME_SCENE` / `DEFAULT_HOME_SCENE`：保留专用 Runtime 代码的兼容脚本；
- `SCENE`：旧装配格式兼容入口。

新作品应保存为 `GENERIC_SCENE`。

## 4. 选择与组织

- 单击选择；再次深入可进入元素内部图元。
- `Ctrl/Cmd + 点击` 多选，`Ctrl/Cmd + A` 选择可编辑实体，`Esc` 或点击空白清除选择。
- `Ctrl/Cmd + G` 编组。组提供父级移动、缩放、旋转、透明度与动画，但成员仍保持独立数据和顺序。
- 结构树拖到条目前后调整层级；拖到元素或组中央创建/加入组。
- 方向键移动当前黄/蓝/绿选择对象 1 个画布像素，按住 Shift 为 10 像素。
- `Alt + 滚轮` 缩放舞台；工具栏复位按钮或 `Alt + 双击` 恢复视图。

## 5. Inspector 与时间

未选择对象时，Inspector 编辑画布、背景和全局效果。选择后按对象能力显示属性、动态、局部效果、粒子或 Sampling Motion。

“时序”决定本次修改写入基础值还是播放头所在时段。下时间轴随当前 Inspector 上下文切换：元素显示窗口、局部 FX 窗口、Sampling Motion 窗口或全局 FX 分段。Linear 目前用于基础数值变换，不等同于完整关键帧曲线编辑器。

## 6. 蒙版与效果

元素和局部 FX 共用矩形、椭圆、多边形、Alpha/明度图片及实时元素蒙版。元素蒙版来源会从普通合成中派生隐藏，但仍按自身动画、时序和组变换参与 Alpha 捕获。

局部 FX 在数据中保持独立 `fx.layers[]`，在界面中作为绑定元素的子项出现。实际作用时间为目标可见窗口与 FX 自身窗口的交集。

Sampling Motion 面向图片采样结构，可组合像素沸腾、阈值呼吸、网点游移、颗粒潮汐、共享采样场和边缘规则。它可能读取像素缓冲；大画布应使用 Auto/Draft 预览或提高对象采样尺度。

## 7. 保存与导出

- **保存场景**：保存可继续编辑的 JS；图片会冻结为可移植数据。
- **测试场景**：生成内嵌 Scene、Runtime 和图片的独立 HTML。
- **导出其他格式**：当前帧 PNG、Sprite PNG、多帧 PNG、时间采样拼图和 GIF。

GIF 只适合有限色板和二值透明；带半透明边缘时优先保留 PNG 序列。APNG/WebP/WebM/MP4 尚未提供。

浏览器无法读取文件选择器所选 Scene 的相邻文件时，会要求人工重连。Tauri 桌面端可在已授权 Scene 目录内自动解析相对素材。

## 8. 当前数据边界

Scene JS 保存处理后的图片快照，因此可以离开原图运行；当前还不会保存原图、预处理配方或跨场景个人素材库。不要把相对素材解析误解为已经拥有 Project 系统。
