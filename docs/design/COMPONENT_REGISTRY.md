# 组件注册表

> 状态：骨架。本文记录可复用 UI 组件的“结构、视觉变体、状态与数据语义”，防止不同模块各自造一套控件。

## 单个组件的标准条目

```md
## 组件名称

- 用途与禁用场景：
- 解剖结构：
- 变体：
- 状态：默认 / hover / active / selected / disabled / error / loading（按需）
- 数据映射与默认值：
- 交互与键盘：链接到 INTERACTION_AND_MOTION.md 的模式；
- 视觉 token：链接到 DESIGN_SYSTEM.md；
- 最小代码入口：实际 HTML/CSS/JS 文件与选择器；
- 参考图或状态图：相对链接；
```

## 首批待登记组件

- 主按钮、次按钮、危险按钮、图标按钮；
- 三态/多态分段选择器（例如边缘保留/增强/消除）；
- 数值输入、数值步进、带单位输入；
- 图层卡片、parts 卡片、FX 卡片；
- 折叠组与参数子组；
- 标签、状态 chip、`[S]` 时段按钮；
- 下拉选择、颜色选择、滑块、空状态与提示。

## 维护规则

- 新控件进入第二个模块前必须登记；只在单处使用的临时控件可先不登记。
- 组件语义优先于视觉相似：同样“看起来像按钮”的控件，若一个切模式、一个执行破坏操作，应是不同变体。
- 代码实现仍留在 HTML/CSS/JS；本文只保留决定性的小样例，不复制整段实现。
