## 首批待登记组件

- 主按钮、次按钮、危险按钮、图标按钮；
- 三态/多态分段选择器（例如边缘保留/增强/消除）；
- 数值输入、数值步进、带单位输入；
- 图层卡片、parts 卡片、FX 卡片；
- 父级组卡片（紫色联合框、成员数、解组与复制）；
- 折叠组与参数子组；
- 标签、状态 chip、`[S]` 时段按钮；
- 下拉选择、颜色选择、滑块、空状态与提示。

## 重构 v1 的优先组件

- 结构树节点：背景 / 组 / 元素 / 图元 / 粒子 / 绑定局部 FX；支持展开、选中、锁定、隐藏、删除与插入排序。
- Inspector 分段：`属性 / 动态 / 效果`；当前选择决定内容，不得与结构树重复承载参数。
- 时间编排轨：场景段、对象显示窗口、局部 FX 窗口与全局 FX 分段，共用切分 / 建立 / 移动 / 缩放 / 删除规则。
- 素材缩略格：双列、删除、添加到场景、可拖入舞台；素材处理属于入库流程，不混入结构树。

各组件的数据与交互边界见 [UI_RECONSTRUCTION_V1.md](UI_RECONSTRUCTION_V1.md)。

## 已确认的组件语言

- 组件应显露其语义：执行动作、切换模式、选择状态、危险删除不能只靠外观相近的“方按钮”区分。
- 像素化细节优先落在图标、边缘、状态 chip、焦点环和缩略图容器；复杂表单控件以清晰、稳定、可键盘操作为先。
- 暖黄主按钮只用于当前任务的主推进动作；青/绿/紫是稳定的对象语义色，不可被任意复用为装饰。
- 首轮优先定义可反复出现的“分段选择器、图层卡、参数折叠组、图标按钮、空状态”，而不是先制作孤立的整页视觉。

## 维护规则

- 新控件进入第二个模块前必须登记；只在单处使用的临时控件可先不登记。
- 组件语义优先于视觉相似：同样“看起来像按钮”的控件，若一个切模式、一个执行破坏操作，应是不同变体。
- 代码实现仍留在 HTML/CSS/JS；本文只保留决定性的小样例，不复制整段实现。
