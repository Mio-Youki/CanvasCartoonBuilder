# 旧媒介工作台：下一轮 UI 规则

> 状态：信息架构与状态语义已对齐；[可运行界面小样](prototypes/old-media-workbench.html)正在做视觉整理，尚未迁入正式编辑器。本轮属于字号整理：保留布局与交互，只统一可读性层级；图标、字体授权及真实数据交互仍待落实。
>
> 适用范围：ToSampool v4 编辑器的整体界面、Inspector、时间轴及临时面板。本文是下一轮 UI 改造的视觉与交互依据；现有页面和旧设计文档仍记录当前实现。效果 ID、参数、Step / Linear 能力和保存格式以 Effect Registry、Scene Spec 与 Runtime 合同为准，不能由视觉稿改写。

## 方向与边界

- 产品呈现为「旧媒介工作台里的拼贴采样机」：暖象牙色实体外壳与既定布局保持安静、稳定；复古未来主义的能量主要发生在深色屏内，来自切分、采样、错位与套印的图形语法，而不是全屏霓虹或额外的设备造型。实体键选中时仍以暖琥珀透光表达。
- 屏内读数以偏暖的高对比中性色为基底；青绿、珊瑚、赭黄分别呼应成样 / 加样 / 采样的处理阶段，集中用于阶段索引、效果图示及少量切入痕迹。它们不是任意字段的装饰色，也不替代选中、启用等稳定状态。产品作品与用户素材始终优先于界面色彩。
- 舞台上的作品是视觉主角。外壳围绕舞台，不在 Canvas 作品画面上叠加全局 CRT 失真、扫描线或玻璃纹理。
- 结构化界面遵循 `FRAME → SUBFRAME → LABEL`：大屏幕定区域，分组标题定任务，标签和数值定参数。不为每个字段另套一层装饰边框。
- 图标化和像素感服务于识别功能。中文名称、数值、键盘焦点、可点击区域及高密度参数必须保持清晰。

## 字号层级（100% 缩放）

- 正文基线 `14px`，操作标签、参数数值、树节点、页签与按钮文字 `13px`，分组标题 `14px`，当前对象标题及输入小样的卡片标题 `16px`。
- `11px` 只用于非主要操作的辅助刻度、索引、单位和状态元数据；不把 Inspector 字段或左栏条目压到该层级。密集区域优先增加行高、允许内部滚动，不缩小文字来维持原高度。
- [工作台小样](prototypes/old-media-workbench.html)与[输入组件小样](prototypes/inspector-input-lab.html)共用这套语义字号。后者尚在调整控件样式，暂不把其未定稿的外观和交互批量覆盖到工作台；正式编辑器也留待迁移阶段处理。

## 屏幕数量与位置

主屏幕只有四处，各自具有完整边框：

| 主屏幕 | 内容 |
|---|---|
| 舞台 | Canvas、选择框与直接操作；显像管式外壳围绕作品，不处理作品像素。 |
| 左侧上屏 | 常驻「场景结构」树；标题栏承载粒子化与删除动作。 |
| 左侧下屏 | 同一屏幕槽内以 Tab 切换「对象效果 / 素材」；它们不同时占据两个独立屏幕。 |
| 右侧屏幕 | 当前场景、对象、组或图元的 Inspector。 |

另外有四处嵌入式数显区，不再各套一层厚外壳：

1. 工具栏右侧的当前工具参数读数。
2. 舞台上边框右侧的运行与性能数字；运行状态灯嵌在旁边的实体边框上，而非数显内部。
3. 时间刻度上方左侧的当前对象 / 轨道语义与时间读数。
4. 底部时间轴下轴的 Scene 划分与当前上下文编排轨。

## 工作台布局

- 顶部为两层：上层目前只显示 `ToSampool`，为未来页签留位置；下层是共用实体面板中并排的三个镶嵌区。每区各有贴合面板的细黑圆角嵌边，边界与下方左栏 / 舞台 / Inspector 对齐；区间不另加刻线或凸起的第二层凹槽。六个场景动作与八个工具同排：新建 / 打开 / Agent 对齐左栏，八个工具对齐舞台，保存 / 测试 / 导出对齐 Inspector。
- 十四个实体键均有深色键帽轮廓与嵌边，但不加向下投影；左右六个场景键的浅色键帽比中间八个深色工具键更宽，填满各自区域并保持接近中间键区的键间距。键帽内只有图标，功能文字与键帽之间保留清楚的间距；长工具名可以使用短标签，完整名称保留在悬停和无障碍名称中。
- 工具参数数显区始于最后一个工具按钮右侧的间距，延伸至舞台右端。八个工具已有参数全部保留，切换工具不改变工具栏行高；删除工具栏中的说明性备注。选择无参数的「选择」「图片」等工具时仅显示工具名称。
- 左右栏采用可读的固定默认宽度，并允许在上下限内拖动分隔线；中间舞台承担窗口宽度变化。默认值与上下限由小样在目标视口中校准，不以百分比强制缩放侧栏内容。
- 场景结构常驻。左侧下屏用类似 Inspector 页签的 Tab 切换「对象效果 / 素材」，屏幕槽位置和整体高度保持稳定。场景结构与下屏之间的分界沿用可调高度；滚动只发生在各自内部。两处页签切换共用约 `260ms` 的短扫描线／信号亮度反馈，不改变容器尺寸，并尊重系统「减少动态效果」。
- 场景结构、左侧下屏和 Inspector 各预留常驻的无倒角细滚动轨道，不出现端箭头，也不因内容刚好溢出而突然挤窄正文。无溢出时轨道通体青色；溢出时青色滑块表达当前可见段，黄色轨道首先出现在其下方。原生滚动条在 Windows／Edge 会强制出现圆角、端箭头和不一致的宽度，因此小样改为 **3.5 px 等宽的自绘轨道／滑块（原 7 px 的一半），16 px 透明指针命中区**；实际滚动仍由原容器承担，保持滚轮、触控板、键盘和可拖拽滑块。正式迁移须在 Tauri 环境再验收缩放、长列表与面板切换。
- 左栏延伸至页面底部。时间轴固定在舞台与 Inspector 底部，横跨这两个区域；保持紧凑的固定高度，不提供向上拖高或纵向滚动。

## Inspector 信息层级

- 对象页签为「成样 / 加样 / 采样」；场景页签为「成样 / 叠加滤镜 / 采样滤镜」。页签属于右侧同一块数显屏内部。
- 对象「成样」内部只有一条标题行：显示「成样」或「动态」，标题右端的同一图标按钮在两页间切换；不另造横向页签，切换也不启用效果。左侧「对象效果」的阶段索引把原先误称的「成样」改为「动态」，对应实际对象运动效果。
- 「成样」页把位置、尺寸、比例、斜切、旋转、混合收在一张「基本」卡内，以细线分隔内部参数组，卡片标题最右提供对象参数时序入口；这张卡与后续调色、蒙版、外观、文字等卡同级。基础参数继续使用对象轨的时序入口，Linear 仅限数据合同允许的字段。基本字段旁不再出现兼具展开与启用语义的动态按钮。
- 「动态」采用每行两张的效果卡：漂浮、循环滚动、呼吸缩放、持续旋转、摆动、闪烁。卡片主体只选中，角部电源键才启用或停用；选中项的参数与独立时序入口在下方展开。
- 「成样 / 动态 / 加样效果 / 采样效果」四个内容页采用相同的顶部标题行结构；加样和采样标题右端不显示装饰性的 `FX / 06` 计数。
- 每种动态的参数时序仅为 Step，并按 `anim.{motionId}` 限定读写与清除范围。底层仍共用对象参数轨，动态显示时段另存于该动态的可见性轨；左侧动态条目选中后，底部同一 TRACK 同时呈现两者。清除某动态参数不得删除基本参数或其他动态的值。
- 场景「成样」保留画布、背景和过渡的各自分组。背景可在 Scene 内部分段写入；画布尺寸与循环周期不因为页面拟物化而变成逐时段参数。
- 「加样 / 采样」及场景对应的两类滤镜页，用每行两张的效果图示卡片浏览效果。卡片主体点击只选中以编辑，卡角独立电源开关负责启用或停用。被选中的效果在网格下方展开唯一一块参数区，其标题放该效果的时序入口及可用的运动入口。
- 选中用赭黄细描边表示；已启用用较暗的青绿填充与点亮的电源键表示；两态可以同时存在。一次只展开一项效果的参数，多项效果可以同时启用。未启用的卡片也允许先选中查看用途与默认参数，不因选中而隐式启用。效果图示可使用三色套印或有节制的错位，不把同一条装饰斜线复制到每张卡。
- 「时序」仅出现在确有按段写入与 Runtime 读取能力的参数组或效果标题。图元几何与路径 Paint、蒙版编辑形状、处理阶段顺序、工具设置和素材预处理不因有参数就自动获得时序按钮。任何卡片不得向 Registry 未声明的字段提供 Linear。
- 「时序」是时间轴状态，不使用成样／加样／采样的套印色。时序入口启用态和 TRACK 的 Step 时段使用独立的 `#009944` 绿；未启用入口可用较亮的同色系线条保证可见。

## 左侧屏幕与时间轴

- 「对象效果」是当前对象或场景**已启用效果的索引**，不是第二套参数编辑器；点击条目同时定位 Inspector 和下轴。效果阶段沿用现有可调序能力，阶段内效果仍按 Registry 固定顺序。
- 「素材」维持双列缩略图、入库与拖入场景工作流。导入文件夹、导入精灵图、导入素材属于屏幕外沿的实体式动作按钮。
- 时间轴实体部分只有一枚放大的圆形播放键，图案始终为 `▶`，其上下留白相对下方数显与实体面板上缘均衡；右侧只有上下两盏状态灯，不显示「播放 / 暂停」字样。两灯的整体中线与播放键中线对齐，播放为青灯、暂停为黄灯，仍提供无障碍状态名称。删去「编排器」字样。当前小样在每秒内再分四条短线，视觉刻度间隔为 `0.2s`；最短刻线为主刻线的一半高度，六秒标签居中位于对应主刻线上方，`0s` 与下方可编辑轨的起点对齐。可变时长的自适应刻度间隔尚待确认；具体时间编辑精度仍由时间轴数据合同决定。
- 刻度上方左侧是一块独立数显读数区，合并显示当前对象与轨道语义、当前时间与总时长，例如「冬季 · 木屋 / 显示与参数　16.8 / 36.0 S」。下方另一块数显屏只显示 Scene 分段与可切分编排轨，其右边界与刻度右端对齐。Inspector 焦点改变时，两块数显的上下文同步，不新增竖向轨道。
- 密集时段通过横向缩放、平移和悬停读数处理；不压小文字和操作命中区。Scene 切段、Step / Linear、显示时段和效果时段的既有数据语义保持由时间轴合同定义。
- TRACK 使用上下两层：上层主轨约为原高度的一半，按处理阶段呈成样青、加样红、采样黄；每段独立圆角，段间留窄缝。Step 时序段在主轨下方另加半高的 `#009944` 绿线，不把主轨整段涂绿。Linear 下层只绘绿色波点，波点之间直接露出屏幕底色，不铺连续底色；默认→时序时波点向右增大，时序→默认时向右减小，两段时序间则由绿点向中央减小再向右增大，露出的阶段色主轨形成绿→阶段色→绿。波点是时段类型提示，不声称底层插值采用对称曲线。

## 两套状态语言

| 控件位置 | 悬停 | 选中 / 焦点 | 启用 / 持续状态 |
|---|---|---|---|
| 数显屏内部的 Tab、效果图示和状态开关 | 边缘轻微点亮 | 赭黄描边或浅色 Tab 面 | 深青绿填充与明确的电源状态；不使用实体状态灯 |
| 屏幕外部的实体按钮 | 小幅按下位移 | 工具模式持续琥珀色透光 | 一次性命令只在按下或执行期间透光 |

- 顶部十四个实体按钮（六个场景动作、八个工具）各需一个静态图标。「粒子化 / 删除」目前位于场景结构屏幕标题栏，因此采用数显命令图标，而非突出的实体键。导入文件夹、导入精灵图、导入素材仍归属实体按钮族，正式版应放在素材屏外沿。
- 八个工具是持续模式；六个场景动作中，新建、打开、保存、测试、导出是一次性命令，完成后不保持选中灯态。Agent 创作面板打开期间可持续透光。
- 结构树的「锁 / 独 / 隐」各需要可辨认的开、关两态图形，不能只更换颜色。每一种「加样 / 采样 / 叠加滤镜 / 采样滤镜」效果都需独立静态图示，停用和启用共用图形但状态不同。
- 效果卡 Hover 用短促的预制图示动画解释效果，不触发一次真实 Canvas 效果渲染，也不改变卡片尺寸；键盘焦点提供同等说明。最终图标造型与 Logo 一起设计，当前先冻结图标清单和状态语义。

### 屏内「数位感」的落点

- 一块屏幕以深色底、暖白主字和中性次字维持可读性；阶段色只占局部，用于蒙版 / 加样 / 采样的索引和图示。屏幕外的运行灯仍是实体状态灯，不让屏内文字靠多色编码运行状态。
- 效果图示展示各自的变换机制：例如双色分割、条带错位、网点和套印色散；彩色图样优先放在图示和结果预览，不进入每一行普通参数。
- 字段按固定基线和数字列对齐；数值用等宽数字，标签仍用清晰中文。用细刻线和明度差分层，不给每行参数套独立厚框。
- 只让当前输入、播放头和执行中状态短暂变化；常规文字不持续闪烁，也不在整块屏幕铺明显扫描线。作品 Canvas 更不能被界面噪声覆盖。
- 场景结构的粒子化、删除处于屏内，表现为数显命令图标；素材导入与对象效果删除也位于下屏各自 Tab 的屏内命令行。状态先由位置与反馈说清，再由最终图标补足识别。

## 临时面板与动效

- 图片预处理、精灵图切帧、Alpha 编辑和「导出其他格式」共用一种数显风格临时浮层。Agent 创作暂用同一容器；后续可在功能成熟时形成自己的样式。
- 打开时由中央闪烁的数显竖线开始，快速展开为面板，内容在外框展开后显现，文字不随外框拉伸。关闭更短。浮层覆盖期间保留主工作台的空间上下文；未提交的编辑不能因误点背景而丢失。
- 实体按钮、Tab、左侧下屏切换与浮层都应有短且可中断的状态反馈。画布拖拽、选择框、手柄和时间轴定位保持即时跟手。系统启用减少动态效果时，省略位移与闪烁，保留边框、填充和焦点变化。

## 待小样校准的数值和资产

- 左右栏初始宽度、拖动上下限、具体字号、字体授权与中英文字体组合、外壳与屏内色值、边框厚度、控件间距及固定时间轴高度。
- 顶部与场景结构动作、结构树双态开关、全部效果卡的正式图标；与 Logo 统一完成。当前小样只有几何占位图标。
- 效果 Hover 示意、实体按钮位移、临时面板展开的准确帧数与时长。以真实窗口、键盘操作和减少动态效果模式验收。

这些是**视觉校准项**。当前已确认的屏幕数量、布局关系、选中/启用语义、Inspector 层级和时间轴固定高度不因校准数值而重新解释。

## Inspector 控件体系：迁移前盘点

此轮不全量重画参数。正式编辑器至少要逐项盘点：场景画布／背景／过渡、对象基本变换及其动态、组／元素／图元差异、文字和多帧、程序构件、蒙版与粒子、加样／采样效果及控制器、场景滤镜。以 `classic-v4-inspector-controller.js` 的实际渲染入口、`effect-registry-vnext.js` 的字段定义、时间轴可时序字段三处交叉核对；原型里的少数示例参数不等于完整清单。

逐模块字段与输入语义已整理为 [Inspector 输入类型盘点](INSPECTOR_INPUT_TAXONOMY.md)：建议收敛为 11 类可复用输入样式，动态／时序等另作为状态与操作语法。

每个参数先记录「类型、单位与范围、成对关系、是否可连续预览、是否支持时序／动态、输入频率」，再决定控件。XY、宽高、水平／垂直斜切等成对值同排；颜色与透明度以共享控件联动；离散模式用单选／下拉；连续且有明确上下限的强度类可用滑杆加精确数值；位置、尺寸、角度、种子和开放范围参数保留数值输入。只有频繁直接操作且不损失精度时才增加旋钮，不能为了仪器外观把所有数字换成滑杆。先确认一组代表性卡片，再复用到各模块，避免逐屏重新发明控件。
- 效果卡的主体选择与角部电源按钮是两个独立命中区；选中描边与启用填充可同时存在。播放状态由时间轴双灯表达，舞台状态灯只表达预览质量。浮层展开为屏幕内部动画，尊重系统「减少动态效果」。
- 此轮只校准空间关系、视觉层级与状态语义；样例图形图标、性能读数和 Inspector 参数不是正式素材或功能验收。正式迁移前需再检查实际中文长标签、键盘焦点、最小支持窗口和高 DPI 缩放。
