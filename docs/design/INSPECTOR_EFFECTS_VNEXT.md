# Inspector 效果界面 vNext

> 下一轮视觉排布以 [旧媒介工作台 UI 规则](OLD_MEDIA_WORKBENCH_UI_RULES.md) 为准：成样使用基本/动态分组，加样与采样使用两列图示卡片和下方单项参数区。本文件继续描述当前效果语义与数据映射；下文的纵向文字效果卡是既有界面记录。

> 状态：设计合同 + Classic V4 可见实现。对象页签“成样 / 加样 / 采样”、场景页签“成样 / 叠加滤镜 / 采样滤镜”及左侧效果索引已接入 `img2asset-v4-classic.html`；控件细节仍按迁移矩阵逐项达到 Legacy 体验等价。

## 设计原则

Inspector 不再按底层字段来源分“属性 / 风格 / 局部 FX / Sampling Motion”，而按用户正在做的事组织：先造对象，再给它加层，最后重采样。控件从 `editor/effect-registry-vnext.js` 派生，页面不应私自定义效果 ID、默认值或时序能力。`editor/vnext-inspector-model.js` 已把 Registry 推导为页签、卡片、存储路径与可编辑状态；`editor/vnext-effect-state.js` 是唯一效果写入器，负责默认值、启用、移除、参数路径、阶段重排与关联效果轨道清理；`editor/vnext-entity-state.js` 则是成样基础字段的白名单写入器。两者都必须经 `editor/vnext-scene-mutation.js` 事务提交。UI 层只消费模型并调用这些写入器。

## 上下文与页签

| 当前选择 | 页签 | 解决的问题 |
|---|---|---|
| 对象 / 组 / 图元 | 成样 | 内容、变换、路径/文字、混合、基础蒙版 |
| 对象 / 组 / 图元 | 加样 | 给对象增加投影、外描边、染色、纹理、内外光效 |
| 对象 / 组 / 图元 | 采样 | 改变对象像素的颜色、格点、网点、噪点与偏移 |
| 未选中对象（场景） | 成样 | 画布尺寸、循环、背景 |
| 未选中对象（场景） | 叠加滤镜 | 对已合成画面加调色、染色、纹理、蒙版暗角 |
| 未选中对象（场景） | 采样滤镜 | 对完整合成画面进行采样处理 |

“动态”不再作为把所有动画塞进一起的平级页签：位置、比例、旋转、透明度的右侧分别披露 bob/scroll、pulse、spin/wave、blink；效果自己的运动开关在对应效果卡标题右侧。关闭运动只移除程序调制，不改写静态值。时间轴上下文统一由当前选中对象/效果卡决定。

## 通用控件族

| 组件 | 适用位置 | 固定行为 |
|---|---|---|
| 颜色 | 任意颜色字段 | 色相/明度面板、Hex、每色独立 Alpha、画布实时预览、提交/回滚边界一致 |
| 纹理 | 纹理填充 / 纹理叠加 | 预览 + 纹理类型 + 结构参数；颜色由颜色组件负责，纹理组件不再复制 Alpha |
| 蒙版 | 对象蒙版 / 场景滤镜范围 | 同一个选择、编辑、反相、引用源和 `keep/mask-only` 控件；不再有“剪切/范围/Alpha”三套分叉 UI。场景暗角的范围为可选：未设置时作用于整张画面。 |
| 效果开关 | 所有效果 | 关闭时只有名称、用途和启用键；启用后才披露参数，并同时创建左侧效果卡 |
| 时序标记 | 允许 Step/Linear 的字段 | 仅显示注册表允许的 Step / Linear 状态；禁止让 UI 对未知字段擅自插值 |
| 程序运动 | 支持 `motion` 的效果 | 效果标题右侧的运动开关；开启后披露周期、seed、幅度等运动参数，不把运动伪装成关键帧 |

## 成样

基础变换采用简短的“位置 / 尺寸与比例 / 旋转与中心 / 透明度”分组。它们是对象的基础值，时序覆层可对登记为 Linear-safe 的字段线性过渡；bob、scroll、spin、wave、pulse、blink 是叠加在基础值之上的程序调制。Classic V4 已在对象、组与图元 Inspector 中接入右侧披露入口：位置对应漂浮/循环滚动，比例对应呼吸缩放，旋转对应持续旋转/摆动，透明度对应闪烁。

场景成样页包含三组数据：画布、背景与过渡。背景只管理 `颜色 / 透明度 / 纹理填充`，并复用所有填色字段的颜色组件；图片应作为普通 Scene 图层加入结构树，而不是另设不可选的图片背景。当前播放头所在的 `timeline.scenes[]` 段持有入口 `transition`，也持有该 Scene 的背景基础覆盖。

场景成样页打开时，下方编排器切换为“场景分段与参数覆层”：蓝带是无法删除、始终跟随上方 Scene 标签边界的当前 Scene 范围；在其内部可用 Alt+单击显式切分背景 Step 段，黄色带表示已写入的背景覆层，双击黄色带清除覆层并合并空段。Scene 的“时序”只武装当前内部段；未武装的背景修改写入当前 Scene 基础值，武装后才写入该段。背景不开放 Linear，以避免颜色 / 图案在没有明确语义时产生不可预期插值。

即使刚切出的背景段尚未写入参数，也必须以白色分界显示，不能把“切分”和“黄色时序覆层”误显示为同一件事。过渡提供可选颜色的黑场转场、前后 Scene 的淡入淡出、带方向的扫描擦除、以及可控颗粒/种子的溶解；黑场转场用覆盖色渐隐，其余三种复用前一 Scene 与当前 Scene 的实际渲染帧。场景叠加滤镜的“蒙版暗角”采用 Legacy 暗角的轻量径向渐变：颜色、强度、中心保留、边缘范围和叠加方式；蒙版仅用于限制它的作用区域。

路径描线、纯色/纹理填充、文字字体/字距/行高仍属于内容层。图元路径描线与对象 `outline` 必须同时存在但明确标识：前者沿路径，后者沿最终 Alpha。

## 加样与采样

加样、采样均以**效果卡**为最小交互单位：

```text
[启用] 效果名称 · 一句用途说明
启用后：
  卡头：名称 | 运动开关 | 时序入口 | 移除
  内容：按 registry.params 顺序生成的控件
```

采样页最上方常驻显示三个共享控制器（仅在至少一个实际采样效果已启用时）：采样格、采样场、边缘规则。它们不是可排序卡，避免用户误以为每个采样效果各有一份网格。隔离 Workbench 已按该规则写入对象 `effects.sample.controllers` 或场景 `sceneEffects.sample.controllers`。

`color-map` 中色板一经选择即覆盖取色数并禁用该输入，而不是保存两个相互冲突的最终值。`offset-sampling` 在 `boil` 模式提示采样格尺寸至少为 2；若条件不满足，明确禁用运动而非悄悄退化为物体平移。

## 渐进披露与时间轴

1. 点击启用：立即渲染参数、立即增加左侧卡片、立即刷新时间轴上下文；不得需要切换页签才显示。
2. 点击效果卡：Inspector 定位到该效果，底部显示该效果轨道。
3. 开启时序：仅写当前时段中被实际修改的参数。Step 和 Linear 的可用性读 registry，不能由 HTML 特判。
4. 开启程序运动：不自动创建时序段；周期/seed 保证循环闭合。
5. 点击移除：删除该效果及其时序覆层，作为一次可撤销命令。

## 明确不做

- 不开放任意效果逐张拖拽排序；只可拖动对象的“蒙版 / 加样 / 采样”三个阶段。
- 不在第一版让调色四轴、采样格、采样场、边缘规则做 Linear；它们保持 Step，避免高分辨率连续重算。
- 不在 UI 层维护第二套默认值、性能判断或 Agent 文案。
- Runtime 尚未实现的卡片不可伪装成可编辑；Registry 的 `runtimeSupport` 必须显示为计划状态并禁用写入。
