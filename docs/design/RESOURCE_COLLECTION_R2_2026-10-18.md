# 资源收藏R2：现有左栏的增量入口

意图：加新功能，沿用既有视觉；不是整体UI重设计。用户任务是“把这个素材／图样留给下一个作品使用，并能安全带回工程”。

## 选定方案

采用“顺手”方案：左下素材／图样旁增加收藏，不增加全局页面、弹窗或Inspector参数。与效果容器继续互斥展开，只有一个内容滚动区。当前工程列出可收藏资源；我的收藏提供取用、导出、移除，移除后可撤销。支持的原生自定义图样可从当前选中实例保存参数预设。

结果是一份带依赖闭包的资源副本，而不是对另一个工程文件的链接。示例：收藏“括号／角标”的粗细5、横臂27；切换空工程不自动带入资源，点击取用才复制预设，点击新建后在画布拖拽，获得同参数、独立可编辑的实例。

方案沿用对象先行、次级动作按钮、左栏详情、原地反馈的习惯。不采用“自动把所有素材跨工程持久化”，因为会破坏会话隔离；不另建专用工作区，因为本轮只需少量显式动作。参考既有素材导入与图样新建流程，而不是重新设计素材管理系统。

## 入口与行为

- 收藏 → 当前工程条目的“收藏”：图片／序列带上原图、recipe及Alpha依赖；模块带源码、Manifest及声明素材。
- 收藏所选图样：目前仅原生custom图样（角点箭头、括号／角标）的完整参数与描线样式。刻度／嵌套／元素排布等附着拓展尚无完整预设适配，不能伪装支持。
- 我的收藏 → 取用：复制到当前工程，一次工程撤销可移除这次取用；不自动创建对象、不授信、不运行JS。
- 当前工程图样 → 新建：复用原有拖拽绘制，参数进入预览和最终图元；一次撤销删除绘制结果，保留已取用的预设。
- 导入资源包：读取`.tosampool-resource.json`，校验成功后取用；坏包／冲突不部分写入。导出资源包随带闭包，不需要对方拥有本地收藏库。
- 移除仅修改收藏库，不修改工程。撤销移除单独恢复上次收藏；它不是工程Ctrl+Z，也不是磁盘回收站。
- 缺失资源明确列出。匹配ID的有效资源包可重连缺失图片／模块数据；R2初版不提供几何回退，后续[R3a](../architecture/V4_PATTERN_SNAPSHOT_R3A_2026-10-18.md)已补匹配静态快照显示与内部锁定，不代表生成器实现恢复。

## 状态、性能与安全

异步准备在Scene副本完成，提交前检查工程身份与revision；中途切工程或编辑则拒绝写入。失败保留工程和入口，错误留在收藏区域。等待期间防止重复按钮操作。收藏／导入不执行代码，模块仍遵守既有显式授信合同。

预览复用图样Runtime、图片recipe和Alpha管线；只处理进入可见区域附近的条目，静态首帧不跑持续动画。不在播放循环刷新收藏列表。收藏库列表底层仍为R1的完整包读取，海量收藏的索引／分页是后续性能优化，不能宣称无上限。

按下反馈复用80ms位移、列表进入120ms、标签选中即时变化；减少动态偏好下关闭动效。没有加入长说明、制作占位文字或新的视觉主题。

## 走查与验收

计数口径：从已有对象／素材开始，点击一次计一步；绘制算一次手势，阅读与滚动不算点击。

| 任务 | 原来 | 本次 |
|---|---|---|
| 跨工程复用图片 | 没有共享收藏入口，需外部保存／导入 | 收藏栏→收藏；另一个工程→取用，不丢recipe |
| 跨工程复用已调图样 | 需记住并重填参数 | 收藏所选图样→取用→新建→拖拽 |
| 误移除收藏 | 无入口 | 移除→撤销移除；工程始终不变 |

浏览器夹具从真实按钮验证：收藏去重、三类资源、预览有像素、工程切换不自动混入、取用撤销、图样保参绘制与一次撤销、资源包往返、移除恢复、缺失重连、坏包失败、异步切工程防污染。证据见`evidence/resource-r2-2026-10-18/collection.png`；主Agent实际看图自检，未做独立视觉评分。自动Skill更新检查因宿主未安装Python失败，未影响界面运行与浏览器验证。
