# 图样目录 G1/G2 交付记录

意图：沿用现有视觉与绘制习惯，改变图样的发现／创建／应用流程；不是整页风格重做。现阶段接入刻度排布、轮廓嵌套、元素排布，不提供未实现的新生成器。

## 用户路径

- 顶栏图片右侧“图样”图标→左下栏切换至图样；素材与图样共享空间，不另开弹窗。
- 无唯一图元：展示三个已交付图样，仅“新建”。点击后在卡片内选择载体，复用原工具在Canvas绘制。
- 唯一图元：按能力筛选，仅“应用”。开启或重新开启该拓展，打开其参数；重复应用不更改参数或增加历史记录。
- 新建完整提交载体与配置，单次撤销一起移除；多图元对象新建时附着到当前对象。组／多选不擅自选择其中一个对象。
- 自由多边形沿用逐点绘制与Enter／双击闭合。选择变化、Esc或项目替换取消未提交图样绘制，不把旧目标写进新项目。
- 返回素材保留原有导入与预处理入口。目录不是状态面板，不放启用标记或停用操作。

## 四层落点

| 层 | 实现 |
|---|---|
| 登记／选择 | editor/v4-pattern-registry.js；以已有能力提供合法图样及载体，不修改EffectRegistry或Scene格式 |
| 目录／参数入口 | editor/classic-v4-pattern-library.js与CSS、Inspector.focusExtension；HTML仅加载与初始化 |
| 绘制／Runtime | 复用DrawingController、PartsState、pathExtensions；新建与应用直接保存现有extensions；没有增加Runtime算法或新参数 |
| 验证 | tests/v4-pattern-registry-contract.mjs、tests/browser/v4-pattern-library.mjs，均纳入统一verify-v4 |

图样预览由同一Runtime在160×88小画布固定时间生成，预览Player绘制后立即dispose。无RAF预览循环，不读取或修改当前工程素材。目录只在目标／可用类型／展开项变化时重建，不随播放帧反复刷新。
