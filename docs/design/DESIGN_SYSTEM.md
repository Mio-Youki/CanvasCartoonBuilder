# 设计系统

> 状态：方向已确认，token 与组件数值待通过首轮预览校准。本文是 Canvas Cartoon Builder 的视觉语言合同；未写明的内容不构成既定视觉决策。

## 职责

定义“界面看起来像什么”：颜色、字体、间距、表面层级、图标与组件的视觉 token。它不规定页面流程或字段显隐；这些由 `UI_INFORMATION_ARCHITECTURE.md` 负责。

## 已确认的产品气质

Canvas Cartoon Builder 是一个**轻量、可编辑、可由 AI 协作完成的像素动态场景工作台**。它帮助用户把静态灵感压缩为可继续调整、可运行、可导出的像素动态世界。

像素风在此不是“低清滤镜”或复古装饰，而是一种有意识的信息压缩：有限的色块、层次与运动留出想象空间，也让素材、图元和程序效果能以小体积被拆解、组合与再编辑。界面应传达“数字手作”和“安静的夜间创作台”，有轻微游戏感，但不能像玩具或街机皮肤。

## 视觉原则

- **现代工作台里的像素语法**：布局、可读性和密度遵循现代创作工具；像素感用于边框、图标、状态、缩略图与关键反馈，而非覆盖全部界面。
- **像素是单位，不是噪声纹理**：不为“像素风”额外铺满扫描线、抖动或装饰颗粒；每个像素化细节都应表达层级、状态或可操作性。
- **安静而清楚**：深色工作区承接画布，暖色只用于主行动和创作焦点；语义色稳定，不用彩虹色争抢注意力。
- **先让作品发光**：界面表面克制，画布、缩略图与效果预览是最有色彩的区域。
- **中文优先的清晰阅读**：正文和复杂参数使用高可读无衬线字体；像素字体仅用于少量标题、索引、数值标签或状态，不承担长段中文说明。

## 初始视觉方向（待首轮预览校准）

- 主基调：深墨蓝夜间工作台；面板之间以明度、细边框和有限阴影分层，而非厚重拟物。
- 强调色：偏暖黄用于“创建、导出、当前创作焦点”；青色用于可编辑/数据交互；绿色用于蒙版与有效范围；紫色用于编组；红色只用于破坏与错误。
- 表面：低圆角或近直角的模块化面板，可用 1px 像素阶梯细节作为少量识别点；避免大面积发光、CRT 扭曲、仿旧塑料机框。
- 密度：默认紧凑但不拥挤；高频操作显露，低频参数进入折叠子组或上下文面板。

## 当前字号基线（实验工作台）

这是一份用于 UI 重构期对照的**实装基线**，不是最终 token。字号采用 `px`，正文以等宽界面字体显示；后续只通过 token 收口，不再无目的地新增字号。

| 层级 | 当前值 | 用途 |
|---|---:|---|
| 工作台品牌 / 主标题 | 13px | 品牌与页面最高层级 |
| Inspector 对象名称、左栏分区标题 | 12px | 当前上下文、场景结构、素材 |
| 顶部动作按钮、输入控件 | 11px | 高频操作与可编辑值 |
| 常规按钮、结构树行、页签、Scene 标签 | 10px | 默认界面正文；Scene 标签已由 9px 上调 |
| 字段标签、说明、轨道上下文 | 9px | 参数名、辅助信息、紧凑分组 |
| 次级状态、角标、画布提示 | 8px | 不参与主要阅读路径的辅助信息 |

最低可读字号暂定为 **8px**；长句说明、主要按钮和对象名称不得低于 **9px**。

## 后续填充

- 配色：画布工作区、面板、浮层、文字、语义状态、选中与禁用色；
- 字体：标题/分组/正文/辅助文字/数值的字号、粗细、行高；
- 空间：页面栅格、面板 padding、组件间距、紧凑与标准密度；
- 表面：圆角、边框、阴影、像素纹理、焦点环；
- 图标：尺寸、描边、像素图标与文字按钮的组合规则；
- 视觉 token：最终对应 CSS 自定义属性，避免散落的硬编码色值与间距。

## 维护规则

- 每项确认的视觉决策写明“用途、token 名、值、示例、不要使用的场景”。
- 设计参考图放在 `docs/design/assets/`，文中使用相对链接；规则不嵌入大图。
- 组件的具体视觉变体同步至 `COMPONENT_REGISTRY.md`；不要在此复制其交互逻辑。
- 修改已上线的 token 或视觉层级时，记录本文“变更记录”，并视用户可见性同步 README / CHANGELOG。
