# v4 UI 继承清单

> 目的：`img2asset-vnext.html` 复用成熟的编辑器工作流与视觉外壳，但只写 `tosampool-scene/v4`。本清单避免把“停止执行旧代码”误做成“删除成熟交互”。

## 判定规则

| 分类 | 条件 | 处理方式 |
|---|---|---|
| A：纯界面会话 | 不写 Scene，只影响浏览器当前操作 | 直接继承交互与视觉，改为 v4 页面控制器维护 |
| B：可映射创作能力 | 输出可明确写入 v4 Scene / Asset / Timeline | 保留入口与心智模型，重接 v4 受控写入器 |
| C：需先补 schema | 用户价值明确，但 v4 尚无对应持久字段或 Runtime | 保留位置与禁用说明；先补 schema/Runtime，再解锁 |
| D：旧格式特有 | 依赖任意 JS、旧 `fx.layers` 或 legacy 程序对象 | 不继承执行逻辑；仅经显式迁移向导处理 |

## 逐区域对照

| 区域 | Legacy 已有能力 | v4 当前状态 | 继承判定 | v4 实现依据 |
|---|---|---|---|---|
| 顶部“新建 / 打开 / 保存” | 读取/保存旧 JS | 读取/保存 `.tosampool.json` | B，已迁移 | 文件格式不同，但工作流一致 |
| 顶部图形工具栏 | 选择、移动、旋转、缩放、矩形、直线、椭圆、多边形、文字、图片 | 矩形、直线、椭圆、多边形拖拽建立；文字点击建立；图片打开配方导入 | B，首版已迁移 | 所有已解锁工具写普通 v4 实体；选择框/变换手柄仍需 Geometry Controller；钢笔仍 C |
| 素材导入 | 选择、多帧、处理、入库、添加画布/背景 | 单图或有序多帧预处理后入库，支持卡片与拖放，可选对象/背景/由图片建立场景 | B，首版已迁移 | 文件选择与缩略交互继承；预处理写 v4 `assets[id].recipe`，不重用 legacy `state.sources` |
| 素材预处理 | 采样、色板、量化、去背景、尺寸、预览 | 配方预览：尺寸、采样格、PICO-8/NES/GB/VGA 色板、量化、去背景容差；多帧按 fps 循环预览 | B，首版已迁移 | Runtime 在载入每个 locator 后按同一 Recipe 重算；逐素材再次编辑仍属后续 |
| 素材库 | 缩略图、删除、添加、拖入画布 | 仅文本清单 | A+B | 卡片与拖放可继承；删除/放置经 `AssetState` / Entity 创建器 |
| 舞台 | 缩放、平移、重置、高 DPI Overlay、选择框/手柄 | 已有 Alt 缩放、Shift/中键平移、重置、选择框、拖移、四角缩放、旋转；Ctrl/Cmd 可加入多选 | A+B，首版已迁移 | 单对象直操以单次手势事务写 v4 `EntityState`；多选时不显示误导性的单对象手柄；精确路径点和枢轴编辑仍待扩展 |
| 预览质量 / 性能 | Auto/Full/Draft 与旧 Runtime 指标 | 旧控件残留但未接线 | C | v4 Runtime 未声明同一 preview-quality 合同；不得假装生效 |
| 结构树 | 展开、收起、多选、调序、组、锁定、独立、隐藏、删除、粒子化 | 层级树、Ctrl/Cmd 多选、展开/收起、编组/解组、删除、拖放前后插入/拖入组内均已迁移 | A+B，首版已迁移 | 组写 `parentId`，实体数组仍为唯一 z 顺序；拖到对象中央自动建组，删除组只解组保留成员。锁定、独立、隐藏、粒子化与 program 节点仍待后续 |
| Inspector | 属性、动态、局部效果、采样运动、颜色/纹理/蒙版组件 | 成样/加样/采样/场景效果首版 | B+C | Registry 是唯一来源；颜色、纹理、蒙版必须做跨效果共享组件 |
| 时间轴 | 播放头、Scene 标签、上下文轨道、切分、Step/Linear、段样式 | 简化 v4 轨道 | A+B | 视觉与交互应靠近旧版；数据只读写 v4 `TimelineState`，不沿用旧 scene 分段格式 |
| 测试场景 / GIF 等导出 | 自包含旧 JS、帧渲染、GIF | 禁用 | C | 需 v4 Artifact Builder，不能调用 legacy 导出器 |
| 旧程序元素 / 专用绘制函数 | 任意 JS 绘制、专用 Runtime 行为 | 无 | D | 仅 explicit migration：builtin、冻结素材或保留 Legacy |

## 恢复优先级

### P0：不改变 v4 schema 的可用性恢复

1. 工具栏保留并恢复“选择 / 移动 / 缩放 / 旋转”模式；恢复舞台平移、缩放、重置。
2. 素材库恢复缩略图、拖放进画布、删除和“添加到场景”。
3. 时间轴改回原页面的视觉节奏与播放控件，但只接 v4 对象/效果轨道。
4. 结构树恢复折叠、滚动定位与当前对象高亮。

### P1：v4 Schema / Runtime 先行后解锁

1. 精确路径点与旋转枢轴。
2. 统一颜色、纹理、蒙版组件；它们由 Registry 属性生成。
3. 扩展 `Asset Recipe`：透明度、已入库素材的再次编辑与帧间独立处理。

### P2：完整交付闭环

1. v4 自包含测试页。
2. PNG / GIF / WebP / WebM 等按固定时间 Runtime 导出。
3. 旧 JS 显式迁移向导与 `home-scene-v4.tosampool.json` 样例。

## 时间轴继承原则

v4 不应保留 legacy 的场景数组、`show`、`fx.segs` 或自动切段算法；但应继承用户已熟悉的交互：

- 上方播放刻度与播放头；
- 当前上下文轨道；
- 单击定位、明确按钮切段；
- Step 段、Linear 段的可见差异；
- Inspector 与当前轨道严格同步。

数据映射为：对象 `timeline.tracks[entityId]`，效果 `effect:object:<entityId>:<effectId>` / `effect:scene:<stage>:<effectId>`。这就是“体验继承、数据不继承”的边界。
