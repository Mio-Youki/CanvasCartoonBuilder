# 交互与动效规范

> 状态：骨架。本文定义界面对用户动作的回应方式，而不是单纯列出 CSS 动画。

## 职责

沉淀状态反馈、模式进入/退出、拖拽、实时预览、异步操作和动效 token。组件的外观见 `DESIGN_SYSTEM.md`，信息出现时机见 `UI_INFORMATION_ARCHITECTURE.md`。

## 全局原则（待视觉方向确认后细化）

- 高频编辑优先即时、可逆、低干扰反馈；
- 拖拽与画布操控必须跟手，不添加拖尾动画；
- 动效用于说明状态变化、空间关系或等待过程，不能仅作装饰；
- 重要状态不能只依赖动效或颜色，须同时有文字、图标或结构反馈；
- 提供 reduced motion 策略：去除位移/循环装饰，保留必要状态变化。

## 每种交互的标准条目

```md
## 行为名称

- 触发条件：
- 前置状态与目标状态：
- 即时反馈：
- 过渡：属性 / 时长 / easing / 是否可打断：
- 完成、失败与撤销反馈：
- 鼠标、触摸、键盘等价操作：
- 不应发生的误触：
```

## 首批待沉淀行为

- 面板折叠与渐进展开；
- 模式进入/退出：绘制、parts 编辑、蒙版编辑；
- 图层/parts/FX 的插入式拖拽排序；
- 参数实时预览与历史记录；
- 保存、测试场景、帧导出等异步反馈；
- 画布选中、hover、锁定、隐藏与诊断提示。
