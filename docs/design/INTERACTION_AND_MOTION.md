# 交互与动效规范

> 状态：骨架。本文定义界面对用户动作的回应方式，而不是单纯列出 CSS 动画。

## 职责

沉淀状态反馈、模式进入/退出、拖拽、实时预览、异步操作和动效 token。组件的外观见 `DESIGN_SYSTEM.md`，信息出现时机见 `UI_INFORMATION_ARCHITECTURE.md`。

## 全局原则（待视觉方向确认后细化）

- 高频编辑优先即时、可逆、低干扰反馈；
- 拖拽与画布操控必须跟手，不添加拖尾动画；
- 动效用于说明状态变化、空间关系或等待过程，不能仅作装饰；
- 重要状态不能只依赖动效或颜色，须同时有文字、图标或结构反馈；
- 提供 reduced motion 策略：去除位移/循环装饰，保留必要状态变化。

## 每种交互的标准条目

```md
## 行为名称

- 触发条件：
- 前置状态与目标状态：
- 即时反馈：

- 完成、失败与撤销反馈：
- 鼠标、触摸、键盘等价操作：
- 不应发生的误触：
```

## 首批待沉淀行为

- 面板折叠与渐进展开；
- 模式进入/退出：绘制、parts 编辑、蒙版编辑；
- 图层/parts/FX 的插入式拖拽排序；
- 参数实时预览与历史记录；
- 保存、测试场景、帧导出等异步反馈；
- 画布选中、hover、锁定、隐藏与诊断提示。

## 已确认的基础编辑反馈

- 黄/蓝/绿画布控件分别表示元素、part、蒙版，绘制预览与未编辑蒙版提示也必须使用同一高 DPI Overlay，不得回退到低分辨率场景 Canvas。
- 矩形/椭圆绘制时，Shift 固定宽高比；矩形为正方形、椭圆为正圆。
- 方向键遵循当前最具体的选中对象：蒙版编辑（绿）→ part（蓝）→ 多选/元素（黄）。普通方向键移动 1 个画布像素，Shift + 方向键移动 10；输入控件获取焦点时不得拦截。
- 连续按住方向键合并为一个撤销快照；拖拽与画布操控保持实时跟手，不附加拖尾动画。
- 新建 Alpha 图片蒙版先进入“拖拽放置”而非默认铺满画布；场景图片被用作 Alpha 源时继承其当前轴对齐位置和尺寸。旋转、镜像、滚动和动画不自动继承，避免将尚不支持的蒙版变换伪装为已生效。
- 素材库来源的 Alpha 蒙版首次拖拽和后续绿角缩放默认锁定图片比例；按住 Shift 临时自由缩放。场景图片来源则优先继承该图片已设置的位置和尺寸。
- `Ctrl/Cmd + 点击`在画布与图层卡片上切换普通图片、矢量与稳定 id 程序 parts 元素多选；`Ctrl/Cmd + A`仅选可编辑元素。Esc 或单击画布空白处退出；不应把背景或隐藏的 Alpha 蒙版素材加入集合。
- `Ctrl/Cmd + G`将至少两个未编组成员建立为父级组，`Ctrl/Cmd + Shift + G`解除当前父级组。组选择使用紫框（不用红色，红色保留给删除/错误）；Canvas 点组内成员必须进入黄框并展开/定位对应组内卡片，双击再进入蓝色 parts 编辑。同步动画/滚动优先使用组内唯一非空值，否则取最上方成员，建组本身不改写成员参数。
