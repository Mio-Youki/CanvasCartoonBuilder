# 旧媒介工作台界面小样

当前基线：后续只使用 [现状输入组件](inspector-input-lab.html)，不再比较 A/B/C 外观副本。[Inspector 全量图鉴](inspector-atlas.html)以实际 348 px 栏宽铺开 31 个可交互面板，涵盖 Scene、组、元素、图元、图片／序列、粒子、Builtin 参数示例、13 张效果卡及采样格。两页都只从 [`inspector-input-kit.js`](inspector-input-kit.js) 与 [`inspector-input-kit.css`](inspector-input-kit.css) 取得控件实现和样式；修改一个组件会同时更新小样及图鉴内所有实例。效果字段读取 V4 Registry，显隐由 Inspector 的参数规划器和图鉴中的场景／蒙版／粒子分支规则驱动，互斥参数不再并列展示。图鉴只用于核对输入类型、同行／单行布局与渐进式交互，不写工程数据。当前扫描方向仍按正式编辑器的四向下拉展示；连续方向的 Runtime 先决项见 [迁移前 Runtime 清单](../INSPECTOR_PRE_MIGRATION_RUNTIME.md)。逐模块排布与分支核对见 [图鉴排布矩阵](../INSPECTOR_ATLAS_LAYOUT_MATRIX.md)。

工作台左下屏与 Inspector 的页签切换现改为 210 ms 的旧内容退出／新内容锁定过渡：轻微横向错位、一次短抖、迅速稳定。只作用于屏内内容；不支持 View Transitions 或启用“减少动态效果”时直接切换。此前单纯覆盖在新内容上的扫描线已移除。

当前验证：图鉴与工作台脚本语法、共用组件引用、Registry 效果卡与关键条件分支检查已通过；浏览器画面和动效录屏尚未完成验收，不能仅凭静态检查宣称视觉定稿。

## Inspector 输入样式集合

直接打开 [inspector-input-lab.html](inspector-input-lab.html) 可预览 11 类可交互输入：精确数值、滑杆＋数值、成对数值、角度／方向、枚举选择、双态开关、颜色＋透明度、素材／对象引用、文本、画布空间输入、图样预览。初稿采用 Graphic Retro Futurism 的米色机壳、直角数显、套印色状态；[1600 宽截图](inspector-input-lab-1600.png)与[1280 宽截图](inspector-input-lab-1280.png)用于比较信息密度。

这是独立的设计试验页，不连接工程数据，也不会修改正式编辑器。「采样场」属于不均采样内部参数，没有独立启用开关；样本中的双态开关使用网点映射的「双色」举例。输入分类与对应参数见 [Inspector 输入分类](../INSPECTOR_INPUT_TAXONOMY.md)。

第二轮按参考图收紧为“默认读数、悬停编辑”：数字框上下拖动调值，宽高可锁比例，离散外观滑杆、连续方向盘、独立边框的枚举、棋盘底色块＋同行 Alpha、简化的旋转中心入口、图样预览内颜色与同排偏移。检查图：[1600 宽](inspector-input-lab-v2-1600.png)、[1280 宽](inspector-input-lab-v2-1280.png)。旋转中心的真实画布取点仍待正式控件接入；小样按钮只演示进入与复位状态。

第三轮将比例锁换成参考图所示的纵向链环符号；所有双数值行统一预留右侧操作槽，避免有锁定键的宽高行与无按钮的坐标行错列。扫描擦除的连续方向仍只是小样语义，正式编辑器的四向数据与裁切机制另列为待办。工作台小样的左上屏、左下屏与 Inspector 也加入常驻细滚动轨道，用青色当前可见段／黄色剩余轨道检查样式；尚未替换正式编辑器滚动行为。

第三轮检查图：[输入样式 1280 宽](inspector-input-lab-v3-1280.png)、[工作台滚动轨道 1280 宽](workbench-v13-scroll-1280.png)。第二张使用 `?state=timed`，因此可同时检查 Inspector 动态展开后的溢出状态。

第四轮仅修滚动轨道：原生滚动条在 Windows／Edge 中仍出现圆角、端箭头与滑块／轨道不同宽；因此工作台小样改用 3.5 px 青／黄等宽轨道（原 7 px 的一半）、16 px 透明拖拽命中区，滚动内容仍由原容器负责。无溢出时青色填满全高。见[1280 宽动态展开截图](workbench-v14-scroll-1280.png)。正式编辑器尚未接入此自绘轨道。

第五轮统一左侧图元与成样为套印青；时序按钮及 TRACK 的时序段改用独立绿 `#009944`。TRACK 默认段跟随当前成样／加样／采样页签呈青／红／黄；Linear 用随时间方向变化的波点呈现默认→时序、时序→默认及绿→阶段色→绿的时序间过渡。检查图：[1600 宽图元与加样轨](workbench-v15-primitive-1600.png)、[1280 宽成样轨](workbench-v15-timing-1280.png)、[1280 宽采样轨](workbench-v15-sample-1280.png)。这是视觉状态小样，不改变正式编辑器的时间轴数据与插值行为。

第六轮取消组／元素／图元的三色身份：场景结构统一暖白选中与悬停，Inspector 顶部不再有身份色条。TRACK 主轨缩至约原高度一半，每段独立圆角，仍由处理阶段色标识；Step 只在下层增加半高绿色细线，Linear 只用下层绿色波点、无连续底色。检查图：[1280 宽成样与时序](workbench-v16-timing-1280.png)、[1600 宽图元与加样](workbench-v16-primitive-1600.png)、[1280 宽采样](workbench-v16-sample-1280.png)。正式编辑器尚未应用这些视觉变更。

## 工作台整体小样

直接在浏览器打开 [old-media-workbench.html](old-media-workbench.html) 即可查看。它只模拟界面状态，不连接工程数据，也不会修改正式编辑器。

可试的交互：在共槽键区切换八个工具并修改右侧数显参数；切换左侧「对象效果 / 素材」、右侧「成样 / 加样 / 采样」；在成样内切换「基本 / 动态」，点击动态或效果图示卡主体选中、点击角部电源按钮启停；拖动左右栏分隔线；点击圆形播放键查看竖排实体状态灯；打开「导出格式」观察浮层动画。

第十七轮将成样的基本/动态改为常驻切换，并为六种动态提供独立选择、启用与参数时序入口。小样的 `?state=timed` 展示已启用的漂浮卡与绿色时序键：[1280 宽截图](workbench-v17-motion-1280.png)。正式编辑器同轮接入共享对象轨上的逐动态 Step 覆层；小样本身不保存数据。

第十八轮移除额外的「基本／动态」页签，改为标题右侧图标切换；基础属性合并为单张「变换」卡，内部以行和细分隔线组织。加样、采样标题移除 `FX / 06`，动态页补齐相同标题行。检查图：[基本](workbench-v18-basic-1280.png)、[动态](workbench-v18-motion-1280.png)、[正式编辑器变换卡](workbench-v18-editor-transform-1280.png)。

URL 中加入 `?state=compose`、`?state=sample`、`?state=assets` 或 `?state=modal` 可直接进入对应检查状态。当前第七轮截图为 [1600×900 采样](workbench-v7-1600.png)、[1280×800 成样](workbench-v7-1280.png)、[素材视图](workbench-v7-assets.png)和[临时浮层](workbench-v7-modal.png)；前六轮截图保留以便比较。第七轮保留实体排布，仅将屏内改为暖白读数与三阶段套印色。可变时长的刻度密度仍是待定的界面规则。

第八轮仅调整已确认的结构与控件：[1280×800 成样](workbench-v8-1280.png)、[1600×900 采样](workbench-v8-1600.png)。工具参数与 Inspector 共用输入视觉；动态、时序各用一个统一图标；左侧对象效果分为采样、加样、蒙版、成样四层，成样固定排在底部。下一轮是否采用说明书式直角卡片，仍待讨论。

第九轮层级小样：[1280×800 成样](workbench-v9-1280.png)、[1600×900 采样](workbench-v9-1600.png)。四个处理阶段采用编号直角模块，成样恢复青绿代表色、蒙版保留中性字色；场景结构的展开层级用左侧导引框，Inspector 的基本参数使用较轻的编号字段框，效果图示下方只给当前选中效果一张参数框。实体机壳和四屏布局不变。编号、调序符号和样例数据不代表正式数据协议。

第十轮状态小样（历史配色，已由第十六轮替换）：[1280×800 元素](workbench-v10-1280.png)、[组](workbench-v10-group.png)、[图元](workbench-v10-primitive.png)、[素材](workbench-v10-assets.png)、[动态与时序启用](workbench-v10-timed.png)、[1600×900 采样](workbench-v10-sample.png)。`>`／向下箭头与点号区分可展开和叶节点；元素子项也有导引线。对象效果卡片拉开间距，成样不再固定高亮外框；蒙版保持中性。素材导入与对象效果删除动作移至各自 Tab 下的屏内操作行。该轮 Inspector 顶部身份色带已在第十六轮移除。

第十一轮细化：[1280×800 成样](workbench-v11-1280.png)、[1600×900 采样](workbench-v11-1600.png)。图元导引线与元素展开符号对齐；对象效果条目只负责选中，删除集中在上方命令键，Inspector 图示卡仍负责效果启停。阶段标题增至与 Inspector 小标题相同的 12 px，去掉标题前的编号与装饰标记。左栏屏幕底部的青色套印条向左延展。原型内的删除键可移除选中效果，再从 Inspector 启用可恢复条目；这些操作仍只改变本页示意状态。

第十二轮细化：[1280×800 成样](workbench-v12-1280.png)、[Auto 降档](workbench-v12-auto-draft.png)。成样卡片的动态键移到标题右端，与「基本」时序键共享右对齐线；时间轴末刻度与轨道实际右边界对齐。舞台上框的灯与数显只表示预览质量，模式选择为 Auto／Full／Draft，数显另显示实际 Full／Draft 与性能读数；播放状态仍由底部双灯表示。`?state=auto-draft` 仅模拟 Auto 降档以检查黄灯与文案，原型不读取真实调度器。

图标、场景画面、性能数字与具体参数均为占位。正式界面的数据语义继续以 Effect Registry、Scene Spec 和 Runtime 合同为准。
