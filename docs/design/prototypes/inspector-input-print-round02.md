# Inspector 输入组件 · 印刷复古未来主义 / 第二轮

本轮是已有组件页的视觉方向比较。基线与 A／B／C 共用 [控件行为脚本](inspector-input-contract.js)和[控件结构样式](inspector-input-contract.css)，三版再各自决定纸面、标题、边框、按钮与读数的视觉性格。正式编辑器暂不覆盖；工作台只应用本轮明确指定的命名与页签切换改动。

| 方向 | 视觉北极星 | 有意突出的内容 | 主要风险 |
|---|---|---|---|
| A · 印刷说明书 | 可操作的旧设备手册 | 字段与数据的阅读次序、暖纸与深墨的对比 | 浅底与当前工作台深屏的衔接需要再设计 |
| B · 套印海报 | 大众拼贴与三色套印 | 采样产品的鲜明识别度、粗字与编号 | 高饱和标题在高频操作时可能过于活跃 |
| C · 信号仪表 | 工程蓝图转译成数显 | 数据、网格、低照度下的参数扫描 | 与现有数显较接近，印刷感相对弱 |

在 [比较页](inspector-input-print-compare.html)切换并排或单张的实际尺寸。三份页面分别为 [A](inspector-input-print-a.html)、[B](inspector-input-print-b.html)、[C](inspector-input-print-c.html)；完整页面截图分别为 [A](inspector-input-print-a-1280.png)、[B](inspector-input-print-b-1280.png)、[C](inspector-input-print-c-1280.png)。比较时优先看参数值、字段名、当前选择和禁用／启用状态，而不是缩略图上的色彩冲击。

控件合同：普通数值输入不显示 `px`；百分比输入的 `%` 是框内固定视觉后缀，实际仍保存 `0–100` 数字，写入编辑器透明度等 `0–1` 字段时按原有逻辑除以 100。滑杆标出两端值，角度盘显示八个 `45°` 刻度。枚举下拉以左侧 `>` 表示可展开，打开时变为向下箭头。双态开关在名称左侧；打开后名称按所属处理阶段着色，浮标后方留向下箭头并展开从属参数。各类强调色分别使用成样青、加样红、采样黄。

检验：四份页面在 1280px 宽下无页面级横向溢出，均出现八个方向刻度和两个框内百分比后缀。四页的滑杆数值、双态开关和图样类型交互均已在浏览器核对，未出现页面异常；工作台两处页签切换的扫描状态亦已核对。尚未独立视觉评审；选定方向后再做更深入的 200% 阅读与动效节奏精修。
