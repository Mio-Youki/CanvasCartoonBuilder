# 左侧“效果”容器 vNext

> 下一轮左侧布局以 [旧媒介工作台 UI 规则](OLD_MEDIA_WORKBENCH_UI_RULES.md) 为准：场景结构常驻，下方的对象效果与素材是同一屏幕槽的两个 Tab。本文件记录当前容器的数据与导航语义；互斥展开方式属于现有界面实现。

> 状态：Classic v4 首闭环已接入。已实现启用项索引、与素材互斥展开、卡片定位 Inspector / 下时间轴、统一停用清理，以及对象三大阶段 Pointer 调序；对象效果、共享控制器、对象蒙版、场景效果与保存重开均有真实 Edge 覆盖。卡片标题内的“运动 / 时序”快捷图标仍属后续渐进披露优化，不阻塞当前数据闭环。

## 位置与展开规则

“效果”位于左侧栏的“场景结构”下方、“素材”上方。它与“素材”互斥展开：打开其中之一会收起另一个，容器高度与左侧栏的可调分界共享同一布局约束。

它不是第二套 Inspector，也不是完整图层树，而是当前上下文已经启用的效果索引：

- 选中对象：显示该对象的 `采样 / 加样 / 蒙版`；
- 未选中对象、Inspector 处于场景上下文：显示 `叠加滤镜 / 采样滤镜`；
- 未启用效果：显示空态及“前往 Inspector 添加效果”的入口。

新启用效果时自动展开；切换上下文不会强制抢开面板。当前实现中，用户手动收起后只有同一上下文的启用项数量增加才会再次展开；进入相关 Inspector 页不抢夺展开状态。

## 卡片与顺序

每个已启用效果生成一张固定顺序的卡片：

```text
[阶段标题]                         ← 仅对象；蒙版 / 加样 / 采样可拖动
  效果名称           [运动] [时序] [×]
  轻量摘要：如「screen · 35% · 4px」
```

- 点击卡片：定位 Inspector 的对应效果，并切换底部编排器为该效果轨道。
- `×`：以统一命令禁用效果，删除该效果的时序覆层。
- `运动`：仅当 registry 声明 motion 时可用；表示过程式循环，不是关键帧。
- `时序`：进入该效果的时段编辑上下文；具体可否 Linear 仍由参数声明决定。
- 阶段内卡片顺序固定为 registry 的 stage 顺序；不允许逐卡拖拽。
- 对象只可拖动阶段标题。默认 `蒙版 → 加样 → 采样`；拖动会写 `pipeline`，并即时重建预览。

场景效果不开放阶段排序，固定为 `叠加滤镜 → 采样滤镜 → 输出颗粒`。

## 与结构树、粒子和蒙版的关系

- 效果卡不会成为结构树中的可绘制图层；它们是对象或场景的声明式处理。
- 粒子源的卡片显示继承摘要（例如“继承：描边、采样、投影”），不复制一组独立的效果面板。
- 蒙版引用的元素仍在结构树中，引用状态以“引”标记；被引用时仅作蒙版，不参与可见合成，也不修改自身的隐藏属性。
- 场景范围蒙版不在结构树生成一个伪 FX 层；卡片只在“效果”容器中出现。

## 空态与性能反馈

卡片不显示原始成本字母作为创作门槛，但在高成本组合时以一句行动建议提示，例如“场景级采样 + 大画布：预览会使用 Draft，导出保持完整质量”。详细性能数据留给诊断面板和 Agent manifest。
