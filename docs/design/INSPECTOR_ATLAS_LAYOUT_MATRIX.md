# Inspector 全量图鉴：输入与排布核对表

状态：2026-10-09，迁入正式编辑器之前的设计基线。可交互图鉴为 [`inspector-atlas.html`](prototypes/inspector-atlas.html)；12 类控件的唯一视觉与交互实现是 [`inspector-input-kit.js`](prototypes/inspector-input-kit.js) 和 [`inspector-input-kit.css`](prototypes/inspector-input-kit.css)。输入组件小样与图鉴均引用它们。图鉴中的值是演示状态，不写项目、时间轴或 Runtime。

## 排布判定

`single`：一个独立概念占一行，名称在左、输入在右；滑杆、颜色＋透明度、引用、文本、图样预览均适用。`pair`：两个短且强相关的独立概念并列，如粒子的寿命／速度、方向／扩散角、旋转／旋转中心。X/Y、W/H、比例、斜切等虽然视觉上有两个数，但它们是**一个** `PairField`，占一个完整外层行，末尾统一预留 28 px 操作槽。图鉴 DOM 的 `data-layout` 明确记录每一行的选择；窄栏下发现拥挤时，先将该行改为 `single`，不缩小文字和命中区。

带单位的数字只允许编辑数值；`°`、`%`、`S` 是紧贴数字的不可编辑后缀，不写入数据。`S` 用于周期时间、持续时间与寿命等秒数；周期帧数与帧率不加 `S`。滑杆两端的上下限以轨道自身的左右边缘为中心对齐，标题与轨道下缘对齐。

滑杆＋数值分为两种：**电池格滑杆**用于透明度、饱和度、对比、阈值、强度等语义上天然存在比例或有效上限的量；**连续滑杆**用于语义上没有固有上限、但实现为性能或可操作性设置调试范围的量（如溶解颗粒数、投影距离）。连续滑杆使用端点标注 min/max、圆形主题色游标和连续浅色轨道；数值框与轨道共享同一上下限和值，拖动步进由字段 `step` 决定。图鉴只示范控件形态，不据此指定正式编辑器字段的范围。

### 通用输入校验与渐进展开

- 数值允许在编辑过程中暂时处于越界状态；失焦或确认输入时进行结果校验：低于 `min` 归到下限，高于 `max` 归到上限，空值/非数值恢复到上次有效值。图鉴只演示控件机制，字段边界不代表正式编辑器的最终取值范围。
- 整数输入按整数精度提交。小数默认最多保留由 `step`、`min`、`max` 推导出的最大小数位（最多 6 位），不强行补齐尾随零；字段可用 `decimals` 覆盖提交精度，`displayDecimals` 仅用于固定显示位数。边界优先于格式：若显式精度与边界的小数位冲突，最终仍精确落在边界。
- 滑杆的电池格填充和游标均继承当前主题套色，游标定位在当前值处；两端范围值以轨道端点为基准。
- 连续滑杆使用浅色连续轨道与实心圆游标；游标、描边采用所在 Inspector 的套印主题色。端点文字显示配置范围，拖动按字段 `step` 增减；数值框提交仍遵循通用上下限与精度规则。
- 下拉选项的文本左侧留出半个字号的内距。素材／对象引用菜单在每项左侧显示类型图标，图标类别来自选项的 `kind`，后续可独立替换成正式图标。
- 开关分两种：普通开关只有左侧标题与右侧“开关＋名称”；渐进开关额外显示居中的下展箭头，展开内容向右缩进一个字符并带当前主题色竖线。无从属内容时不得显示箭头。
- 图样颜色使用共用颜色＋透明度控件；透明度直接影响图样预览。

## 检查时必须操作的分支

1. 场景过渡依次选无、黑场、淡入淡出、扫描擦除、溶解；确保无相互残留的参数。
2. 对象蒙版依次选无、矩形、Alpha 图片、元素／组；核对引用、映射、固定仅作蒙版、跟随与画布编辑。粒子范围不得出现 Alpha 图片或元素／组。
3. 打开背景、图元、加样纹理叠加三处的图样编辑；修改共用控件一次，应三处一起更新。图样内逐一选单线、网格、叠线、点阵、噪点；点阵错列才显示错列偏移。
4. 每张效果卡先关闭再打开；打开动态、展开参数并切换动态方式。纹理叠加的噪点动态只能选噪点雪花／随机保持，其余类型只能选图样动态。
5. 颜色映射选自动与命名调色板；网点映射切换原色／单色／双色渐变、调整错列偏移；不均采样切换波／径向／噪声及边缘规则；核对隐藏项。
6. 粒子实体切换单帧／多帧及播放方式；图元几何切换矩形／线段／像素笔触；确认单行／同行输入没有互相挤占。

`node scripts/verify-inspector-atlas.mjs` 检查共用组件链接、Registry 效果卡覆盖、主要显隐条件与行布局合同；它不替代最窄栏宽下的浏览器视觉验收、键盘操作验收及正式编辑器数据流测试。
