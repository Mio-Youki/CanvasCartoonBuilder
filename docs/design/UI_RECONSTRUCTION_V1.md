# UI 重构 v1：结构树、舞台、Inspector 与编排时间轴

> 状态：工作台骨架已落地，进入持续细化阶段。`img2asset-layout-v1.html` 已具备真实结构树、舞台、Inspector 与编排器；Inspector 信息层级、图标系统、组件细节和模式交互仍是后续 UI 主线。本文仍是布局蓝图与格式边界，不改变当前 Scene / Runtime 合同。

## 目标

把编辑器从“功能卡片的集合”重组为一个轻量像素动态场景工作台。用户应能在任意时刻回答四个问题：

1. 场景里有什么？
2. 它现在长什么样？
3. 我选中的对象如何变化？
4. 它在何时发生？

本轮只重组信息和交互入口；不以模仿 Rive 的矢量、状态机或关键帧系统为目标。

## 宏观线框

```text
┌──────────────── 工程：新建 / 打开 / 生成* ───────────── 工具：播放 / 保存 / 测试 / 导出 ┐
│  场景结构                │               舞台（Canvas）                       │ Inspector          │
│  背景                     │  选择 / 绘制 / 图片 / 缩放与比例                   │ 属性 / 动态 / 效果  │
│  组                       │                                                     │ 当前选择的单一真相  │
│    元素                   │                                                     │                    │
│      图元 / 局部效果*     │                                                     │                    │
│  ───── 素材库（可收起）   │                                                     │                    │
├───────────────────────────┴─────────────────────────────────────────────────────┴────────────────────┤
│ 时间刻度 / 播放头  ·  场景段轨  ·  当前对象显示时段轨  ·  当前效果作用时段轨                         │
└──────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

`*` 为未来 Agent 入口或由现有独立 FX 数据映射出的视觉子节点，不表示新格式字段。

## 四个稳定工作区

### 1. 左侧：场景结构与素材

- 上半部分是**结构树**，不是属性卡片。它以组、元素、图元、粒子为层级；元素默认收起，点击才展开图元；局部 FX 可作为其绑定元素的视觉子节点。背景不进入树。
- 图层条目只呈现名称、缩略标识与快捷图标：粒子化、锁定、隐藏、删除等；不再承载完整参数表单。
- 下半部分为可收起的**素材库**：导入、素材缩略图、拖入 Canvas、添加到场景。图片的去背景、均匀量化、源尺寸等仍在入库前处理。
- 元素级 `pixelDiv` 是样式能力，进入右侧 Inspector；不把所有图片预处理参数错误推广给图元或程序元素。

### 2. 中间：舞台与创作工具

- 工程命令：新建、打开、未来的生成场景；交付命令：播放、保存、测试、导出。
- 中部工具为选择、矩形、直线、椭圆、多边形、图片等。绘制目标由当前选择层级决定：黄框创建元素，蓝框创建图元；移除额外“目标”下拉。
- 舞台容器固定，Canvas 在其中缩放与平移；舞台横栏显示比例、缩放倍率与适配状态。
- 钢笔仍需 path 数据与控制点模型，暂不纳入；文字已采用“工程信息 + 内嵌 PNG 栅格快照”实现可编辑的轻量路径，后续重点是文字 Inspector 与工具交互完善，而非重新定义 Runtime。

### 3. 右侧：统一 Inspector

无选择时顶部使用 `属性 / 全局效果`；选择对象后将逐步使用 `属性 / 动态 / 效果` 分段。选择决定 Inspector 的对象：

| 当前选择 | 属性 | 动态 | 效果 |
|---|---|---|---|
| 无 | 场景尺寸、周期、背景 | — | 全局 FX 与转场 |
| 背景 | 布局、透明度、多帧 | — | — |
| 元素 | 变换、混合、蒙版、元素样式 | 滚动、循环动画、多帧 | 绑定的局部 FX |
| 组 | 组变换 | 组动画、同步策略 | — |
| 图元 | 几何、填充、路径描线 | — | — |
| 局部 FX | 范围、绑定、混合 | 时段由时间轴编辑 | 覆盖 / 调色 / 风格效果 |

Inspector 是当前选择的唯一参数入口；结构树只负责定位、排序和选择。

### 4. 下方：上下文编排器

- **时间刻度 / 播放头**与**场景段轨**永远可见。
- 选中元素、组或粒子时显示其 `show` 窗口轨；场景段 chip 既是导航，也可作为该对象在某场景是否出现的快捷开关。
- 选中局部 FX 时显示其 `show` 窗口轨；选中全局效果时显示当前 `fx.segs[scene]` 的分段轨。
- 局部 FX 的最终生效区间始终是“绑定元素可见窗口 ∩ FX 自身窗口”。元素范围可以作为浅色底带，不自动覆盖 FX 自己的时间。
- `[S]` 不再作为卡片头中的独立弹窗，而是时间轴的对象焦点状态；编辑操作仍沿用现有切分、增加、移动、缩放、删除语义。
- **选择同步约束**：结构树、Canvas、Inspector 与下时间轴必须由同一选择上下文派生。选中绑定 FX 时下轴切换到该 FX 的参数 / 可见时段；取消对象选择时 Inspector 与下轴同时回到场景 / 全局 FX。任何新增选择入口都必须触发这两处刷新。

## 数据与运行时边界

| 需求 | 首轮实现方式 | 是否迁移 Scene 格式 |
|---|---|---:|
| 结构树 | 从 elements、groups、parts、背景与粒子派生 View Model | 否 |
| 局部 FX 显示为元素子项 | 从 `fx.layers[].bind.targetId` 派生 | 否 |
| 元素 / FX 时段轨 | 复用 `show` | 否 |
| 全局 FX 时段轨 | 复用 `fx.segs[scene]` | 否 |
| Inspector | 编辑既有元素、组、图元、FX 字段 | 否 |
| 锁定 | 可选新增 `locked:true`；Runtime 忽略，编辑器阻止变换 | 小增量 |
| 时间标签 | 后续可新增 `markers:[{id,t,label,color?}]` | 小增量 |
| 一个元素的局部 FX | UI 默认一个；数据仍允许多个独立 `fx.layers` | 否 |

禁止为了视觉树而把 `fx.layers` 强行移动进 `element.localFx`：这会破坏现有独立排序、绑定解除、全局合成阶段和旧场景兼容。首轮只改变视觉归属。

### 透明度与叠加方式

- **元素**：`alpha` 与 `blend` 是实体绘制边界属性。`alpha` 会与元素动画的 blink 相乘；`blend` 支持 `normal / screen / multiply / lighter`，在该元素绘制到已完成画面时应用。
- **图元**：图元的 `alpha` 再与所属元素 alpha 相乘；图元 `blend` 优先于元素 `blend`。图元 `stroke/strokeWidth` 是路径本身的描线，可形成空心形状；它不等同于元素 `style.outline` 的最终 Alpha 轮廓。这使一个由 parts 构成的元素可在内部混合不同图元。
- **组**：组不新增 `blend`，也不成为离屏合成容器；组 `transform.alpha` 是逐成员乘算的透明度，`transform.rot/pivot/anim` 同样以确定性共享矩阵表达。若增加真正的组混合方式、裁切或调整层，才需要缓存画布与新的渲染容器。

## 新增编辑器临时状态

这些仅存在于编辑器，不写入导出的场景：

- `inspectorTarget`：当前由右侧编辑的场景 / 元素 / 组 / 图元 / FX；
- `timelineTarget`：当前时间轴展示的元素或 FX；
- `structureExpanded`：结构树展开状态；
- `pinnedTimelineTargets`：后续多对象比较用，首轮可只支持单一焦点；
- `selection`：与现有黄 / 蓝 / 绿 / 紫选择态互通。

## 分期与验收

### Phase A：无格式风险的 UI 骨架

1. ✅ CSS token 与固定三栏 / 底栏 shell；
2. ✅ 从既有数据渲染左侧结构树；结构行采用 Rive 式细滚动条与更高可读字号，背景不进入结构树；元素默认收起图元，图元选中会同步高亮；Ctrl/Cmd 多选、元素 / 图元的插入式调序均复用既有编辑语义，结构 / 素材高度以细分隔条调整；
3. ✅ Inspector 上下文：未选中时提供 `属性 / 全局效果`；属性含画布、背景。全局效果已接入既有 `fx.segs` 当前场景/当前段数据：过渡、叠加效果、调色、风格以 Rive 式分块呈现。调色四项统一以 `0` 为原样、`-100~100` 为 UI 值域；
4. ✅ 图片与程序元素已接入 `属性 / 动态 / 局部效果` 三页 Inspector：属性包含规范根字段、蒙版、元素风格；动态包含滚动、动画开关与多帧；局部效果仍复用 `fx.layers[].bind.targetId`。完整局部 FX 参数及组 / 图元 Inspector 仍是迁移期兼容层；
4. 保留旧 `[S]` 逻辑，先以 `timelineTarget` 驱动下方对象轨。

验收：既有 `GENERIC_SCENE`、`HOME_SCENE` 和兼容脚本均可打开、编辑、保存后重开；输出 JS 与 Runtime 画面不因 UI 重构变化。

### Phase B：时间与 FX 归位

1. 将 `[S]` 的多场景窗口编辑直接并入底部对象轨；
2. 显示局部 FX 的元素有效范围与 FX 自身时段；
3. 结构树中将绑定 FX 映射为元素子项；
4. 全局 FX 分段在“无选择 / 场景选择”状态下进入 Inspector + FX 轨。

验收：同一 `show` / `fx.segs` / `fx.layers` 数据，在新旧 UI 路径中编辑后得到相同的运行时可见性与合成结果。

### Phase C：可选能力

- `locked`；
- 时间标签 markers；
- 钢笔路径、文字图层、图元纹理须各自先有 schema / Runtime 设计，不作为 UI 重构的附带承诺。

## 未决问题

- “独立”图标的确切语义必须先定义，不能以含糊状态进入格式；
- 元素动画 UI 需将现有 bob / spin / wave / pulse / blink 映射为面向用户的动作名称，避免新旧字段重复；
- 局部效果的分类、默认预设与效果栈仍需单独收口；
- 多对象轨道比较是否进入首轮，或先只支持一个明确的 `timelineTarget`。
