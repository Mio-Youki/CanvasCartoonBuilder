# 派生 / Derive

## 结果

从静态图片产生经用户确认的可复用素材包。输出进入素材栏；本分支不负责制作正式场景。

## 输入

至少一张角色为 `source` 的参考图。其他参考图可说明目标轮廓、姿态、风格或修补方向，但不得自动替换源图。

## 执行

1. 返回派生计划卡：列出要拆出的语义对象、需要补全的区域、可选姿态/多帧变体、风险与预计人工修边点。
2. 用户批准后生成候选 Alpha、补全底层或变体；每个候选保持来源关系。
3. 进入统一 Alpha 修边与素材审阅，不绕过用户确认。
4. 用临时原位复合检查轮廓、补洞和移动后是否露缝。该复合只用于校验，不保存为正式 Scene。
5. 用户可逐项接受或批量接受；接受项进入素材栏，拒绝项不污染工程。

## 完成条件

- 每个素材有稳定 ID、来源、派生类型和可再次编辑的 Alpha 信息。
- 擦除和恢复以原始 RGB 为基底，不产生黑色恢复区。
- 被拆对象可独立移动，底层补全没有明显空洞或缝隙。
- 可选姿态/逐帧变体被标为独立派生任务；默认不自动生成。
- 结束于素材栏和校验结果，不增加场景效果、动画或时间轴。
