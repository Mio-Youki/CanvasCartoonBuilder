# 审阅门禁

## 共享门禁

- **方向确认**：用户已选择方向卡和素材策略。
- **来源诚实**：图片、派生素材、程序对象、粒子和 Module 的贡献均已说明。
- **结构有效**：结果格式、素材引用、Module Manifest 和稳定 ID 通过验证。
- **结果隔离**：确认前没有修改当前工程或素材栏。
- **上下文一致**：Scene Draft 的基底 revision 仍与当前工程一致；选择作用域外的稳定 ID 与内容没有被改写。
- **证据可复查**：保存输入、Skill/协议版本、固定时间预览、验证报告和性能数据。
- **应用确认**：用户明确接受后才写入。

## 分支门禁

- 场景创作：主要公开参数必须产生可见变化；循环边界和视觉层级通过人工审阅；当前场景/选择模式还须通过作用域保持检查。
- 派生：轮廓、补全、非破坏 Alpha 和移动露缝检查通过；交付物只有素材包。

评分只用于比较实验轮次，不替代二元工程门禁。未通过时保留证据并说明归因，不直接修补已冻结的实验结果。
