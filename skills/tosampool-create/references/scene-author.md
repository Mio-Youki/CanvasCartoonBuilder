# 场景创作 / Scene Author

## 结果

交付完整、隔离、可继续编辑的 ToSampool Scene Draft。起景与编排不是两条工作流；它们只是在同一创作流程中采用不同基底。

## 基底与作用域

先确认一个基底：

- `blank`：从空白场景开始；适合纯文本起景。
- `selected-assets`：只使用用户明确选中的素材作为主要材料；适合素材编排。
- `current-scene`：读取当前工程快照，在现有创作上继续。

`current-scene` 还须声明作用域：`scene` 或 `selection`。选择作用域时，未选对象、Scene 设置和未授权素材必须保持不变。不要把“读取当前画布”误解为可以直接修改活工程。

## 上下文

同时读取：

- 结构化快照：画布、循环、场景段、层级、稳定 ID、当前选择、对象属性、效果/时序摘要、素材清单和公开参数；
- 视觉快照：当前播放头预览；必要时补充固定时间帧；
- `sceneRevision`：应用前必须仍与当前工程一致。

完整 Scene 只在隔离执行期作为冻结输入；不要在方向卡阶段塞入大量字段。若支持按需读取，先用摘要，再读取确实要修改的对象、轨道或素材细节。

## 方向卡

当载体选择会显著改变结果时，返回两到三张真正不同的候选：

- 结构优先：普通对象、图元、粒子和少量程序构件；
- 素材优先：用户素材或获准生成的图片承担主要细节；
- 混合：高细节图片/Module 与独立对象、粒子和效果协作。

每张卡说明视觉策略、载体、可编辑部分、冻结部分、素材计划、变更作用域和成本。不要要求用户先填写完整参数表。

## 执行

1. 冻结基底、作用域、revision、参考图和素材授权。
2. 选择普通对象、图片、粒子、项目 Module 或混合载体。高细节程序绘制可保留在项目 Module 中，不强拆为无意义图元。
3. 输出完整 Scene Draft、载体报告和 `changes` 清单。即使只改选择区，也交付完整 Scene，便于预览、验证和一次性撤销。
4. 验证稳定 ID、未授权区域、循环边界、公开参数和性能预算。
5. 用户确认应用时再次核对 revision；若工程已经变化，停止并要求重新基于最新画布生成或显式重基线。

## 完成条件

- 场景可在编辑器中打开、继续修改并导出。
- `base`、`scope`、`sceneRevision` 和预计变化清楚。
- 当前场景/选择模式没有改写作用域外内容，也没有重复已有素材。
- 主要构件、生成素材和冻结细节都有诚实说明。
- 公开参数语义明确且产生可见变化。
- 不以一张完成图加装饰冒充结构化场景。

## 评测配置

C1 与 C3 继续保留，但只作为同一流程的测试配置：

- C1：`base=blank`，验证从自然语言建立世界与载体选择；
- C3：`base=selected-assets`，验证对既有素材的构图与循环编排；
- 协作修订：`base=current-scene`，验证 Agent 能否保持用户已完成内容，只修改指定对象或局部。
